# 合伙人小程序产品需求文档（PRD v1.0）

> 产品代号：**钢联合伙人**（Steel Union Partner）  
> 类型：微信小程序 + 配套后台管理系统  
> 目标：把"裂变 + 返佣 + 客户管理"做成自助化工具，让合伙人主动帮我们卖。  
> 核心理念：**钱、名、圈子三件套数字化呈现**。

---

## 1. 产品定位

### 1.1 一句话描述
**让钢厂老板、行业顾问、设备厂商、区域代理可以**："注册 → 推荐客户 → 跟进进度 → 自动算返佣 → 提现 / 抵月租 → 升级合伙人等级"，全流程自助。

### 1.2 解决的核心问题
| 问题 | 当前痛点 | 小程序方案 |
|---|---|---|
| 推荐流程混乱 | 微信群里报名字、销售忘记登记 | 推荐人录入 + 系统留痕 |
| 返佣不透明 | 客户不知道返多少钱、什么时候到 | 返佣账本 + 进度可视 |
| 合伙人没归属感 | 介绍完就没下文 | 等级体系 + 任务勋章 |
| 销售难追踪 | 谁带来的客户、跟进到哪一步看不到 | 销售协同看板 |
| 裂变缺工具 | 转发素材每次找市场要 | 内置素材库 + 一键分享 |

### 1.3 用户角色

| 角色 | 描述 | 权限关键词 |
|---|---|---|
| 合伙人（基础） | 老客户/顾问/KOL/设备商/代理 | 推荐、看返佣、提现 |
| 销售（内部） | 跟进合伙人推荐线索 | 协同跟进、CRM |
| 区域代理（高级） | 签约的独家代理 | 团队管理、二级返佣 |
| 平台运营 | 公司市场部 | 审核、结算、配置 |
| 财务 | 公司财务 | 提现审核、对公打款 |
| 管理员 | 公司管理层 | 全权限 + 数据看板 |

## 3. 核心功能详细设计

### 3.1 合伙人注册 & 实名认证

**入口**：扫码 / 销售邀请 / 客户老板自助

**字段**：
- 姓名 / 手机号（短信验证）
- 微信授权（昵称 + OpenID）
- 角色选择：老客户 / 行业顾问 / 设备厂商 / 区域代理（区域代理需后台审核）
- 实名认证：身份证正反面 + 人脸识别
- 对公账户（如需对公结算）

**业务规则**：
- 老客户角色须能匹配到现有客户合同（系统自动校验客户公司）
- 顾问/KOL 须上传 1 份个人简历或资质截图，人工审核
- 区域代理须签电子代理协议（独家区域、业绩门槛）

**数据表设计要点**：
```
partner: id, name, phone, openid, role, level, kyc_status, bank_account, region, ref_code, created_at
```

---

### 3.2 推荐客户（最核心）

**入口**：首页大按钮"+ 推荐新客户"

**录入方式**（三选一，降低门槛）：
1. **手填表单**：客户公司全称、联系人、电话、客户类型（4 选 1）、产线数、备注
2. **扫描名片**（OCR 识别公司+电话）
3. **一键转发**：选择"转发我的专属链接给客户老板"，客户填表登记，自动归属此合伙人

**关键规则**：
- 同一客户公司**首次录入者获归属权**，30 天内未推进自动释放
- 系统自动校验：是否已是现有客户、是否被其他合伙人提交过
- 录入后立即推送给运营团队（钉钉/企微通知），24 小时内分配销售跟进

**客户状态流转**：
```
新线索  →  已分配销售  →  上门诊断  →  3 天工作坊  →  POC  →  合同签订  →  上线  →  已结算
   ↓                                                                               ↓
不合格（关闭）                                                                  二次返佣（续约）
```

合伙人可全程看到当前节点，但**不能看到销售内部备注**（只能看到面向合伙人的进展摘要）。

---

### 3.3 返佣账本

**信息呈现**：

| Tab | 显示内容 |
|---|---|
| 待结算 | 合同已签但客户款未到位 |
| 待提现 | 客户已付款，平台待打款 |
| 已到账 / 已抵扣 | 历史明细 |

**结算规则**（写在产品规则页）：
- 客户每付一笔款 → T+15 工作日内合伙人对应比例返佣转入"待提现"
- 客户退款 → 同步扣减待提现 / 已提现部分要求合伙人退还
- 提现门槛：≥ ¥500 起提；对公无门槛

**抵扣自家月订阅费（双倍奖励）**：
- 老客户合伙人在小程序内勾选"用本期返佣抵扣月订阅费"
- 系统自动通知财务，下个月账单减免对应金额
- **抵扣金额 = 应返金额 × 2**（即双倍）

**审计要求**：
- 所有结算流水可导出 Excel
- 每笔返佣绑定具体客户合同编号、付款编号

---

### 3.4 等级与勋章系统

**5 级 × 累计推荐金额**（与文档 README 中收费方案一致）：

| 等级 | 累计签约金额 | 主要权益 |
|---|---|---|
| 青铜 | < ¥30 万 | 现金返佣 |
| 白银 | ¥30-100 万 | 返佣 + 自家月租 8 折 |
| 黄金 | ¥100-300 万 | 返佣 + 终身 7 折 + 大会 VIP |
| 铂金 | ¥300-800 万 | + 年度日韩参访 |
| 钻石（共建伙伴） | ≥ ¥800 万 | + 区域排他权 + 股权候选 |

**勋章/任务系统**：
- "首单达成"勋章
- "本月推荐之星"
- "灯塔厂介绍人"
- "老板局召集人"（带 3 位老板参加）
- "白皮书联合署名者"

> **设计意图**：勋章可在客户/同行面前展示，是合伙人的**社交资产**。

---

### 3.5 素材库 + 一键生成专属海报

**素材分类**：
- 行业白皮书（PDF，下载需手机号验证）
- 灯塔厂案例（短视频 + 长图）
- 标准化方案 PPT（按 4 类客户分版）
- ROI 测算 Excel
- 行业资讯简报（每周更新）

**一键生成专属海报**：
- 选择素材模板 → 自动嵌入合伙人专属二维码 → 保存到相册或转发微信
- 客户扫合伙人二维码进表单 → 自动绑定归属
- 海报样式：钢厂车间实拍背景 + 合伙人头像 + 合伙人称号

---

### 3.6 老板圈（社交 + 活动）

**功能**：
- **老板局活动**：每月推送、报名、签到（核销码）
- **同行交流**：实名老板专区，可发帖问问题
- **白皮书联合署名展示**：让合伙人成就被同行看见

**风险控制**：
- 所有发言敏感词过滤
- 不允许发布广告 / 招聘 / 撮合交易（远期再开放）

---

### 3.7 区域代理专属功能（仅铂金及以上）

- **二级合伙人管理**：发展子级合伙人，按 5% 二级返佣
- **区域客户视图**：看到本区域所有合伙人推荐进度
- **业绩看板**：月度/季度/年度
- **代理协议在线续签**

## 4. 后台管理系统（PC 端）

### 4.1 模块清单
1. 合伙人管理（KYC 审核、等级调整、冻结）
2. 客户线索池（分配销售、跟踪状态）
3. 销售协同看板（每位销售名下线索 / 漏斗）
4. 返佣结算（自动计算 + 财务确认）
5. 提现审核（双人复核）
6. 素材库管理（上传 / 下架）
7. 活动管理（老板局排期、报名核销）
8. 数据大盘（DAU、新增合伙人、推荐转化漏斗、TOP 合伙人榜）
9. 内容审核（敏感词管理）
10. 风控（异常推荐、重复客户、刷单识别）

### 4.2 数据大盘核心指标（管理层早会必看）
- 当日新增推荐线索数
- 当周转化漏斗（线索→签约转化率）
- 本月返佣支出与新签收入比（健康值 ≤ 15%）
- TOP10 合伙人贡献度
- 灯塔厂参观转化率

## 5. 风控与反舞弊

| 场景 | 控制 |
|---|---|
| 销售自己注册马甲合伙人套返佣 | 实名 + 人脸 + 内部员工屏蔽名单 |
| 同一客户被多个合伙人重复提交 | 公司名称/电话校验 + 30 天归属冻结 |
| 客户退款后合伙人已提现 | 提现需达成"客户付款 90 天后"门槛；前 90 天可冻结 |
| 区域代理把客户喂给个人合伙人套高比例 | 业绩归属穿透校验 |

## 8. 上线节奏（按里程碑）

**M0：方案定稿** —— 本 PRD 通过 + 技术方案设计 + 视觉初稿

**M1：MVP 闭环** —— 注册、实名、推荐、返佣账本、素材库、提现（核心 6 大功能）

**M2：等级体系 + 老板圈** —— 勋章、活动报名、老板圈帖子

**M3：区域代理 + 数据大盘** —— 二级返佣、代理后台、管理层数据看板

**M4：风控与运营工具完备** —— 敏感词、异常识别、A/B 测试位

> MVP 不要追求完美。**先用飞书多维表格 + 企微机器人**做手动版，跑通业务流程再开发，避免一上来就压宝大投入。

## 9. 验收标准（功能性）

- 合伙人 30 秒内可完成首次推荐提交
- 客户付款到账后，合伙人可在 24 小时内看到返佣进入"待提现"
- 提现申请到对公账户到账 ≤ 5 个工作日
- 后台导出任意时间段返佣明细 ≤ 10 秒
- 小程序冷启动 ≤ 2 秒、推荐表单提交成功率 ≥ 99.5%

## 10. 后续可扩展功能（远期路线图）

- **行业撮合**：钢厂之间余料 / 加工能力撮合（基于已认证老板圈）

- **海外版**：东南亚钢铁加工市场（越南、印尼）
