# 白皮书 ② 《中国民营镀锌 / 冷卷加工行业数字化转型白皮书》

## 一、封面副标题
> **"机组连续生产时代的数字化生存指南"**

## 二、序言推荐人选
- 中国冶金工业协会镀锌分会副会长 / 秘书长
- 宝钢 / 沙钢 / 鞍钢退休的镀锌技术总工
- 河北邯郸 / 江苏沙钢周边 / 广东佛山的标杆灯塔厂老板

## 三、第一章 行业现状（差异化）

### 3.1 5 个核心数据
1. 中国民营镀锌 / 冷卷企业约 **2,400 家**，集中在河北 / 江苏 / 山东 / 广东 4 个产业带
2. 平均净利润率从 2019 年的 **11.5% → 2025 年的 5.8%**（比钢管行业稍好但下滑同样剧烈）
3. **仅 18%** 民营镀锌厂上线了完整 MES（比钢管行业稍高，因汽车/家电客户倒逼）
4. 已上系统的镀锌厂吨成本降低 **¥80-120**（高于钢管，因机组复杂度大）
5. **OEE（设备综合效率）** 全行业平均仅 **65%**，灯塔厂可达 **78%+**

### 3.2 5 大核心挑战（与钢管行业不同点）
1. **机组停机损失大**：连续机组停 1 小时损失 ¥3-8 万，**设备 EAM 是命门**
2. **客户结构倒逼**：汽车（占 25%）+ 家电（占 30%）+ 出口（占 18%）—— **质量追溯到秒级、参数追溯到批次**
3. **能耗双控压力剧增**：吨钢综合能耗指标年度收紧 5-8%，无系统**直接被环保限产**
4. **银带 / 锌锭原材料波动**：锌价 30 天波动可达 ±15%，**成本核算精度直接决定生死**
5. **镀层质量稳定性**：同一卷材首尾镀层重量差 ±10g/m²，**SPC 统计过程控制**势在必行

## 四、第二章 5 大数字化模型（差异化）

| 模型 | 适合场景 | 投入区间 | 关键模块 |
|---|---|---|---|
| 模型一：**OEE 提升型** | 单机组试点 | ¥3-8 万 | 设备点检 + 故障记录 + OEE 看板 |
| 模型二：**质量追溯+SPC 型** | 汽车/家电客户为主 | ¥6-15 万 | 卷号追溯 + 镀层数据 + SPC 统计过程控制 |
| 模型三：**机组成本核算型** | 多机组对比 | ¥8-18 万 | 锌耗 / 电耗 / 卷耗 / 工时 自动归集 |
| 模型四：**全机组联通型** | 2-3 机组中型厂 | ¥15-30 万 | 经营版 + EAM + WMS + 财务对接 |
| 模型五：**APS+MES 智能型** | 3+ 机组 + 出口客户 | ¥30-65 万 | 旗舰版 + APS + 多基地汇总 |

## 五、第三章 4 个典型案例（差异化）

### 案例 1：河北 XX 镀锌科技（双机组，年产 35 万吨）
- **痛点**：汽车客户审厂连续 2 年未通过；OEE 仅 58%
- **改造**：经营版 + 质量追溯 + EAM
- **9 个月成果**：
  - 通过 IATF 16949 二方审核
  - OEE：58% → 73%
  - 拿到日系汽车厂年度供应商资格 + ¥1,500 万年订单
- **老板原话**："以前我以为汽车厂故意为难，上完系统才知道是我自己没数据。"

### 案例 2：江苏 XX 冷卷有限公司（3 机组，年产 80 万吨）
- **痛点**：3 机组吨成本被"摊大饼"，无法定位真实成本中心
- **改造**：旗舰版 + 成本自动化 + APS
- **12 个月成果**：
  - 3 机组吨成本对比可视，发现 2# 机组锌耗高 8%
  - 调整工艺后年节省锌锭 ¥320 万
  - 月报从 22 天 → 6 天

### 案例 3：广东 XX 镀锌厂（单机组，年产 12 万吨）
- **痛点**：家电客户要求电子化质检报告，传真 + Excel 完全跟不上
- **改造**：种子版（质量追溯 + OEE）单机组试点
- **6 个月成果**：
  - 自动生成电子质检报告，客户接 API 直查
  - 接到美的 / 格力扩单订单 ¥600 万
- **老板感言**："我以为这套要花几十万，结果种子版 3.6 万就解决了。"

### 案例 4：山东 XX 镀锌+冷卷一体厂（4 机组，年产 60 万吨）
- **痛点**：能耗双控政策下被限产，无能耗实时数据无法申诉
- **改造**：经营版 + 能耗模块（专项扩展）
- **9 个月成果**：
  - 通过省级能效领跑者认定
  - 限产解除，年增产值 ¥4,500 万
  - 入选地方政府绿色制造示范企业

## 六、第四章 ROI 测算模型（差异化数字）

| 规模 | 推荐方案 | 3 年投入 | 年节省 | 3 年净收益 | ROI |
|---|---|---|---|---|---|
| 单机组 | 种子版 + 经营版 | ¥12-15 万 | ¥120-180 万 | ¥350-525 万 | 23-35 倍 |
| 双机组 | 经营版 | ¥25-30 万 | ¥320-480 万 | ¥935-1410 万 | 31-47 倍 |
| 3+ 机组 | 旗舰版 | ¥60-80 万 | ¥800-1200 万 | ¥2340-3520 万 | 30-44 倍 |

## 七、第六章 趋势预测（差异化）
1. **汽车 / 家电客户全面要求"实时数据接入"**（2027 年起）
2. **能耗双控数据→碳交易资产**：未来无系统者**白白损失碳资产收益**
3. **镀层 SPC 成为出口标配**（欧盟 / 北美客户硬要求）
4. **行业整合加速**：未来 3 年 25-35% 民营镀锌厂将被并购或退出
5. **AI 工艺参数自优化**：节省锌锭 / 提升镀层均匀度

# 白皮书 ③ 《中国民营开平 / 纵剪加工行业数字化转型白皮书》

## 一、封面副标题
> **"薄利时代的数字化救命指南"**

## 二、序言推荐人选
- 中国钢铁工业协会加工配送分会会长 / 秘书长
- 找钢网 / Mysteel 加工配送领域负责人
- 长三角 / 珠三角 / 京津 头部开平纵剪老板

## 三、第一章 行业现状（差异化）

### 3.1 5 个核心数据
1. 中国民营开平 / 纵剪企业约 **8,500 家**（数量最多的细分），集中在所有钢材物流节点
2. 平均净利润率从 2019 年的 **5.2% → 2025 年的 2.6%**（**最薄、最危险**）
3. **仅 6%** 上线了完整成本核算系统（最低）
4. 上系统的厂吨毛利提升 **¥30-50**（**对薄利行业是救命的**）
5. **30% 的开平纵剪厂的真实毛利低于自己以为的 1-2 个百分点**——靠"猜"在亏钱

### 3.2 5 大核心挑战（差异化）
1. **极薄利润 vs. 高物流损耗**：每吨利润 50-150 元，**少算 30 元就亏损**
2. **快速接单 / 快速交付**：客户要求 24-48 小时内交货，**计划+库存协同是命脉**
3. **小批量多规格**：每天处理 100+ SKU，**Excel 完全跟不上**
4. **应收账款风险高**：下游小客户信用差，**90 天 + 应收账款占比 25-30%**
5. **行业小卷退化为"配送公司"**：被找钢网等 B2B 平台压价，**数字化是唯一升维通道**

## 四、第二章 5 大数字化模型（差异化）

| 模型 | 适合场景 | 投入区间 | 关键模块 |
|---|---|---|---|
| 模型一：**成本透视型**（首推） | 1-3 条线小厂 | ¥1-5 万 | 自动归集开平/纵剪损耗+电耗+人工 |
| 模型二：**库存账实型** | 多 SKU 小批量 | ¥3-8 万 | WMS + 卷号扫码 + 自动盘点 |
| 模型三：**应收风控型** | 下游客户多 | ¥3-6 万 | 应收账款台账 + 预警 + 信用评级 |
| 模型四：**全厂联通型** | 4+ 线 | ¥10-20 万 | 经营版 + 财务对接 + BI |
| 模型五：**配送数字化型** | 服务中转客户 | ¥15-30 万 | 旗舰版 + 客户 API + 配送调度 |

## 五、第三章 4 个典型案例（差异化）

### 案例 1：宁波 XX 钢材加工（3 条纵剪线，年产 6 万吨）
- **痛点**：不同卷材损耗差异 2-3%，但月底才发现
- **改造**：种子版（成本自动化）¥3.6 万
- **3 个月成果**：
  - 实时显示每卷损耗
  - 发现 1#线卡刀比 2#线高 1.8%（设备老化）
  - 调整后年节省钢材损耗 ¥85 万
- **老板原话**："我做了 12 年开平，从没见过这么清晰的成本表。"

### 案例 2：广东佛山 XX 开平加工（4 条线 + 2 仓库，年产 10 万吨）
- **痛点**：账实差 12%，呆滞料 ¥420 万
- **改造**：经营版 + WMS + 卷号扫码
- **9 个月成果**：
  - 账实差：12% → 1.2%
  - 呆滞料：¥420 万 → ¥120 万
  - 释放现金流 ¥300 万

### 案例 3：江苏 XX 钢材配送（5 条纵剪线 + 物流车队）
- **痛点**：客户要求 24 小时交付，订单管理混乱
- **改造**：旗舰版 + 配送调度模块
- **12 个月成果**：
  - 准时交付率：68% → 96%
  - 接到 3 家家电厂年度合同 ¥2,200 万
  - **从"加工厂"升级为"客户加工配送中心"**

### 案例 4：天津 XX 开平厂（2 条线，年产 4 万吨）
- **痛点**：账上有钱但财务说没钱（应收账款拖累）
- **改造**：种子版（应收账款 + 信用预警）
- **6 个月成果**：
  - 应收 90 天+ 占比：32% → 11%
  - 收回 ¥280 万陈年欠款
  - 老板"睡得着觉了"

## 六、第四章 ROI（差异化数字 / 强调薄利属性）

| 规模 | 推荐方案 | 3 年投入 | 年节省 | 3 年净收益 | ROI |
|---|---|---|---|---|---|
| 1 条线 | 种子版 | ¥1.5-3 万 | ¥30-60 万 | ¥88-177 万 | 30-59 倍 |
| 2-3 条线 | 经营版 | ¥6-10 万 | ¥80-150 万 | ¥234-440 万 | 23-44 倍 |
| 4+ 条线 | 旗舰版 | ¥12-20 万 | ¥150-280 万 | ¥438-820 万 | 22-41 倍 |

> **关键卖点话术**："您一吨利润才 100 块，**少算 30 块就亏一半**——上系统就是把'猜'变成'算'。"

## 七、第六章 趋势预测（差异化）
1. **找钢网 / 国联资源 / Mysteel 等 B2B 平台数字化对接成为标配**——无系统者上不去平台
2. **"配送公司化"**：单纯加工厂将被淘汰，**集成"加工 + 仓储 + 配送 + 金融"**的厂才能活
3. **下游小客户消失**：直接服务终端工厂（汽车/家电/家具/集装箱）
4. **应收账款全面"区块链化"**：电子债权凭证（如 e 信）逐步推广
5. **加工配送中心整合**：未来 3 年 **40-50%** 小厂将被淘汰或并入大型加工配送中心

# 白皮书 ④ 《中国民营钢管 + 镀锌一体化企业数字化转型白皮书》

## 一、封面副标题
> **"全产业链协同的数字化系统作战手册"**

## 二、序言推荐人选
- 大型集团（如沙钢 / 鞍钢 / 友发）的副总
- 行业一体化标杆灯塔厂老板
- 工业 4.0 / 智能制造领域的院士 / 学者

## 三、第一章 行业现状（差异化）

### 3.1 5 个核心数据
1. 中国民营钢管 + 镀锌一体化企业约 **350 家**（数量少但客单价最高）
2. 平均净利润率 **6.8%**（**最高的细分**，但下滑同样剧烈）
3. **仅 25%** 上线了完整全套系统
4. 已上完整系统的一体厂 **多业务协同效益**: 年节省 ¥800-2,000 万
5. 一体厂老板平均年龄 **52 岁**，二代接班率 **35%**——**接班人是数字化决策核心**

### 3.2 5 大核心挑战（差异化）
1. **多业务数据割裂**：钢管业务、镀锌业务、加工业务各用一套系统，数据对不上
2. **集团合并报表难**：3-5 个法人主体，月报合并要 20+ 天
3. **跨业务协同复杂**：原料采购、半成品调配、成品调度——人工调度跟不上
4. **二代接班 vs. 一代固守**：管理理念冲突，**数字化是平衡点**
5. **被规模化集团兼并的诱惑**：估值 vs. 自主，**有完整数字化系统的估值高 30-50%**

## 四、第二章 5 大数字化模型（差异化）

| 模型 | 适合场景 | 投入区间 | 关键模块 |
|---|---|---|---|
| 模型一：**单业务 POC 型** | 试点起步 | ¥6-15 万 | 钢管或镀锌任选 1 业务上质量追溯 |
| 模型二：**双业务联动型** | 全厂全套 | ¥15-30 万 | 经营版 + 集团基础合并 |
| 模型三：**集团合并报表型** | 多法人 | ¥25-45 万 | 旗舰版 + 财务合并模块 |
| 模型四：**多基地协同型** | 跨地域 | ¥40-65 万 | 旗舰版 + 多基地数据同步 + 跨厂调度 |
| 模型五：**集团 BI + AI 决策型** | 集团总部 | ¥60-150 万 | 旗舰版 + AI 预测 + 战略仪表盘 |

## 五、第三章 4 个典型案例（差异化）

### 案例 1：山东 XX 钢铁集团（3 条焊管 + 2 镀锌机组，年产值 25 亿）
- **痛点**：3 个法人月度合并 20 天；钢管 → 镀锌内部供货价不透明
- **改造**：旗舰版 + 集团合并报表
- **18 个月成果**：
  - 月度合并：20 天 → 4 天
  - 内部供货价 + 利润分摊清晰
  - 一次发现"钢管→镀锌"环节年隐性损失 ¥850 万

### 案例 2：江苏 XX 钢铁（4 条钢管 + 3 镀锌 + 2 开平，年产值 38 亿）
- **痛点**：8 套老系统并存；老板看数据每月翻 6 个 Excel
- **改造**：旗舰版 + APS + 多基地数据同步
- **24 个月成果**：
  - 8 套系统统一为 1 套
  - 老板手机端看 30 项核心 KPI
  - 估值从 12 亿 → 18 亿（被某上市集团收购参考价）
- **老板原话**："最大的回报不是省钱，是公司估值跳了一档。"

### 案例 3：天津 XX 一体厂（2 钢管 + 2 镀锌，年产值 15 亿）
- **痛点**：二代接班争议大，老一辈认为"系统会限制经验"
- **改造**：经营版双业务联动
- **12 个月成果**：
  - 数据让二代接班的方案"被数据证明"，老一辈接受
  - 内部"扯皮会"减少 60%
- **二代原话**："系统让我接班的合法性来自数据，不是我爸的指定。"

### 案例 4：广东 XX 钢铁（3 镀锌 + 4 开平，集团 + 多基地）
- **痛点**：3 个基地数据无法同步，老板无法做"集团级"决策
- **改造**：旗舰版 + 多基地协同
- **24 个月成果**：
  - 集团 BI 大屏统一看 3 基地数据
  - 跨基地原料调度年节省 ¥1,200 万
  - 入选省级智能工厂示范单位

## 七、第六章 趋势预测（差异化）
1. **集团 BI / AI 决策仪表盘**成为一体化集团标配
2. **数字化估值溢价**：上市/被并购前的"系统化整理"将提升估值 20-40%
