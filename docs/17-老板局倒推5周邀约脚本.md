> **决定后立刻锁包间**——好包间提前 1 个月才能定到。

## 2.2 圈定 12 位老板候选名单

**来源池**：
- 灯塔厂候选 30 家清单中的 S/A 级
- 现有客户老板（口碑好、有影响力）
- 销售总监行业人脉
- 灯塔厂老板的"圈内朋友"

**筛选标准**：
| 标准 | 必须满足 |
|---|---|
| 年龄 | 40-60 岁 |
| 决策力 | 一把手（董事长 / 总经理） |
| 与同行关系 | 圈内人，不是孤狼 |
| 与我方关系 | ≥ 弱引荐（不要纯陌生） |
| 行业地位 | 在所在产业带前 30% |
| 互不冲突 | 同桌不要安排正面竞品 |

**12 → 8-10 实到**：行业经验，邀 12 实到 8-10 是正常水平。

## 2.3 名单分类

按"实到概率 + 价值"双维度分 3 档：

| 档位 | 数量 | 说明 |
|---|---|---|
| **必到** | 4 位 | 灯塔厂候选老板 + 老板亲密人脉，亲自邀 |
| **力争** | 5 位 | A 级候选 + 圈内大佬，销售总监主邀 |
| **加分** | 3 位 | B 级候选 + 备选，运营专员发邀请 |

**铁律**：

# 第四部分：T-4 / T-3 / T-2 / T-1 各周话术全套

## 话术 1：T-4 周首次电话邀约（老板亲自打）

**给"必到"档（如灯塔厂候选老板张总）的话术：**

```
张总好，我是 XXX，您还记得我吧？

这周想跟您说个事——
6 月 11 号周四晚上，我们在佛山办一个小桌饭局，
只请 10 位钢铁老板，
现在确定来的有 [灯塔厂老板] X 总、[行业大佬] X 总，
[协会] X 秘书长会到场说几句。

我想请您来——一是您一直关心成本算账这个事，
二是大家想认识您。

饭局我们公司请，但您来不来都没关系，
您不来我们就空一个位置，等下次。

您看 6 月 11 号晚上有空吗？
```

**3 个关键技巧**：
1. **不卖产品**：全程不提"系统"、"软件"、"产品"
2. **抬高对方**：「大家想认识您」而非「我想介绍我的东西」
3. **给后路**：「您不来我们就空一个位置，等下次」——降低压力反而提高接受率

**应对反应**：

| 老板反应 | 回应 |
|---|---|
| "我看下日程" | "好的张总，您看完我下周一再请教，不催您" |
| "什么主题？" | "灯塔厂老板讲他这一年怎么把成本算清楚，全是干货" |
| "你们卖什么？" | "饭局上不卖任何东西，纯交流；如果您之后感兴趣再说" |
| "我助理跟您对接" | "可以，但麻烦给我您助理直接电话，我加微信" |
| "下次吧" | "理解。X 总，那下次我提前 2 个月跟您约？" |

## 话术 2：T-3 周跟进未确认者（销售总监打）

**前提**：T-4 周邀约后，约 30-50% 老板未明确确认。

```
张总好，李 XX 啊（销售总监 A）。
上周我们老板打过电话，说 6.11 那个老板局——
这两天我整理实到名单，所以来跟您再确认一下。

到目前确认到的有 [列 4-5 位老板的名字]，
您有没有时间？您来的话我们这边就给您留位置了。

如果您临时有事，您也可以让 X 副总过来听听
（仅限您不在的备用方案，正常我们只请老板）。
```

**话术核心**：
- **报名单**：让对方看到"圈内人都来了"
- **预占位**：把"邀请"变成"已留位置"
- **退而求其次**：副总作为备份，但仍强调"只请老板"

## 话术 3：T-3 周由灯塔厂老板亲自致电（最高招）

**前提**：你已经签下 1 家灯塔厂，灯塔厂老板和邀约老板有交集。

让灯塔厂老板亲自打电话：

```
张总你好，我是 XX 钢管科技的 X X X。

我跟你说个事——6.11 在佛山有个小局，
是 XXX（你方公司）那边组织的，
我也去，给大家讲讲我这一年用他们系统的实情。

你来吗？我跟他们说留个位置给你。
```

**这一招的杀伤力**：
- **同行老板的话比销售强 10 倍**
- 灯塔厂老板的"现身说法"已经种草，邀约就是临门一脚
- 老板之间互相给面子，**拒绝率从 50% 降到 10-20%**

## 话术 4：T-2 周短信 + 微信二次确认

**前提**：实体邀请函通过快递送达。

**短信文案**（统一）：

```
【XXX 公司】张总您好！6.11(周四)17:30 佛山乐从老板局，
您的位置已预留。实体邀请函今天快递到您办公室，
请您查收。任何问题：李 XX 138-XXXX-XXXX
```

**微信文案**（个性化）：

```
张总好，
6.11 老板局实体邀请函我快递给您了，明后天到。

最新实到名单更新：
- XX 钢管科技 X 总（灯塔厂主讲）
- XX 协会 X 秘书长
- XX 钢铁 X 总
- ……（共 8 位老板已确认）

您还有 1 周时间，期待您。

P.S. 当天 17:30 集合，开车 / 高铁 都可以提前告诉
我们安排接送。
```

**关键技巧**：
- **更新名单**：让老板看到"圈子在确认"
- **解决细节**：交通安排（接送）降低决策门槛

## 话术 5：T-1 周最终电话确认（老板自己打）

**前提**：T-1 周必须**老板亲自再打一遍**。

```
张总好，李 XX 啊（老板）。
明天 6.11 老板局，我亲自再跟您确认下。

我这边您的位置已经留好了，您席位在主位旁边。
当天 17:30 我亲自到酒店门口接您。
您是开车来还是高铁来？

[听对方回答]

好的张总，明天见！
```

**心理学**：老板亲自二次确认 = **不可拒绝信号**。  
**到场率从 80% 拉到 95%**。

# 第五部分：邀约的"7 个细节"（决定成败）

## 5.1 时间细节
- 邀约时间：**周一-周三 14:00-17:00 最佳**（老板心情松、未到下班）
- 避免：周五下午 / 周末（"明天再说"陷阱）
- 避免：上午 8:00 前 / 晚上 20:00 后（不专业）

## 5.2 称呼细节
- 第一次：「X 总好」
- 熟一些：「X 哥」（仅限同辈或熟客）
- 极熟：「X 总，老李啊」（用自己外号）

## 5.3 微信细节
- **绝不群发**——任何形式都不行
- 每条微信必须**带名字 + 个性化内容**
- 凌晨 / 周末发：永远等到工作时间

## 5.4 邀请函细节
- **实体版必须老板手写一句话**（如"诚挚邀请您 — 李 XX"）
- 实体版用 EMS 寄送（不是普通快递）
- 实体版到达后 1 小时内**销售总监打电话确认收到**

## 5.5 礼品细节（不必送邀约期，老板局当天送）
- 不送高价值（避税务争议）
- 不送有 LOGO 的（土）
- 推荐：**精装版行业白皮书**（一定要有老板自己的姓名烫金）+ 一盒好茶

## 5.6 接送细节
- **必须有专车接送**（即使老板说自己开车）
- 司机提前 30 分钟到酒店等
- 司机也要培训：知道老板姓什么、不要乱说话

## 5.7 备选老板细节
- 邀约 12 位 → 实到 8-10 → **必须备 3-5 位备选**
- T-1 周如有人临时不来，**立刻启动备选**
- 备选老板：**事后单独发微信感谢**，下次老板局优先

# 第六部分：实到 8 老板后的"现场分组"

为避免冷场 / 内卷 / 竞品冲突：

## 6.1 桌次安排
- **大圆桌 1 张，10-12 人**（不要分桌！）
- 老板（CEO）坐正主位，灯塔厂老板坐主宾
- 其他老板按"业务互补 / 性格相似"原则排
- **协会秘书长**（如有）坐副主位

## 6.2 座位铁律
- 同业竞品**绝不同桌相邻**
- 内向老板坐两个外向老板中间（自然破冰）
- 二代接班人单独安排"二代联谊小区"（如 ≥ 3 位）

## 6.3 现场摄影摄像
- 摄影师**穿正装，不要扛大设备**
- 重点抓拍：老板对话、合影、灯塔厂老板讲话
- **当晚就要剪好"15 秒精彩集锦"**，发朋友圈

# 第八部分：常见问题

## Q1：第一次办老板局没经验怎么办？
**A**：
- 老板亲自全程把关
- 找 1 位**有经验的会议公司**协助场地 + 流程（不让他们参与销售）
- 第一场宁可"小而美"，**8 位老板比 12 位更好**

## Q2：邀约率低（< 50%）怎么办？
**A**：
- **检查名单质量**：是不是 30 家清单关系基础太弱？
- **检查邀约话术**：是不是讲得太"销售"？
- **请灯塔厂老板帮邀**：转化率立刻翻倍
- **降低门槛**：从"老板专属"放宽到"老板 + 1 位副总"

## Q3：同业老板互相不认识怎么办？
**A**：
- **主持人破冰**：每位老板自我介绍 90 秒（强制）
- **席间游戏**：让每位老板分享"今年最痛的一件事"
- **协会秘书长**：作为"中立第三方"调度气氛

## Q4：竞品厂商混进来怎么办？
**A**：
- **严格名单审核**：每位邀约前先核实公司 / 业务
- **现场签到**：发现混入立刻请走（话术：「不好意思，今天是封闭老板局」）
- 备选措施：每位老板进场前**签 1 份保密承诺**（不强制）

## Q5：老板局结束后老板态度冷淡怎么办？
**A**：
- 复盘当晚：是不是销售在场上"卖东西"了？
- 当晚是不是讲超时了？我方 ≤ 15 分钟铁律
- 是不是同业气氛尴尬？
- **教训反向用**：第二场全部修正
