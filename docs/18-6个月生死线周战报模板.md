# 6 个月生死线 · 周战报模板（Plan A 跟踪工具）

> 配套 Excel：`tools/周战报_6个月生死线跟踪表.xlsx`  
> 用途：每周一战报会的标准化输入；6 个月一次决策依据  
> 核心信条：**没有数字就没有判断**

---

# 第一部分：周战报的"3 个铁律"

## 1.1 时间铁律
- **每周一 09:00-09:30**（30 分钟，不能拖到 1 小时）
- 老板亲自主持
- 全员到（销售 / 售前 / 实施 / 市场 / 运营 / 行政）
- 远程开也行，但**镜头必须开**

## 1.2 内容铁律
- **5 个数字 + 3 个故事 + 1 个决策**
- 5 个数字：上周关键 KPI 实际/目标
- 3 个故事：1 个亮点客户 + 1 个失败客户 + 1 个学到的事
- 1 个决策：本周最重要的 1 件事是什么

## 1.3 输出铁律
- **每周战报必须发到全员群** + 老板个人备份
- **每月一次月度战报**（合并 4 周）
- **每季度一次季度战报**（合并 12 周，对照生死线）

# 第二部分：每周战报标准结构（5+3+1 模型）

## 2.1 5 个核心数字

每周必报：

| # | 指标 | 计算方式 | 报告方 |
|---|---|---|---|
| 1 | **新增线索数** | 当周地推 + 老板局 + 合伙人 + 转介绍 + 内容 | 销售运营 |
| 2 | **新增 POC 数** | 当周新启动 POC | 销售总监 |
| 3 | **新增签约数** | 当周新签合同 | 销售总监 |
| 4 | **当周回款** | 当周到账金额 | 财务 |
| 5 | **新增合伙人数** | 当周通过实名认证的合伙人 | 销售运营 |

## 2.2 3 个故事

讲故事比讲数字重要——但只能 3 个：

### 故事 1：**亮点客户**
- 公司名 + 老板姓名
- 当周发生了什么（如签约 / POC 启动 / 关键见面）
- 关键决策点是什么
- 下周怎么推进

### 故事 2：**失败客户**
- 公司名 + 老板姓名
- 失败原因（价格 / 决策慢 / 关系不到 / 竞品）
- 教训：以后怎么避免
- **不允许只讲"客户没决策"——必须找到我们能控制的因素**

### 故事 3：**学到的事**
- 团队当周学到的 1 件事（销售技巧 / 行业知识 / 老板心态）
- 由 1 个具体的人讲（轮流，不要老板讲）
- 沉淀到话术库 / SOP 中

## 2.3 1 个决策

老板在战报会末做出的 1 个决策，必须满足：
- **具体**：不是"加强营销"，而是"把 X 客户的 POC 改为 0 首付模式"
- **可执行**：有责任人 + 时间节点
- **可追溯**：写到下周战报"上周决策回顾"

# 第三部分：6 个月生死线 5 个核心 KPI

每周战报必看的"生死线 KPI 进度"：

| KPI | 6 月生死线 | 当前周达成 | 缺口 | 风险等级 |
|---|---|---|---|---|
| 灯塔厂签约 | ≥ 3 家 | | | 🟢/🟡/🔴 |
| 灯塔厂上线见效（公开案例） | ≥ 1 家 | | | |
| 老板局举办 | ≥ 1 场 | | | |
| 月签客户（不含灯塔厂） | ≥ 3 家 | | | |
| 累计回款 | ≥ ¥30 万 | | | |

**风险评级规则**：
- 🟢 当前进度 ≥ 时间线（如第 12 周累计 ≥ 8 家灯塔候选拜访）
- 🟡 进度落后 1-2 周
- 🔴 进度落后 ≥ 3 周 → 立刻调整打法

# 第七部分：第 12 周（W12）生死线评估会

> **这是 6 月生死线评估的"主战场"**

## 7.1 评估会议安排
- **时间**：2026.07.06（周一）09:00-12:00
- **参加人**：老板 + 财务 + 2 销售总监 + CTO + HR + 市场
- **决策权**：老板拍板
- **输出**：未来 3 个月（Q3）作战决议

## 7.2 评估会 5 步流程

### 第一步（30 min）：数据评审
- 由销售运营经理出 12 周完整数据
- 5 个核心 KPI 达成度逐项核
- 现场打分：S（≥80%）/ A（50-80%）/ B（<50%）

### 第二步（30 min）：故事复盘
- 每个销售总监 / 售前 / 实施轮流讲 3 个故事
- 老板提炼"我们对了什么、错了什么"

### 第三步（30 min）：财务核对
- 累计投入 vs. 累计回款
- 现金流状况
- 是否需要融资

### 第四步（45 min）：Plan 决策
- 按 docs/14 的决策树：Plan A 续打 / 转 B 加速 / 转 C 聚焦
- **必须有书面决议，全员签字**

### 第五步（15 min）：Q3 作战日历输出
- 7-9 月每周固定动作
- 关键节点：第 2 场老板局、第 5 家灯塔厂、新签 ≥ 25 家
- 输出 13-24 周作战日历

## 7.3 评估会"红线条款"

| 条款 | 触发时 |
|---|---|
| 立刻换销售总监 | 该总监 12 周 0 签约 + 0 灯塔厂 |
| 立刻换 CMO（如已有） | CMO 6 月 KPI < 60% |
| 立刻启动融资 | 现金 < 3 月运营成本 |
| 立刻关 1 个客群 | 该客群 12 周 0 签约 |
| 立刻关 1 个城市 | 该城市无销售产出 |

> **狠 = 对公司负责，温吞 = 拖死大家**

# 第八部分：常见问题

## Q1：周战报会被销售当成"考核会"，大家不敢讲实话怎么办？
**A**：
1. **老板第一个讲自己的"上周失败"**——示弱降压
2. **失败案例不追责，只追教训**
3. **有时候让销售运营经理来主持**（弱化老板权威感）

## Q2：每周 30 分钟讲不完怎么办？
**A**：
- 每个数字 / 故事 / 决策 **各 5 分钟严格控时**
- 用秒表计时
- 长话题留到 1 对 1 沟通
- 30 分钟就是铁律——讲不完说明准备不充分

## Q3：数字一直不达标，每周战报会变批斗会怎么办？
**A**：
- 不要让战报会变成 "为什么不达标" 的追问
- 改成 "下周做什么"
- 连续 3 周不达标 → **暂停战报，开战略会**

## Q4：没人想做记录员怎么办？
**A**：
- 设立"**周战报记录员**"角色，**给奖金 ¥500/月**
- 销售运营经理兼任最佳

## Q5：远程怎么开战报会？
**A**：
- 必须开镜头
- 必须共享屏幕（Excel 周战报模板）
- 销售运营提前 1 小时收齐数据填好

# 第九部分：周战报的"反模式"（千万别做）

| ❌ 反模式 | 后果 |
|---|---|
| 战报变 PPT 汇报 | 1 小时讲不完 |
| 老板单方面讲话 | 团队失去主动性 |
| 数据为主、故事缺失 | 看不到客户温度 |
| 责备某个人 | 团队不敢真讲 |
| 决策不写下来 | 下周不了了之 |
| 远程战报关麦克风 | 无效会议 |
| 数字"修正一下" | 一票否决，开除 |

# 给老板的 5 句话

1. **数字不会撒谎，但人会**——周战报是把数字摆在桌上的工具
2. **30 分钟的纪律 > 3 小时的废话**——超时即失败
3. **失败案例的价值大于成功**——每周必讲 1 个，沉淀到话术库
4. **决策要写下来**——下周回看，否则没意义
5. **W12 生死线不能"温柔"**——该换人换、该转 Plan 转，对公司负责
