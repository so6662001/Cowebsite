# 行业熟人引荐路径模板（30 家清单的"破冰武器库"）

> 配套 docs/16 灯塔厂调研评分表使用  
> 用途：把"我们和这家厂没关系"变成"有 1-2 步关系路径"  
> 核心信条：**钢铁行业不存在"陌生客户"，只存在"还没找到的关系"**

---

# 第一部分：6 类核心引荐人（按可用度排序）

## 1.1 引荐人价值矩阵

| 类别 | 数量级 | 引荐成功率 | 关系成本 |
|---|---|---|---|
| ① 现有客户老板 | 5-15 个 | **70-85%** | 0（已是关系） |
| ② 设备厂商销售 | 50-200 个 | 50-70% | 利益分配 |
| ③ 行业协会 / 商会 | 5-15 家 | 40-60% | 协会会费 / 赞助 |
| ④ 退休国企 / 大集团高管 | 10-30 人 | 60-80% | 顾问费（¥5-15K/月）|
| ⑤ 上游钢厂销售 | 30-50 个 | 30-50% | 维护关系 |
| ⑥ 行业媒体 / 财经记者 | 5-10 人 | 20-40% | 软文 / 广告 |

> **铁律**：30 家灯塔厂候选 = **6 类引荐人 × 多路径并行**，不指望某一类把所有事干完。

## 1.2 ① 现有客户老板（最强武器）

### 适用
- 你已签约的客户里**老板满意度 ≥ 8 分**的
- 灯塔厂候选客户

### 引荐路径
```
你（销售总监 A） → 现有客户 X 总 → 候选客户 Z 总
```

### 启动话术（销售总监打给现有客户）

```
X 总好，李 XX。

跟您打个不情之请——
我们想拓展邯郸的钢管厂客户，
您圈里有没有比较熟的钢管厂老板？
如果有 1-2 个比较合适的，
您能不能介绍我们认识一下？

我承诺：
1. 不打扰您；只是您给个微信我自己加；
2. 如果对方签约，我们给您 5% 返佣（或抵您家月租 10%）；
3. 您介绍 3 家，我们送您今年的"行业 VIP 顾问席位"。
```

**关键**：**不直接说"想约饭"**——先要微信，第二次再约见面。

### 转化率提升技巧
1. **请客户老板代发文章 / 案例**（不直接打电话）→ 候选客户主动来问
2. **同行论坛 / 协会场合**安排"巧遇"
3. **客户聚会带 1-2 位候选客户老板**

## 1.3 ② 设备厂商销售（最广武器）

### 适用
- 轧机厂 / 焊管设备厂 / 镀锌线厂 / 纵剪机厂 / 检测设备厂
- 平日跑钢厂老板的销售

### 引荐路径
```
你（销售总监 A） → 设备厂销售老张 → 候选客户 Z 总（设备客户）
```

### 启动动作（找 5 家设备商建立战略合作）

#### Step 1：找到 5 家设备厂的"销售总监 / 大区经理"
- 钢管行业：金恒丰 / 武汉重型 / 国机重装 等
- 镀锌行业：宝钢工程 / 中冶 / 五矿 等
- 开平 / 纵剪：浙江尚艺 / 山东富晨 等

#### Step 2：3 步建立合作

**Step 2.1：上门拜访（不卖东西）**
```
您好，我是 XX 数字化系统的李 XX。
我们的客户基本和你们的客户重叠（钢管厂/镀锌厂）。

我想跟您聊一个互补合作：
您卖设备，我卖系统。客户买完您的设备，
就会想"怎么把这条线管好"——这正是我们的强项。

我不抢您的客户，反过来——我们的客户上系统时，
也会有"换设备"的需求，我们也可以给您介绍。

您觉得这种合作有意思吗？
```

**Step 2.2：签互荐协议**
- 我方推荐 → 设备商成交：**返佣 3-5%**
- 设备商推荐 → 我方成交：**返佣 20%（实施费）+ 10%（月租 12 月）**

**Step 2.3：联合活动**
- 联合参展（共享展位）
- 联合白皮书 / 案例
- 互相参加对方的客户活动

### 引荐成功的关键
- **设备商最在意的是"自己的客户被服务好"**——你必须证明你能做好
- **第 1 单返佣必须及时打款**——后续他才有动力推

## 1.4 ③ 行业协会 / 商会（背书武器）

### 适用
- 中国钢铁工业协会、中国钢管协会、各地冶金 / 钢铁协会
- 各地工商联钢铁分会、商会

### 引荐路径
```
你 → 协会秘书长 → 协会理事长（候选客户老板们）
```

### 启动动作

#### Step 1：每个核心产业带签 1 家协会战略合作
- 河北钢铁工业协会
- 山东钢铁工业协会
- 浙江钢铁工业协会
- 广东钢铁工业协会
- 天津钢铁工业协会

#### Step 2：合作模式

**模式 A：协会副理事长单位**（最有效）
- 缴纳协会副理事长会费（¥3-10 万 / 年）
- 协会大会 / 论坛**主推位**
- 协会秘书长**推荐你给会员**

**模式 B：行业研究合作**
- 联合发布行业白皮书
- 联合举办行业大会
- 协会秘书长担任"特邀顾问"

**模式 C：会员折扣**
- 协会会员签约**送 8 折**
- 给协会**5% 收益**（作为协会服务费）

### 关键人物：协会秘书长
- 协会真正决策人 = 秘书长（不是名义上的会长）
- 秘书长一般任期 5-10 年，关系长期
- **必须老板 / 销售总监级别亲自维护**
- 节日礼品 / 协会活动赞助 / 个人尊重

## 1.5 ④ 退休国企 / 大集团高管（顾问武器）

### 适用
- 鞍钢 / 宝钢 / 沙钢 / 友发 等国企或上市集团**退休 5-15 年**的副总 / 总工
- 这类人**圈子最广**，且无利益冲突

### 引荐路径
```
你 → 退休 X 老总（你方"行业顾问"） → 候选客户 Z 总（X 老总的徒弟 / 老朋友）
```

### 启动动作

#### Step 1：列名单（5-10 位）
- 通过协会推荐
- 通过现有客户老板推荐
- 通过 LinkedIn / 行业网站搜

#### Step 2：聘任"行业顾问"
- **顾问费**：¥5,000-15,000 / 月（不要免费，免费没动力）
- **职责**：每月 1-2 次推荐 + 4 次活动出席
- **奖励**：成功签约**额外 8% 实施费 + 5% 月租 12 月**

### 顾问的"软价值"
- 现身说法（"我以前在 XX 国企就用类似系统"）
- 为你方公司**做行业背书**
- 帮你方培训销售（行业认知）

### 顾问招聘话术
```
X 老总好，我是 XX 数字化的李 XX。

我们想聘您做"行业战略顾问"——
不需要您做具体事，只需要您一年里：
1. 帮我们认识 10-15 位钢厂老板朋友；
2. 出席 4 次我们的客户活动；
3. 给我们指导一下行业判断；

报酬是 8000/月 顾问费 + 成单分成。

您觉得有兴趣吗？
```

> **铁律**：**不要请在职的国企高管**（合规风险）；只请退休 ≥ 5 年的。

## 1.6 ⑤ 上游钢厂销售（关系武器）

### 启动动作

- **私人关系维护**：节日 / 礼品 / 偶尔小局
- **互相帮忙**：你帮他打听其他客户信息，他帮你引荐
- 引荐成功**送红包**（市场惯例 ¥5,000-20,000）

> **注意**：保持私人关系，避免商业化（合规风险）。

# 第二部分：30 家清单的"引荐路径分配"

## 2.1 路径优先级
对每家候选客户，按下面顺序找路径：

```
路径 1：现有客户引荐 → 路径 2：设备厂商引荐 → 路径 3：协会引荐
   ↓                       ↓                      ↓
路径 4：退休高管引荐 → 路径 5：上游钢厂引荐 → 路径 6：陌生开拓
```

## 2.2 30 家清单 × 6 类路径（评估表）

| 候选客户 | 路径 1（现有客户） | 路径 2（设备商） | 路径 3（协会） | 路径 4（退休高管） | 路径 5（上游钢厂） | 路径 6（陌生） |
|---|---|---|---|---|---|---|
| 客户 A | ★★★ | ★ | ★★ | ★★ | ★ | ★ |
| 客户 B | ☆ | ★★★ | ★★ | ☆ | ★ | ★ |
| ...... | | | | | | |

**评分规则**：
- ★★★（强）：直接关系，1 步即可
- ★★（中）：需要熟人引荐
- ★（弱）：路径存在但不强
- ☆（无）：完全无路径

**铁律**：**30 家清单中至少 25 家**必须有 1 个 ★★ 以上的引荐路径，否则候选名单质量不够。

# 第三部分：从"关系"到"会面"的 4 步标准化流程

## 3.1 第 1 步：取得引荐人微信（不要电话）

```
李 XX [我方销售总监]：
X 总，麻烦您把 [候选客户老板] 的微信发我，
我直接加他，不打扰您。
```

> 微信比电话靠谱：候选客户能先看你朋友圈，决定要不要回。

## 3.2 第 2 步：加微信（不要 BD 模板话术）

加微信验证语：
```
我是 XXX，X 总（引荐人）介绍。
他说您是邯郸钢管行业老法师，
特别想跟您学习一下。
```

## 3.3 第 3 步：聊 7-15 天再约见面

**前 3 天**：朋友圈互动（点赞 + 偶尔评论）
**第 4-7 天**：发 1-2 篇行业文章 / 案例（不发产品）
**第 8-10 天**：发 1 段灯塔厂客户老板视频（埋钩子）
**第 11-15 天**：约见面

约见面话术：
```
X 总，下周三我去邯郸办点事，
方便去您厂里坐坐吗？带本《钢管行业数字化白皮书》给您看看。

不耽误您时间，1 小时左右。
```

## 3.4 第 4 步：第一次见面（带 5 件物料）

| 物料 | 用途 |
|---|---|
| 行业白皮书（精装版） | 权威感 |
| 灯塔厂案例 PDF | 同行背书 |
| 健康度自评表 | 互动工具 |
| 茶叶礼盒（≤ ¥300） | 礼貌 |
| 名片（写"行业顾问"） | 不卖货感 |

> **第一次见面的目标 = 让对方愿意见第二次**。  
> 不报价 / 不卖系统 / 只听他讲。

# 第四部分：3 个真实场景案例

## 案例 1：邯郸 XX 焊管厂（评分 79 分，A 级）

**路径分析**：
- 路径 1（现有客户）：☆ 无
- **路径 2（设备商）：★★★ 强**（轧机厂老张是介绍人）
- 路径 3（协会）：★★ 中（邯郸钢管协会理事，需协会引荐）

**实际执行**：
- W2 周三：销售总监 A 联系轧机厂老张
- 老张当天发邯郸钢管厂 X 总微信
- W2 周五：销售总监加微信
- W3 周一-周三：朋友圈互动 + 发案例
- W3 周四：约 W4 周二上门
- W4 周二：上门 1.5 小时，填健康度自评，留下《邯郸 XX 钢管诊断初稿》
- W5 周一：约 3 天工作坊
- W6：签 POC 协议

**关键 take-away**：设备商引荐 + 销售耐心 + 不卖货感 = 3 周内推进到 POC。

# 第六部分：常见问题

## Q1：现有客户不愿意介绍怎么办？
**A**：
- 先**问原因**：是怕得罪同行？还是怕影响关系？
- 提出**匿名介绍方案**：只发微信不强制对方说"是 X 总介绍的"
- 提**双倍返佣**作为激励

## Q2：设备商要求高返佣（>30%）怎么办？
**A**：
- **不接受**——设备商引荐的客户质量参差不齐，高返佣意味着低利润
- **改成结构化激励**：基础 20% + 每签 3 单加 5%
- **加非现金价值**：联合大会演讲 / 共享白皮书署名

## Q3：退休高管"挂名不干事"怎么办？
**A**：
- 顾问合同写**月度任务清单**：至少推荐 X 个、出席 Y 次
- 考核制度：连续 2 月 0 推荐 → 顾问费暂停
- 不行就换人，**别讲面子**

## Q4：协会秘书长不肯独家合作怎么办？
**A**：
- 不要独家——用**优先合作 / 主推位**等"非独家"合作方式
- 给会员折扣，让秘书长有"为会员谋福利"的政绩

## Q5：30 家里有 5 家完全找不到引荐路径怎么办？
**A**：
- 把这 5 家**降级到 B 级**（不是 30 家清单的核心）
- 用陌生开拓（地推 / 老板局邀约 / 内容引流）
- **不要硬上**——硬上的转化率 < 5%

# 给老板的 5 句话

1. **钢铁行业不存在"陌生客户"**——只是还没找到的关系
2. **30 家清单 × 6 类路径**并行，不指望一类路径解决所有
3. **第 1 个月把 5-10 个引荐人盘起来**（顾问费 / 协会会费现在投，6 月后赚回 10 倍）
4. **退休国企高管 = 钢铁行业最被低估的"圈子杠杆"**——花 ¥10K/月 撬动 50 个老板
5. **关系是"前置投资"，不是"事到临头才找"**——平时不维护，要用时找不到
