# 合伙人启动话术 · 前 5 位老客户专用

> 配套 docs/04 合伙人小程序 PRD + docs/11 合伙人招募策略  
> 用途：W2 启动期，从现有满意客户里转化前 5 个合伙人  
> 核心信条：**前 5 个合伙人的质量决定后 100 个合伙人的转化率**

---

# 第一部分：前 5 个合伙人选谁

## 1.1 候选人画像（5 必要）

| 必要 | 标准 |
|---|---|
| ✅ 已签约 ≥ 3 个月 | 至少经历过 1 个完整季度 |
| ✅ 老板对系统满意度 ≥ 8 / 10 | 否则推荐别人会反向坏口碑 |
| ✅ 老板有同行人脉（≥ 50 个钢厂老板微信） | 决定推荐量 |
| ✅ 老板讲话有信用、不夸大 | 不能找"江湖派" |
| ✅ 与你方公司关系 ≥ 1 年 | 信任基础够 |

## 1.2 「3 不要」（直接淘汰候选）

| 不要 | 原因 |
|---|---|
| ❌ 还在合同期内有未付款 | 可能利用推荐"抹账" |
| ❌ 老板有诉讼 / 失信记录 | 反向损害品牌 |
| ❌ 老板对系统有抱怨（任意 1 处未解决）| 推荐时会"吐槽你" |

## 1.3 5 个候选人的"组合策略"

最佳组合：
- **2 位 S 级灯塔厂老板** —— 行业地位最高，引荐成功率 70%+
- **2 位 A 级标杆客户** —— 影响力中等，引荐稳定
- **1 位 B 级"老朋友"客户** —— 关系基础好，愿意帮忙

**铁律**：5 位中**至少 1 位是您（老板）的私人朋友**——他能"破冰"。

# 第二部分：启动前 5 位合伙人的"5 步流程"

## 第 1 步：精挑名单（销售总监做）

### 评分维度（5 维 × 1-5 分）
| 维度 | 权重 | 说明 |
|---|---|---|
| 老板对系统满意度 | ×3 | NPS ≥ 8 才入选 |
| 老板对您的信任度 | ×3 | 1 年以上深度关系最佳 |
| 老板同行人脉广度 | ×2 | 50+ 钢厂老板微信 |
| 老板出镜 / 活跃意愿 | ×2 | 是否爱出席行业活动 |
| 与您（老板）私交 | ×1 | 加分项 |

**总分 ≥ 35（满分 50）才入前 5 名单**。

---

## 第 2 步：第 1 次电话（不是要推荐，是"听反馈"）

### 通话脚本（5-8 分钟）

```
X 总好，李 XX。

打这通电话主要是听您聊聊——
您用我们系统 [X 个月] 了，
您觉得最值的是什么？最想吐槽的是什么？

[听对方讲，不打断，每讲完一段说"嗯，有道理"]

我跟您说实话——
我们公司今年要扩张到 [新城市 / 新客群]，
特别想听听老客户的真实反馈。

您说的这些 [总结 1-2 条]，
我会带回公司讨论。

下周如果有机会，我专门去您那儿一趟——
当面聊 30 分钟，您看周二还是周三方便？
```

### 第 1 次电话的目标
- ✅ 听到 ≥ 2 个客户原话（用于第 2 步）
- ✅ 约下次见面
- ❌ **不要在第 1 次电话提"推荐"**

---

## 第 3 步：第 2 次见面（1.5 小时）—— 真正启动

### 见面前准备
- 带 1 份精装版《行业白皮书》
- 带 1 份**专属的"客户感谢报告"**（30 天 / 90 天数据 + 老板照片）
- 带 1 份《老客户合伙人招募说明》
- 带 1 盒高端茶（≤ ¥500）

### 见面前自检 5 个问题
1. 我能讲出这家客户**3 个具体见效场景**吗？
2. 我能讲出这家老板**最自豪的 1 个标签**吗？
3. 我能讲出**他圈里 2-3 个潜在候选老板**的名字吗？
4. 我准备给他**什么具体激励**？
5. 我能讲清楚**他帮我做什么**（仅 3 件事）？

### 见面 1.5 小时的标准流程

#### 0-15 分钟：寒暄 + 感谢
```
X 总，最近忙吧？我特地来看您。

[递上感谢报告]
这是我们做的"X X 钢管 90 天数据感谢报告"，
您看 [指着数据] 这 3 项指标都比我们当初承诺的还好。

我跟我们老板说——
没有您去年敢"试这第一家"，我们这套系统都跑不出来。
您是真正的"开荒者"。

[让对方感受到被特别对待]
```

#### 15-45 分钟：聊行业 + 聊圈子（不卖货）
```
X 总，您最近有没有跟同行聊过？
我感觉今年钢管行业越来越分化——
您是怎么看的？

[听对方讲]

[根据他的话顺着聊]
您说的 X 总（同行老板）我听说过，
他厂里现在情况怎么样？

[让对方主动讲圈子里的事]
```

#### 45-75 分钟：核心动作 —— 邀请做合伙人

```
X 总，我跟您说个不情之请——

我们公司今年要做一件事，
叫"老客户合伙人计划"。

意思是：
- 您介绍同行给我们，我们成单了，您拿返佣；
- 您不主动卖东西，您只需要"如果同行问您怎么管理，您就推荐一下"；
- 是不是合伙人都没关系，但合伙人能拿到 3 件特别的东西。

[停顿，等对方好奇]

具体怎么操作呢？

▼ 三件事您来做：
1. 把您觉得"该上系统"的同行老板，介绍我们认识；
2. 同行老板如果来问您"X 总你那套系统怎么样"，
   您讲讲真实的话就行（不必夸我们）；
3. 一年偶尔出席 1-2 次老板局，给同行讲讲您的经验；

▼ 三件事我们送给您：

第一件：返佣
- 介绍 1 家成功签单 → 实施费 10% 现金
- 您也可以选"抵扣自家月租"——抵扣是双倍（20%）
- 后 12 个月月租，再返 5%

第二件：升级
- 介绍 3 家 → 您家系统免费升级到旗舰版（市价 12 万）
- 介绍 5 家 → 终身月租 7 折

第三件：地位
- 介绍 5 家 → 授予"行业数字化共建伙伴"称号
- 联合署名《行业白皮书》
- 行业大会有 VIP 席位

[停顿，看对方反应]
```

#### 75-90 分钟：处理异议 + 锁定行动

##### 常见异议 1：「我跟同行讲不太合适，怕关系破坏」
**话术**：
```
X 总，您完全不需要主动推销——
我们也不是让您"销售"的角色。

您只需要：
- 平时不主动提；
- 同行问您"你那套怎么样"，您讲实话；
- 偶尔有合适的，给我们个微信就行。

我们不会用您的名字到处宣传——
保护您的关系，是我们最大原则。
```

##### 常见异议 2：「返佣会不会太敏感了」
**话术**：
```
X 总，我特别理解。
其实"返佣"的写法在合同里——
是"市场推广服务费"，您可以选：
- 转您对公账户（开 6% 增值税票）；
- 抵扣自家下月月租（双倍）—— 这个最简单；
- 转您指定的家人 / 助理账户（少数人选）；

您怎么舒服怎么来，我们都行。
```

##### 常见异议 3：「我先想想吧」
**话术**：
```
X 总，没问题。我把"老客户合伙人手册"留给您 [递实体版]。

但我有 1 件事想请您先做：
不用决定要不要做合伙人，
就先告诉我您觉得**圈子里 2-3 位"该上系统"的同行老板名字**——
就当帮我做做行业调研。

我们绝对不会用您的名字直接联系他们。
您看可以吗？
```

##### 锁定行动：3 选 1
让对方现场选 1 件事：
- A：「您给我 2-3 位同行老板的微信，我自己加，不打扰您」
- B：「您直接发个微信群，把您和我都拉进去，破冰一下」
- C：「您下周帮我打个电话给 X 总，铺个垫」

**铁律**：90 分钟见面后，**必须有 1 件具体行动**。

# 第八部分：常见问题

## Q1：现有客户少，找不到 5 个合伙人怎么办？
**A**：
- **降低门槛**：从 3 个开始也行
- **挖"待签"客户**：报价中的客户也可"预合伙人"
- **退路**：聘请退休国企高管做"行业顾问"补缺

## Q2：合伙人不愿意签实名协议怎么办？
**A**：
- **简化协议**：1 页 A4 + 必要条款 5 条
- **强调保密**：合伙人身份不公开
- **试用期**：3 个月观察期，达标转正

## Q3：合伙人推荐的客户被销售搞砸了怎么办？
**A**：
- **赔礼**：销售总监带礼品上门赔礼
- **补偿**：给老合伙人额外补偿（红包 + 升级权益）
- **复盘**：销售内部复盘，避免重蹈

## Q4：合伙人之间撞单（推荐同一个客户）怎么办？
**A**：
- **首次提交者获归属**——明文规定
- **30 天内未推进**自动释放
- **争议**：销售总监 + 老合伙人共同决定

## Q5：合伙人觉得返佣"算账不清"怎么办？
**A**：
- **每月推送返佣账单**（微信 + 邮件 + 小程序）
- **争议处理**：48 小时内响应
- **第三方仲裁**：协会秘书长可作为仲裁人

# 给老板的 5 句话

1. **前 5 个合伙人决定后 100 个的转化率**——选错 1 个，整个系统污染
2. **第 1 次见面不要谈推荐**——先听反馈、建信任
3. **返佣 + 升级 + 地位 三件套并用**——单纯返佣留不住高价值合伙人
4. **每月 1 次电话回访**——合伙人是"运营"出来的，不是"招"出来的
5. **第 1 笔返佣 7 天内必须打款**——用真金白银建信任，是最便宜的营销
