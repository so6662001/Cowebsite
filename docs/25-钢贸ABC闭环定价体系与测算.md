# 第二部分：你原方案 3 个需要重新设计的细节

## 2.1 ⚠️ 细节 1：「线索费」会被钢贸商抗拒

**你的原方案**：A 闭环收"有效线索费"

**问题**：
- 钢贸商对"按线索付费"的接受度**远低于钢厂**——钢贸商每天接 50-200 个询价，按线索付一周就吃光利润
- 找钢网早期试过"线索付费"，后来全部改成"会员制"

**修订建议**：
- ❌ 不要"有效线索费"
- ✅ 改成"**会员展示费 + 报价工具订阅**"为主，**抢线索靠"信用积分"**（C 闭环带过来）

## 2.2 ⚠️ 细节 2：「按单量订阅」需要再设计

**你的原方案**：B 闭环收"按账号 / 按单量订阅"

**问题**：
- "按单量"听起来公平，但**钢贸商会人工合并单**逃费
- "按账号"是惯例（SaaS 标准），易理解

**修订建议**：
- ✅ "**按账号**"为主（每用户 ¥X / 月）
- ✅ "**按单量阶梯**"为辅（包月不限，超量阶梯加价 — 但加价很轻）

## 2.3 ⚠️ 细节 3：「信用数据服务」对买家更值钱

**你的原方案**：C 闭环收"高级流量包 + 信用数据服务"

**问题**：
- 信用数据卖给"卖家钢贸商"——他们觉得是"卖给自己用"
- 信用数据真正高价值客户是 **银行 / 保理公司 / 大型买家**

**修订建议**：
- ✅ 信用评分对**钢贸商免费**（但有等级，要努力做才能高）
- ✅ 信用数据**对外卖给银行 / 保理 / 大型买家** ¥5-50 万 / 年
- ✅ 高级流量包**对钢贸商收费**（让信用高的钢贸商优先获曝光）

**关键设计**：
- 单价 ¥1.5-3 / 单 = 钢贸商每单成本千分之零点几（毛利的 1%）
- "提货留痕"价值在**避免扯皮 / 法律凭证**——发生 1 次纠纷就回本

**关键设计**：

- 财务岗必装

## 3.7 产品 6：信用评分（C 闭环 - 内部使用，免费）

**收费模式**：免费 + 等级制

| 评分 | 等级 | 权益 |
|---|---|---|
| 90-100 | S 钻石 | 流量倾斜 +50% / 银行授信通道 / 平台担保高额度 |
| 80-89 | A 黄金 | 流量倾斜 +30% / 银行推荐 |
| 70-79 | B 白银 | 流量倾斜 +10% |
| 60-69 | C 青铜 | 标准流量 |
| < 60 | D 警示 | 流量降权 + 标记"低信用" |

**评分维度**（10 项）：
- 履约率（按时发货）×3
- 对账及时（应收周期）×2
- 客户投诉率 ×2
- 平台月活度 ×1
- 经营年限 ×1
- 注册资本 ×1

**关键设计**：
- **对钢贸商免费**——但他们必须主动经营信用才能高分
- "高分 → 流量倾斜 → 多接生意" → 钢贸商主动用其他付费产品（提货通 / 对账通）才能保持高分

## 4.2 5 层客户的 ARPU 配置（推荐套餐）

### 小微钢贸商（年流水 ≤ ¥3000 万）
- 推荐：标准版 ERP/WMS（¥1,800）+ 现货大厅金卡（¥1,500）= **¥3,300 / 月**
- 年付费 ¥3.96 万 = 流水 1.3‰ — 略超红线，**降配到银卡 ¥500，月费 ¥2,300**
- 实际年付费 ¥2.76 万 ≈ 0.92‰ ✅

### 小型钢贸商（年流水 ¥3000 万 - 1 亿）—— **80% 主流客户**
- 推荐：经营版 ERP/WMS（¥3,000）+ 金卡现货（¥1,500）+ 报价工作台 × 2 用户（¥600）= **¥5,100 / 月**
- 年付费 ¥6.12 万 ≈ 流水 0.6-2‰，部分超线
- 调整：**只买 ERP/WMS + 金卡 = ¥4,500/月**（¥5.4 万/年）

### 中型钢贸商（年流水 ¥1-3 亿）—— **核心客户**
- 推荐：经营版 ERP/WMS（¥3,000）+ 金卡（¥1,500）+ 报价 × 5（¥1,500）+ 提货通标准（¥1,500）+ 对账通 × 2（¥1,600）= **¥9,100 / 月**
- 年付费 ¥10.92 万 ≈ 流水 0.4-1‰ ✅
- 加 C 闭环金卡流量 ¥3,000 = **¥12,100 / 月** = 年 ¥14.5 万 ≈ 0.5-1.5‰ ✅

### 大型钢贸商（年流水 ¥3-10 亿）
- 推荐：旗舰版 ERP/WMS（¥6,800）+ 钻卡现货（¥4,800）+ 报价 × 15（¥4,500）+ 提货大客户包（¥4,800）+ 对账 × 5（¥4,000）+ 金卡流量（¥3,000）= **¥27,900 / 月**
- 年付费 ¥33.5 万 ≈ 流水 0.3-1.1‰ ✅

### 集团客户（年流水 > ¥10 亿）
- 全套 + 定制 = **¥50,000-150,000 / 月**
- 年付费 ¥60-180 万 ≈ 流水 0.3-1.8‰ ✅

# 第九部分：3 个生死攸关的产品决策

## 9.1 决策 1：免费策略多激进？

**两种选择**：
- **温和免费**：现货大厅普通会员免费，其他全部收费
- **激进免费**：ERP/WMS 30 天免费 + 现货大厅永久免费 + 报价工作台 30 天免费

**建议**：**激进免费**——钢贸 SaaS 行业付费转化率约 8-15%，免费用户量越大基数越大。

## 9.2 决策 2：金卡 / 钻卡比例如何把控？

按业务模型：
- 80% 落金卡（你的目标）
- 15% 落银卡 / 钻卡
- 5% 自然升级到大客户包

**对策**：金卡定价**比银卡贵 3 倍但权益贵 5 倍**，自然把人推向金卡。

## 9.3 决策 3：信用评分是否完全免费？

**强烈建议完全免费**：
- 评分系统是流量分发的"裁判"，**不能收费**
- 收费 = 公平性受质疑 = 平台公信力崩
- 收费在"流量包 / 数据服务"上，不在评分本身
