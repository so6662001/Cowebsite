# 上篇：平台顾问招聘 + 7 道面试题 + 培训手册

## 第一章：平台顾问的角色定位

### 1.1 一句话定义
> 平台顾问 = **匹配专家 + 用户陪护 + AI 训练员**

### 1.2 与"销售"的区别（铁律）
| 维度 | 销售 | **平台顾问** |
|---|---|---|
| 目标 | 签单 / 收钱 | **让用户真用** |
| 工作 | 拜访 / 报价 / 收款 | **匹配 / 陪护 / 答疑** |
| 提成 | 实施费 + 月租 | **月活率 + 询价数 + NPS** |
| 性格 | 拼劲 / 抗拒 / 能喝 | **细致 / 耐心 / 懂行** |
| 招聘来源 | 工业销售 | **客服 / 加工配送中心采购员 / 钢贸商内勤** |

### 1.3 平台顾问的"3 重职责"

#### 职责 1：**1 对 N 服务买家**
- 平均配比：1 顾问 : 50-100 个买家
- 服务内容：
  - 注册激活辅导（首次上手）
  - 询价匹配辅导（早期 AI 不准时人工辅助）
  - 答疑（产品问题 / 行业问题）
  - 主动周回访（前 3 月每周 1 次电话 / 微信）

#### 职责 2：**帮 AI 训练匹配**
- 标注每次匹配的"好坏"
- 录入匹配失败原因
- 反馈给产品 / 算法团队

#### 职责 3：**收集用户反馈**
- 每周用户访谈 ≥ 5 个
- 输出《本周用户反馈周报》
- 反馈给产品迭代

## 第二章：7 道核心面试题

### 题 1：「你为什么应聘平台顾问，不去做销售」
**评分**：
- ✅ 优秀：能说"我喜欢深度服务用户，看到用户进步比赚提成更有成就感"
- ⚠️ 合格：能讲个人偏好
- ❌ 淘汰：说"做不了销售退而求其次"

### 题 2：「钢贸 / 加工配送行业你了解多少？」
**评分**：
- ✅ 优秀：能讲出 5-10 个钢材牌号 + 物流流程 + 钢贸商生意逻辑
- ⚠️ 合格：知道大概
- ❌ 淘汰：完全不懂——可培养但成本高

### 题 3：「假如一个买家进来 30 天没询价，你怎么办？」
**评分**：
- ✅ 优秀：
  - 先**电话了解原因**（系统不会用？没采购需求？已用别的？）
  - 不会用 → 1 对 1 演示 / 录短视频教学
  - 没需求 → 朋友圈互动 + 节日问候，等他有需求时第一个想起
  - 已用别的 → 不强推，了解对方好在哪里 → 反馈给产品
- ❌ 淘汰：直接说"那就放弃他"

### 题 4：「AI 推荐了 3 个卖家，买家都说不行，你怎么救？」
**评分**：
- ✅ 优秀：
  - 立刻**人工接手**：在系统外用微信群拉 5-10 个卖家报价
  - 同时**标注 AI 推荐失败原因**：是价格不对？库存对不上？信用有问题？
  - 反馈算法团队
- ❌ 淘汰：说"那是 AI 的问题，我管不了"

### 题 5：「买家说提货通有 bug，你怎么处理？」
**评分**：
- ✅ 优秀：
  - 立刻**电话听用户描述** + **同屏共享看问题**
  - **15 分钟内给临时方案**（如先用 Excel 替代）
  - **24 小时内反馈 bug 修复进度**
  - 修复后**主动通知用户**
- ❌ 淘汰：说"我转给技术，你等通知"

### 题 6：「你怎么收集用户反馈，输出有价值的洞察？」
**评分**：
- ✅ 优秀：
  - 每周**5 个用户深度访谈**（不是问卷）
  - 用**标准模板**（背景 / 痛点 / 当前方案 / 期望 / 抱怨）
  - 每周输出 1 页**用户反馈周报**给产品
  - **追踪反馈→修复**闭环
- ❌ 淘汰：说"用户来问我我就答"

### 题 7：「3 个月你给自己定什么 KPI？」
**评分**：
- ✅ 优秀：
  - 月度服务 50-80 个买家
  - 月活率 ≥ 60%
  - 月询价 ≥ 200 笔（来自我服务的买家）
  - 月度收集 ≥ 20 条用户反馈
  - NPS ≥ 30
- ❌ 淘汰：不愿主动给数字

# 下篇：自营 GMV 操作手册

## 第一章：什么是自营 GMV，为什么必须做

### 1.1 自营 GMV 的本质
> 平台**自己当一部分买家**，主动从平台卖家那里采购钢材，再转手卖给真实买家或自己消化。

**目的**：
- 帮卖家"接到第一单"——心理上证明平台真有用
- 撑起平台 GMV 数字——让其他买家看到"有人在交易"
- 沉淀交易数据——为信用评分 / AI 推荐提供基础

### 1.2 找钢网 / 钢银的真实数据
- 找钢网早期 30-40% 是自营
- 钢银至今仍有 50%+ 自营
- 你应该 **5-10% 自营**（轻资产模式）

### 1.3 不做自营的代价
- 早期卖家没单 → 退出 60-80%
- 早期买家看不到交易 → 不信任 → 退出
- 平台数据"假"——刷单解决不了根本问题

---

## 第二章：自营的"3 种模式"

### 模式 A：直采直销（重，不推荐）
- 平台**真的进货**入库
- 仓储 / 物流 / 资金压力大
- **找钢网早期烧 5 亿才稳住**

### 模式 B：撮合垫付（中，可考虑）
- 平台帮买家**先付款给卖家**
- 买家收到货后再付款给平台
- 平台赚利差 1-2% + 担保费
- 资金占用周期 7-30 天

### 模式 C：自营订单引流（轻，**强烈推荐**）
- 平台**自己当买家**下单（小金额 / 高频次）
- 用平台的内部需求（耗材 / 设备）
- **不是真的为转售，是为撑平台数据 + 帮卖家接单**

---

## 第三章：你应该选模式 C + 模式 B 试点

### 3.1 模式 C 详细操作

**资金需求**：¥50-100 万（前 6 月）  
**操作**：
- 平台公司**真实需要的钢材采购走平台**（如装修钢架、工具用具的钢材消耗）
- 联合**关联公司 / 兄弟公司 / 朋友公司**的采购走平台
- 单笔金额：¥1-10 万（小而散）
- 月度总 GMV：¥50-200 万

**真实价值**：
- 不亏钱（真实采购 + 真实使用）
- 撑起平台 GMV 数据
- 卖家觉得"平台真在交易"

### 3.2 模式 B 试点

**资金需求**：¥300-500 万（前 6 月）  
**操作**：
- 选 5-10 家**信用 A 级买家**（你方钢厂客户的下游 / 平台顾问深度服务的）
- 给他们**"先发货后付款"**的服务（垫付 7-30 天货款）
- 平台抽 1-2% 担保费

**真实价值**：
- 帮 A 级买家"快速拿到货"
- 帮 A 级卖家"快速回款"
- 平台沉淀**真实交易数据**

## 第四章：自营 GMV 的"4 个红线"

| 红线 | 说明 |
|---|---|
| ❌ 不超过总 GMV 的 10% | 超过就是"伪平台"，是自营公司 |
| ❌ 不刷单 | 一次刷单 = 平台公信力崩盘 |
| ❌ 不亏钱做 | 自营要小赚（成本价采购 + 内部使用）或保本 |
| ❌ 不赚卖家钱 | 自营给卖家的价格 = 卖家其他买家平均价 |

## 第五章：自营 GMV 的"3 个增长曲线"

| 阶段 | 自营 GMV / 月 | 占总 GMV 比 | 投入资金 |
|---|---|---|---|
| M1-M3 冷启动 | ¥50-100 万 | 30-50%（初期 GMV 少）| ¥50-100 万 |
| M4-M6 激活 | ¥200-500 万 | 10-20% | ¥150-300 万 |
| M7-M12 规模化 | ¥500-1000 万 | 5-10% | ¥300-500 万 |
| M13+ 成熟 | ¥1000-2000 万 | 3-5%（稳定值） | ¥500-1000 万 |

**资金占用**：注意自营 GMV 是**周转**——同 ¥500 万资金可以做 ¥3000-5000 万 GMV / 年。

## 第七章：5 个执行细节

### 1. 自营订单的"卖家选择"
- 选**平台活跃度高**的卖家
- 选**信用评分 ≥ 70** 的卖家
- 优先**新入驻 30 天内**的卖家（帮他们破冰）

### 2. 自营订单的"价格策略"
- 不压价（按市场价采购）
- 不抬价（按市场价转售）
- 平台只赚"真实交易凭证"

### 3. 自营订单的"留痕"
- 必须走平台合同 + 提货通 + 对账通
- 沉淀完整数据
- 数据用于信用评分 + AI 推荐训练

### 4. 自营订单的"信用建设"
- 自营订单 100% 按时付款
- 自营订单 100% 按时验收
- 树立"平台付款及时"的口碑——吸引更多卖家

### 5. 自营订单的"逐步退出"
- M12 末自营 GMV 占比降到 10% 以下
- M24 末降到 5% 以下
- **永远不退到 0**——保留 3-5% 作为"健康度调节器"

## 第八章：4 个常见问题

### Q1：自营会不会被卖家发现"是平台自己买"？
**A**：会。但只要价格公允、付款及时，卖家不会反感——反而觉得"平台是个稳定大客户"。

### Q2：自营资金从哪里来？
**A**：
- 启动资金 ¥50-100 万：自有资金
- 规模化资金 ¥300-500 万：可用 30-60 天滚动周转
- 极端情况：找银行做"平台供应链贷"

### Q3：自营会不会被监管认定为"自营平台"，影响估值？
**A**：
- 只要 ≤ 10% 不会
- 找钢网 / 钢银都有自营，照样上市
- 招股书披露清楚即可

### Q4：自营和"刷单"的区别？
**A**：
- 自营：**真实采购 + 真实使用 + 真实付款**
- 刷单：**虚假交易 + 假数据**
- **绝对不能混淆**——刷单一旦被披露，平台立死

# 总结：5 句话给老板

## 关于平台顾问
1. **平台顾问 ≠ 销售**——招客服 / 钢贸内勤背景的人最合适
2. **配比 1:50-100 是底线**——少于这个无法服务好

## 关于自营 GMV
3. **自营 GMV 5-10% 是双边市场启动的"必需品"**，不是可选项
4. **模式 C（自用采购）+ 模式 B（垫付撮合）是创业公司的最佳组合**
5. **自营 ≠ 刷单**——前者真实交易，后者诈骗，绝不能混
