# 合作企业三重激励协议模板（钢厂 + 大型钢贸商 + 物流 + 设备商）

> 用途：与各类合作企业签订带"3 重激励"的合作协议  
> 核心信条：**合作企业不是被白嫖的，必须给真实价值**

---

# 第一部分：合作企业类型与激励差异

## 1.1 4 类合作企业 + 不同激励

| 合作类型 | 他们带来 | 我方价值 | 激励重点 |
|---|---|---|---|
| **钢厂**（你方主业客户）| 下游钢贸商 → 卖家 | 帮钢厂管理分销 | 数据反馈 + 客户管理 |
| **大型钢贸商** | 下游终端 → 买家 | 帮钢贸商管客户（不抢）| 客户管理价值 + 业务分润 |
| **物流公司** | 已合作钢贸商 | 帮物流管运单 | 业务延伸（运单 SaaS）+ 分润 |
| **设备商**（轧机 / 镀锌设备 等）| 已合作钢厂 | 帮设备商管客户 | 销售线索 + 联合服务 |

## 1.2 「3 重激励」框架（适用所有合作企业）

```
激励 1：数据反馈（合作企业能看到的）
   ↓
激励 2：客户管理价值（不抢客户，是帮你管）
   ↓
激励 3：业务分润（实质性收益）
```

# 第二部分：钢厂合作协议模板

## 2.1 适用场景
- 你方钢厂客户（已签 ERP/MES/WMS 主业系统）
- 钢厂的下游 = 钢贸商 = 你的"卖家"
- 钢厂希望帮自己的下游钢贸商**做强**（钢贸商做强 = 钢厂卖货更好）

## 2.2 协议核心条款（5 条）

### 条款 1：定义
- "我方"：XX 数字化平台
- "甲方"：XX 钢厂
- "下游钢贸商"：甲方现有的合作钢贸商（合作 6 月以上）

### 条款 2：合作内容
1. 我方为**甲方下游钢贸商**提供数字化平台服务（免费试用 + 优惠收费）
2. 我方为**甲方**提供"分销管理工具"（免费）
3. 我方与甲方**联合品牌**（白皮书 / 案例 / 大会署名）

### 条款 3：3 重激励 - 给甲方

#### 激励 1：数据反馈
- 甲方可在平台后台**看到所有下游钢贸商的活跃度数据**：
  - 下游钢贸商在平台的月成交 GMV
  - 下游钢贸商对甲方产品的库存周转
  - 下游钢贸商的最终客户分布（脱敏）
- 数据帮助甲方做"分销策略优化"

#### 激励 2：客户管理价值
- 平台**不抢甲方客户**：协议明确"我方不直接销售给甲方下游钢贸商的终端客户"
- 平台**帮甲方管理客户**：
  - 钢贸商订单数据自动同步给甲方
  - 甲方可在平台**直接对话**下游钢贸商
  - 甲方可在平台**发布"分销激励政策"**

#### 激励 3：业务分润
- 我方**任何**对甲方下游钢贸商的收费 → 甲方分润 **5%**
- 分润按月结算，对公打款（开 6% 增值税票）
- 三年合作期 + 自动续约

### 条款 4：甲方义务
- 引荐**至少 30 家**下游钢贸商进入平台
- 老板**亲自打 1 通电话**给前 10 家最重要的下游
- 不阻止平台与下游钢贸商深度合作

### 条款 5：保密 + 数据所有权
- 甲方下游钢贸商的数据 → 钢贸商所有，平台代管
- 甲方仅能看**自己引荐**的钢贸商数据
- 三方数据使用都需用户授权

## 2.3 钢厂合作的"额外特权"
- 平台**冠名**为"XX 钢厂数字化升级合作伙伴"
- 联合署名《行业白皮书》
- 钢厂老板进入"平台战略委员会"（每年 4 次会议 + 决策投票）
- 钢厂下游钢贸商付费**自动 8 折**

# 第三部分：大型钢贸商合作协议模板

## 3.1 适用场景
- 大型钢贸商（年流水 ≥ ¥3 亿）
- 他们**不愿把买家完全交给平台**（怕被抢）
- 但愿意**用平台帮他们管理买家**

## 3.2 协议核心（与钢厂版的关键差异）

### 差异 1：保护客户关系
- 协议明确："**平台不直接销售给甲方的终端买家**"
- 终端买家在平台的所有活动，**都标注"由甲方服务"**
- 终端买家的合同 / 付款 / 物流，**由甲方主导**

### 差异 2：甲方使用平台是"代客户管理"
- 甲方在平台**为自己的买家创建账号**（B2B2B 模式）
- 平台是甲方的"客户管理工具"，不是替代

### 差异 3：分润模式不同
- 甲方使用平台 = **免费**（对甲方完全免费）
- 平台**任何对甲方买家的收费** → 甲方分润 **30%**（高于钢厂版 5%）
- 因为甲方是"代理"角色

## 3.3 三重激励（大型钢贸商版）

#### 激励 1：客户管理价值（最重）
- 提货通 / 对账通 → 帮甲方管买家
- 买家信用评分 → 帮甲方做风控
- 买家活跃度数据 → 帮甲方运营

#### 激励 2：业务延伸
- 平台**未来撮合**：甲方买家询价时 → **优先推荐甲方**
- 平台**金融服务**：与银行合作，给甲方买家做"采购贷"
- 平台**物流服务**：与物流公司合作，给甲方买家做"专线物流"
- 所有延伸业务 → 甲方分润 30%

#### 激励 3：行业地位
- 甲方进入"平台核心合伙人"圈
- 联合大会演讲机会
- 行业白皮书署名

# 第四部分：物流公司合作协议模板

## 4.1 适用场景
- 钢铁专线物流公司
- 客户 = 钢厂 + 钢贸商 + 终端买家
- 痛点：客户运单管理乱

## 4.2 三重激励（物流公司版）

#### 激励 1：业务延伸（运单 SaaS）
- 平台**免费**给物流公司"运单管理 SaaS"
- 帮物流公司管订单 / 司机 / 车辆 / GPS
- 帮物流公司提升数字化形象

#### 激励 2：客户分流
- 平台买家询价时 → 物流推荐**优先**给合作物流公司
- 物流公司从平台获得**新单量**

#### 激励 3：业务分润
- 物流公司接平台撮合的运单 → **平台抽 5%**（轻佣）
- 物流公司**主动推荐买家进平台** → 该买家任何收费 → 物流公司分润 10%

## 4.3 物流公司义务
- 把现有钢铁客户**逐步引导**进平台（不强制）
- 配合平台做"物流时效优化"

# 第五部分：设备商合作协议模板

## 5.1 适用场景
- 轧机厂 / 焊管设备 / 镀锌线设备 / 检测设备
- 客户 = 钢厂（=你的"卖家上游"）
- 痛点：自己的客户怎么继续赚钱

## 5.2 三重激励（设备商版）

#### 激励 1：销售线索
- 平台**月度推送**钢厂数字化升级线索给设备商
- 钢厂上系统时常常**也想升设备**

#### 激励 2：联合服务
- 设备商客户上数字化系统 → 设备商**返佣 20%**（实施费）
- 钢厂买设备 + 同时上系统 → "设备 + 系统"打包销售

#### 激励 3：行业地位
- 与设备商**联合开行业大会**
- 联合白皮书 / 案例

# 第六部分：通用条款模板

## 6.1 合作期限
- **首期 3 年**
- 自动续约（每年自动续）
- 任一方提前 6 个月书面通知 → 可终止

## 6.2 数据所有权
- 用户数据 → 用户所有
- 合作企业数据 → 合作企业所有
- 平台运营数据 → 平台所有

## 6.3 保密义务
- 合作内容、分润金额、用户数据 → 互相保密
- 保密期 = 合作期 + 5 年

## 6.4 排他性
- **平台不与同一区域的同类合作企业签独家**（保持公平）
- 但前 5 家合作企业可享有"优先权"（流量 +10%）

## 6.5 退出机制
- 合作期内任一方违约 → 30 天书面通知 + 整改
- 整改不到位 → 终止合作 + 已获利益结算

# 第七部分：合作企业开发节奏

## 7.1 6 个月开发节奏

| 月 | 目标 | 重点合作企业 |
|---|---|---|
| M1 | 5-10 家钢厂老板**口头确认**（已是你方主业客户） | 钢厂 |
| M2 | 3-5 家钢厂**正式签合作协议** | 钢厂 |
| M3 | 1-2 家大型钢贸商接触（你方主业客户的下游）| 钢贸商 |
| M4 | 2-3 家物流公司接触 | 物流 |
| M5 | 1-2 家设备商接触 | 设备商 |
| M6 | 共 10-15 家合作企业 + 1 家"种子物流" | 全 |

## 7.2 第 1 家合作企业的"超级礼包"
- 实施费 5 折（如付费）
- 联合品牌 + 联合白皮书
- 老板进战略委员会
- 行业大会主讲席位
- **首批合作企业全额分润 + 优先权**

# 第八部分：合作协议谈判 SOP

## 8.1 第 1 次接触（不签）
- 老板亲自打电话或上门
- 介绍合作思路（口头版）
- 给 1 页《合作概念书》
- 约下次正式见面

## 8.2 第 2 次见面（细化）
- 售前 + 业务总监同行
- 具体讲 3 重激励细节
- 听对方提反馈
- 定 2-4 周内出协议

## 8.3 第 3 次见面（签协议）
- 老板 + 法务同行
- 签纸质 + 电子合同
- 拍合影 + 朋友圈战报

## 8.4 第 4 次（首次合作启动）
- 业务总监 + 平台顾问
- 帮合作企业**开通后台账号**
- 演示分润看板
- 约首批"引荐 10 家"行动

# 第九部分：合作协议常见问题

## Q1：合作企业觉得"返佣低"怎么办？
**A**：
- 强调"长期价值"（3 年合同 + 自动续约）
- 强调"非现金价值"（数据 / 客户管理 / 行业地位）
- 不轻易让步

## Q2：合作企业想"独家"怎么办？
**A**：
- 拒绝独家（违反平台公平原则）
- 给"优先权"（流量 +10% / 大会主讲优先）
- 给"区域优先开发权"（半年内不签同区竞品）

## Q3：合作企业不愿引荐下游怎么办？
**A**：
- 先**不强制引荐**——只签合作意向
- 给合作企业**先用平台 30 天**
- 让他们看到"分润看板有数据"才会主动引荐

## Q4：合作企业之间冲突怎么办？
**A**：
- 协议明确"分润归属"（先注册者得）
- 30 天内未推进 → 释放
- 有争议 → 平台老板裁决

## Q5：合作企业想拿股权怎么办？
**A**：
- A 轮前**不给股权**
- A 轮后可考虑"战略股东"（≤ 1%）
- 优先给"前 5 家最大贡献者"

# 5 句话给老板

1. **合作企业不是免费的劳动力**——必须给"3 重激励"
2. **3 类合作企业激励重点不同**——钢厂给数据，钢贸商给客户管理，物流给业务延伸
3. **首批 5 家合作企业必须给"超级礼包"**——长期价值 > 短期收入
4. **协议必须明确"不抢客户"**——这是合作企业最在意的
5. **分润看板要透明**——按月结算 + 实时可查
