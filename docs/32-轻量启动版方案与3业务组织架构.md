## 第二章：轻量版（¥500-1,000 万）详细方案

### 2.1 核心策略：聚焦 + 借力

#### 聚焦：1 个品类 + 1 个区域
- **品类**：从你方钢厂主业最强的 1 个品类切入（焊管 / 镀锌卷 / 开平板）
- **区域**：选择钢厂主业客户最密集的 1 个产业带（建议长三角或珠三角）

#### 借力：把"自营"换成"合作企业引流"
- 不做模式 C 的自用采购
- 完全依赖钢厂客户的下游引荐 + 合作企业激励

### 2.2 团队配置（10-15 人）

```
老板（兼业务总监）
   │
   ├── 平台顾问 6 人（1 顾问 : 50 买家）
   ├── 销售 2 人（拉买家 + 拉卖家）
   ├── 产品经理 1 人
   ├── 工程师 2-3 人（开发）
   └── 行政 / 财务（兼）
```

### 2.3 6 月预算

| 项 | 金额（万）|
|---|---|
| 团队薪酬 | 240 |
| 平台开发 | 80 |
| 老板局 + 物料 + 杂费 | 50 |
| 钢厂客户"引荐礼" | 20 |
| 应急 | 30 |
| **6 月小计** | **¥420 万** |

加上前 12 月运营储备 → **总现金需求 ≥ ¥800 万**

### 2.4 6 月目标（轻量版）

| 月 | 活跃买家 | 活跃卖家 | 月营收 |
|---|---|---|---|
| M3 | 30 | 100 | ¥0 |
| M6 | 200 | 600 | ¥50 万 |

### 2.5 轻量版的"3 个妥协"

#### 妥协 1：放弃 5-10% 自营
- **后果**：早期卖家入驻率 / 留存率会下降
- **补偿**：平台顾问加倍服务 + 合作企业引流加大

#### 妥协 2：AI 询价完全靠人工
- **后果**：用户体验略差
- **补偿**：响应快 + 1 对 1 服务

#### 妥协 3：放弃部分产品（M6 前）
- M6 前**只做 ERP/WMS + 现货大厅 + 提货通**
- 报价工作台 / 对账通 / 流量包 / 信用数据 → M7+ 上

## 第三章：极简版（¥200-500 万）详细方案

### 3.1 适用场景
- 现金流极紧张
- 老板愿意"先验证再扩张"
- 团队 < 8 人

### 3.2 极简策略：纯工具 + 不做平台

#### 战略
- 暂时**不做交易平台**
- 只做"**钢贸 SaaS**"（ERP/WMS + 提货通 + 对账通）
- 当成一个**钢贸版 ERP**卖

#### 团队（5-8 人）
- 老板兼销售总监 + 业务总监 + 产品经理
- 销售 2 人（卖 SaaS）
- 实施顾问 2 人
- 工程师 1-2 人

### 3.3 6 月目标（极简版）

| 月 | 钢贸商客户 | 月营收 |
|---|---|---|
| M3 | 10 | ¥0 |
| M6 | 50 | ¥10 万 |

### 3.4 极简版的"6 月路径"

```
M1-M3：从你方钢厂主业客户的下游钢贸商
        卖 SaaS（不卖平台）
        
M4-M6：50 家钢贸商使用 SaaS 后
        在 SaaS 内部启动"小撮合"
        
M7-M12：撮合数据 → 平台雏形
        引入买家 → 真平台
        
M13+：完整 ABC 闭环启动
```

### 3.5 极简版优势 + 劣势

**优势**：
- 现金流压力小
- 风险低
- 慢但稳

**劣势**：
- 错过"窗口期"（找钢网等已经在加速）
- 24 月营收 ≤ ¥1,000 万（vs 完整版 ¥7,500 万）
- 估值低（5-10 倍 PS = ¥0.5-1 亿）

## 第四章：3 个版本的"决策树"

```
你的现金流是多少？

≥ ¥1,500 万
   ├── 团队齐全？ → 完整版
   └── 团队不齐 → 先轻量版，半年后扩

¥500-1,500 万
   ├── 业务总监到位？ → 轻量版
   └── 没业务总监 → 极简版 + 招业务总监

< ¥500 万
   ├── 老板能 ALL IN？ → 极简版
   └── 不能 ALL IN → 不要做新业务，专心钢厂主业
```

## 第五章：轻量版升级到完整版的"3 个时点"

### 时点 1：M6 末（轻量版评估）
**评估**：6 月营收 ≥ ¥50 万 + 月活买家 ≥ 200 + 付费转化率 ≥ 8%

**通过 → 启动 A 轮融资 ¥1-2 亿** → 升级完整版  
**未通过 → 继续轻量版 6 月**

### 时点 2：M12 末（中期评估）
**评估**：12 月累计营收 ≥ ¥300 万 + 月活买家 ≥ 500

**通过 → 加大投入** → 升级完整版  
**未通过 → 转极简版 + 重新审视战略**

### 时点 3：M18 末（生死线）
**评估**：18 月累计营收 ≥ ¥1,000 万 + 月活买家 ≥ 1,500

**通过 → 启动 B 轮 ¥3-5 亿**  
**未通过 → 关闭新业务，回归钢厂主业**

# 下篇：3 业务组织架构

## 第一章：3 业务总览

```
公司（老板）
    │
    ├── 业务 1：钢厂数字化 SaaS（前 23 份文档）
    │     - CMO（M6+）/ 销售总监 A / B
    │     - 销售铁三角 × 2-3 组
    │     - 实施 + 客服
    │
    ├── 业务 2：钢贸 SaaS + 平台
    │     - 业务总监（独立）
    │     - 平台顾问 5-15 人
    │     - 销售 2-5 人
    │     - 自营 / 增值 团队
    │
    └── 业务 3：信用数据外卖
          - 数据销售总监（M12+）
          - BD 2-3 人
          - 数据分析师 1 人
```

## 第二章：3 业务的"边界 + 协同"

### 2.1 边界（避免冲突）

| 业务 | 客户 | 收入 |
|---|---|---|
| 业务 1 钢厂 SaaS | 钢厂老板 | 钢厂付的 SaaS 月费 |
| 业务 2 钢贸 SaaS + 平台 | 钢贸商 + 终端买家 | 钢贸商付的 SaaS + 撮合佣金 + 增值 |
| 业务 3 信用数据 | 银行 / 保理 / 大买家 | 数据 API 费 + 报告订阅 |

**清晰边界**：客户不重叠 / 收入不重叠 / 团队不重叠

### 2.2 协同（最大化价值）

#### 协同 1：客户引荐
- 业务 1 客户 → 推荐给业务 2（钢厂的下游钢贸商）
- 业务 2 客户 → 推荐给业务 3（钢贸商信用 → 卖给银行）

#### 协同 2：数据共享
- 业务 1 ERP/MES 数据 → 业务 2 平台数据基础
- 业务 2 交易数据 → 业务 3 信用评分基础

#### 协同 3：品牌联动
- 业务 1 灯塔厂 → 在业务 2 推为"标杆案例"
- 业务 2 撮合数据 → 业务 3 行业指数报告

### 2.3 协同的"防火墙"
- **数据共享必须用户授权**（不能私自共用）
- **业务 1 客户的订单数据**不能直接给业务 2 平台（钢厂的商业秘密）
- **业务 3 数据外卖**前必须脱敏

## 第四章：关键岗位画像

### 4.1 业务 2 总监（钢贸新业务的"灵魂"）

#### 必备
- 钢贸 / 工业 SaaS / 钢铁电商 ≥ 5 年
- 操盘过 0-1 业务
- 懂双边市场（找钢网 / 钢银背景最佳）
- 接地气（能跑钢贸商）

#### 加分
- 有平台运营经验
- 懂数据分析
- 个人微信有 200+ 钢贸圈联系人

#### 薪酬
- 北方 50-80 万 / 年 + 业绩奖金
- 期权 1-3%

#### 招聘渠道
- 找钢网 / 钢银 / Mysteel 销售总监
- 大型钢贸商的 CTO / 副总
- 行业熟人推荐 + 高端猎头

### 4.2 平台顾问（详见 docs/28）
- 客服 / 加工配送内勤 / 钢贸商内勤背景
- 月薪 ¥1.5-3 万
- 配比 1:50-100

### 4.3 数据销售总监（业务 3）

#### 必备
- to B 数据 / SaaS 销售经验 ≥ 5 年
- 银行 / 金融 / 保理客户资源
- 大客户销售能力

#### 招聘时点
- M12 启动招聘
- M15 入职

## 第六章：3 业务的"治理结构"

### 6.1 决策机制
- **战略决策**（年度方向、业务边界、重大投资）：CEO + 各业务负责人 → 季度战略会
- **业务决策**（产品 / 客户 / 价格）：各业务负责人独立
- **跨业务协同**：CEO 拍板 + COO 落地

### 6.2 冲突处理
- 客户重叠 → CEO 仲裁
- 资源争夺 → 季度回顾按 KPI 完成度分配
- 文化差异 → 鼓励"百花齐放"，不搞统一

### 6.3 业绩衡量
| 业务 | 北极星指标 | 复盘频次 |
|---|---|---|
| 业务 1 | 钢厂 ARR + 客户留存率 | 月 |
| 业务 2 | 钢贸活跃用户 + 平台 GMV + ARPU | 周 |
| 业务 3 | 数据 ARR + 大客户数 | 月 |

## 第七章：3 业务的「3 个不能踩的坑」

### 坑 1：把 3 业务"合并管理"
- 客户不同 / 文化不同 / 节奏不同
- **必须独立运营，独立 KPI**

### 坑 2：人才"轮岗"
- 钢厂销售去做钢贸销售 → 失败
- 钢贸销售去做数据销售 → 失败
- **每个业务必须独立招人**

### 坑 3：数据"没墙"
- 业务 1 的钢厂订单**直接同步**给业务 2 平台
- 钢厂老板会愤怒——商业秘密泄露
- **必须用户授权 + 数据脱敏**

# 5 句话给老板

1. **现金流决定打法**——不要硬上完整版
2. **3 业务必须独立 KPI 独立团队**——合并管理 = 必死
3. **业务 2 总监是钢贸新业务的灵魂**——优先招他
4. **轻量版可以升级到完整版**，但极简版**很难升级**
5. **数据要墙、客户要墙、文化要墙**——业务之间合作不合并
