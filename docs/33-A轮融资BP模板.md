# 第三部分：第一篇 Why（行业 + 机会 + 政策）

## 3.1 第 1 页：行业现状

```
中国钢铁产业总产值 ¥10+ 万亿
  - 钢厂：8,000+ 家（民营 5,500+）
  - 钢贸商：15-20 万家
  - 终端用户：百万级

行业 5 大痛点：
  1. 民营钢厂利润从 8.2% → 3.6%（5 年腰斩）
  2. 钢贸利润 0.5-1.5%（极薄）
  3. 数字化渗透率 < 18%（远低制造业平均 35%）
  4. 客户审厂 / 出口 / 汽车 / 家电"硬门槛"集中落地
  5. 行业整合加速，30-40% 民营钢厂将被并购

钢铁行业 = 数字化"最后窗口期"
  2024-2027 = 卡位期
  2028+ = 收割期
```

## 3.2 第 2 页：时代机会

```
机会 1：政策红利
  - 工信部"专精特新"补贴
  - 各省"智能制造"专项基金
  - 双碳"碳排放数据上报"强制

机会 2：客户主动
  - 出口客户审厂全面"系统化"
  - 汽车 / 家电客户"实时数据接入"
  - 银行 / 融租"数据化授信"

机会 3：成本断崖
  - 5 年前 ERP 50-100 万 / 1 年部署
  - 现在 1 个核心模块 3-7 万 / 30 天见效
  - 数字化"门槛"降 70%

机会 4：行业整合
  - 大集团兼并加速
  - "数字化估值溢价"30-50%
```

## 3.3 第 3 页：竞争格局

```
TAM = 钢厂 SaaS（¥30 亿）+ 钢贸 SaaS（¥36 亿）+ 平台撮合（¥75 亿）
    + 数据 / 金融 / 增值（¥50 亿）= ¥190 亿 / 年

主要玩家：
  - 找钢网：钢贸平台龙头，¥1,500 亿 GMV，PS 3-5 倍
  - 钢银：钢贸平台 + 自营 + 金融，¥1,000 亿 GMV
  - Mysteel：钢铁信息服务，年营收 ¥10 亿
  - 用友 / 金蝶：通用 ERP，钢铁专版渗透低
  
我们的位置：
  - **唯一全链路服务商**
  - 切入点：钢厂主业（差异化）
  - 优势：数据壁垒 + 协同效应
```

## 3.4 第 4 页：选我们的理由

```
为什么是钢铁数字化这条赛道？
  - ¥10 万亿产值 + 数字化渗透低 + 政策红利

为什么是这个时点（2027）？
  - 卡位窗口仅剩 2 年（2027-2028）
  - 错过 = 永远失去

为什么是我们这个团队？
  - 20 年钢铁行业 + 10 年 SaaS + 钢贸平台基因
  - 已跑通 0-1 + 拥有数据壁垒
```

# 第九部分：BP 制作的"5 个铁律"

## 1. 数字必须真实
- 投资人会逐项核实
- 任何夸大 = 失败
- 宁愿少说，不要多说

## 2. 视觉必须专业
- 找设计师做视觉（¥3-5 万）
- 不要 PPT 默认模板
- 数据可视化必须清晰

## 3. 开场必须抓人
- 第 1 页 = 决定能否见你
- 第 2 页 = 决定能否进入下一步
- 必须 2 页讲明白"为什么投你"

## 4. 财务必须保守
- 投资人会按你的预测打 70% 折
- 你的预测必须**真实可验证**
- 留 30% 上行空间

## 5. 团队必须有"明星"
- 至少 1 位"行业人尽皆知"的高管 / 顾问
- 否则投资人会怀疑"凭什么是你"

# 第十部分：A 轮融资的"3 个关键时点"

## 时点 1：BP 完稿 + 内部 review（M16）
- 由 CFO + COO + 财务顾问 review
- 调整数据 / 表达 / 视觉
- 找 2-3 个早期投资人**预演路演**

## 时点 2：开始接触投资人（M17）
- TOP 30 投资机构清单
- 通过老股东 / 朋友引荐（不要海投）
- 第 1 轮见 5-10 家
- 收集反馈 → 调整 BP

## 时点 3：Term Sheet（M19-M20）
- 至少 3 家给 TS（保持议价权）
- 选择"战略价值 + 估值"双优
- 法务 + 财务尽调
- 签署 + 公告

# 5 句话给老板

1. **A 轮融资是"卖数据 + 卖团队 + 卖未来"**——3 缺 1 都不行
2. **执行摘要是 80% 战斗力**——投资人 90% 决策来自前 2 页
3. **财务必须保守**——投资人会打 70% 折，太激进 = 反向打分
4. **明星顾问 + 战略股东**比现金重要——他们带来"信任"
5. **不要海投**——TOP 30 精准接触，宁缺毋滥
