# 第三部分：核心瓶颈：销售团队"顾问式销售"升级

## 3.1 你的真实问题

老板说："**他们还没有形成顾问式销售思维，而是简单的卖货思维**"

——这是 **¥500 万 / 月** 目标的最大瓶颈。  
没有顾问式销售，钢贸 ERP / 库准 WMS / 工业 MES 这些 **高客单价产品根本卖不动**。

## 3.2 「卖货思维」vs「顾问式销售」对比

| 维度 | 卖货思维 | 顾问式销售 |
|---|---|---|
| 开场 | "我们 ERP 多牛 X" | "X 总，您这一年最痛的是什么？" |
| 主导 | 销售说 80% | 客户说 80% |
| 武器 | 产品手册 | 健康度自评表 + 案例 |
| 节奏 | 1 次见面定生死 | 3-5 次见面深入 |
| 价格 | 一开始就报 | 第 3-4 次才报 |
| 关闭 | "买不买" | "我们一起帮您算笔账" |
| 关系 | 一次性 | 长期顾问 |

## 3.3 顾问式销售的"5 步训练法"

### 步骤 1：诊断式开场（取代产品介绍）
**话术模板**：
```
X 总，开始之前我想先问 3 个问题：
1. 您这一年最痛的 3 件事是什么？
2. 您的同行（X 公司）这两年做了什么？
3. 如果有一件事能立刻改善，您最希望改善什么？

[听完后再决定讲什么产品]
```

**训练动作**：
- 每个销售必须**背 30 个开场问题库**
- 每次拜访前**预演问题清单**
- 拜访后**复盘客户的回答**

---

### 步骤 2：「健康度自评」工具化（详见 docs/07）

**应用到钢贸客户**：

| 模块 | 问题示例 |
|---|---|
| 客户管理 | 您每个月接到多少询价？您还记得每个客户的特殊偏好吗？|
| 库存 | 您库存账实差大概多少？盘点要几天？|
| 应收 | 您 90 天 + 应收账款占比多少？|
| 成本 | 您每个产品 / 每个客户的真实毛利能算清吗？|
| 销售 | 您的销售离职会带客户吗？您能控制吗？|
| 风险 | 您最大客户欠款超期 → 您怎么发现？|
| 决策 | 您能在手机上看到今天的成交吗？|
