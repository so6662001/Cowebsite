# 第六部分：5 个常见问题

## Q1：销售个人计划太"紧"，他们会不会跑路？
**A**：
- 提成结构必须**首月就能见钱**（小赢得快）
- 老板亲自带 3 大客户销售第 1 周
- 给"过渡期"工资保护（M1 兜底 80% 薪资）

## Q2：电销批量销售月签 30-50 个 AI 现实吗？
**A**：
- 计算：每天 50 电话 × 20 工作日 = 1000 电话 / 月
- 8% 转化 = 80 单 / 月（理论上限）
- 实际目标 30-50 单 / 月——**60% 利用率合理**

## Q3：大客户销售 90 天能签工业 MES 吗？
**A**：
- MES 真实决策周期 3-6 月
- 90 天**只能签 1-2 单**（已有强关系 / 已有 POC 基础的）
- M1-M2 主要是**POC + 推进**，M3 才有签单

## Q4：如何让小客户销售"成长"为大客户销售？
**A**：
- 每月让小客户销售**陪 1 次大客户销售拜访**
- 角色扮演 + 录音复盘
- 给 1-2 个 A 段客户**练手**（有 mentor 辅助）

## Q5：如果有销售完全不达标怎么办？
**A**：
- 月 < 50% → PIP 改进计划（30 天）
- 30 天后仍 < 50% → 调岗到电销支持
- 60 天后仍 < 50% → 解约（提前 30 天通知）

# 第七部分：给老板的 3 句话

1. **9 销售必须 3 段分工 + 个性化目标卡**——一刀切目标 = 都达不到
2. **大客户销售给"高客单价 + 长周期"打法**，电销给"高频小单"打法——不要混
3. **顾问式销售训练 + 录音复盘**是第 1 个必须解决的瓶颈，老板亲自抓 4 周
