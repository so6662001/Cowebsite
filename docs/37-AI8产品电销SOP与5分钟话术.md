# AI 8 产品电销 SOP + 5 分钟话术库

> 用途：3 个电销批量销售（C1-C3）的日常作战手册  
> 目标：每人每天 50 通电话，月签 30-50 个 AI，**90 天累计 450-800 个 AI 客户**  
> 配套 docs/36 销售个人计划

---

# 第一部分：电销作战总览

## 1.1 数字模型

```
每销售每天 50 通电话
× 接通率 60% = 30 通有效电话
× 完成 5 分钟介绍率 50% = 15 通完整通话
× 留资率 30% = 4.5 个意向客户
× 后续转化率 25% = 1.1 个签约客户

每销售每天 1.1 单 × 20 工作日 = 22 单 / 月
3 销售 × 22 单 = 66 单 / 月

90 天累计：66 × 3 月 = 198 + 老带新 + 累积 ≈ 500-800 个
```

## 1.2 工具配置（必备）
- **CRM**：录入 + 标签 + 跟进
- **电销系统**：自动外呼 + 录音 + 数据分析
- **微信外挂**：批量加好友 + 自动回复
- **AI 产品演示账号**：能秒进试用
