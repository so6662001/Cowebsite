# 上篇：工业 MES 60 家候选调研模板

## 第一章：工业 MES 客户画像

### 1.1 谁是"工业 MES 真客户"

| 必备条件 | 说明 |
|---|---|
| ✅ 有自主生产 / 加工业务 | 不是纯贸易商 |
| ✅ 年产值 ≥ ¥1 亿 | < 1 亿付不起 ¥30 万 |
| ✅ 至少 2 条生产线 / 工序 | 单线少有 MES 需求 |
| ✅ 老板 ≤ 60 岁 | 老板太大年龄不愿"大动" |
| ✅ 有出口 / 汽车 / 家电客户 | 审厂硬需求 |
| ✅ 历史决策"敢花钱" | 看历史投资额（设备 / 系统） |

### 1.2 「3 不要」客户（直接淘汰）

| 不要 | 原因 |
|---|---|
| ❌ 纯贸易商 | 没有 MES 需求 |
| ❌ 年产值 < ¥5,000 万 | 付不起 ¥30 万 |
| ❌ 5 年内有 ERP / MES 失败案例 | 心理障碍大 |

### 1.3 客户类型分类（对应你方钢厂主业 4 类）

| 类型 | 占 800 腰部客户比例 | 工业 MES 重点功能 |
|---|---|---|
| 钢管生产企业 | 25%（约 200 家）| 排程 + 质量追溯 + 设备管理 |
| 镀锌冷卷企业 | 15%（约 120 家）| 排程 + OEE + 工艺参数 |
| 一体厂（钢管+镀锌）| 10%（约 80 家）| 全套联调 + 多基地 |
| 开平纵剪加工 | 30%（约 240 家）| **不适合 ¥30 万 MES**（推 AI 经营包）|
| 其他贸易 | 20%（160 家）| 不适合 |

**潜在 MES 客户池 = 200 + 120 + 80 = 400 家**

## 第二章：60 家候选筛选模型

### 2.1 评分维度（8 维 × 1-5 分 × 权重）

| 维度 | 权重 | 5 分 | 1 分 |
|---|---|---|---|
| 1. 年产值 | 3 | > ¥10 亿 | < ¥5,000 万 |
| 2. 产线数 | 2 | ≥ 4 条 | 1 条 |
| 3. 老板决策力 | 3 | 一人拍板 | 多股东博弈 |
| 4. 客户结构（出口/汽车/家电）| 3 | ≥ 30% | 0% |
| 5. 现有系统基础 | 2 | 有 ERP + 财务 | 纯手工 |
| 6. 历史投资额（设备/系统）| 2 | > ¥500 万 / 5 年 | < ¥50 万 |
| 7. 与我方关系 | 3 | 已签 ERP / 其他产品 | 纯陌生 |
| 8. 痛点紧迫度 | 2 | 今年审厂被刷 / 急需 | 没有紧迫 |

**总分 = 各维度得分 × 权重 ÷ 100**

### 2.2 总分分级

| 总分 | 等级 | 动作 |
|---|---|---|
| ≥ 85 | S（梦中情人）| 老板亲自跑 + 价格让到 6 折 |
| 70-84 | A（核心目标）| 大客户销售主跟 + 标准价 8 折 |
| 55-69 | B（备选）| 排队跟进 |
| < 55 | C（淘汰）| 不进 60 家清单 |

### 2.3 60 家清单结构

```
3 大客户销售 × 各负责 20 家 = 60 家清单

S 级（≥ 85）：8-12 家（老板亲自跑）
A 级（70-84）：30-35 家（大客户销售跟）
B 级（55-69）：15-20 家（备选）
```

# 下篇：库准 WMS 轻量版产品定义

## 第一章：库准 WMS 当前问题诊断

### 1.1 老板描述的问题
- ✅ "市面独有" → 优势
- ❌ "最近半年销售不好" → 增长卡死
- ❌ "每个地区都建了标杆，没再宣传" → 缺新故事
- ❌ "销售没能形成推力" → 推力机制断
- ❌ "头部已上，中小户认为不必要" → 客户层偏移
- ❌ "需要硬件支持" → 中小客户付不起

### 1.2 根因分析

| 问题 | 根因 |
|---|---|
| 头部已上 | 现有产品定位"中大型企业"，市场天花板已到 |
| 中小户不要 | ¥10,000 / 用户太贵 + 硬件依赖 |
| 销售没推力 | 没新故事 + 提成低 |
| 半年销售下滑 | 产品没迭代，市场已饱和 |

### 1.3 重启的"3 个方向"

#### 方向 1：**轻量版**（强推荐）
- 砍掉硬件依赖
- 降价到 ¥5,000 / 用户
- 卖给 700 小客户中"有 2-3 仓库"的（约 100 家）

#### 方向 2：**捆绑销售**
- 与 ERP / MES 一起卖 → 送 WMS 6 月免费
- 用 ERP / MES 的客户基础**反向推 WMS**

#### 方向 3：**AI + WMS 联动**
- AI 库存（月费 ¥3,000）+ WMS（一次 ¥5,000-10,000）
- 卖"动 + 静"完整库存方案

## 第二章：库准 WMS 轻量版产品定义

### 2.1 三档产品规划

| 版本 | 价格 | 含模块 | 目标客户 |
|---|---|---|---|
| 🌱 **轻量版**（**新**）| **¥5,000 / 用户**（一次性）| 基础入库 + 出库 + 盘点（**无硬件**）| 700 小客户中"有仓库"的 100 家 |
| 🚀 标准版（**保留**）| ¥10,000 / 用户 | + 多仓 + 卷号扫码 + 硬件 | 800 腰部客户 |
| 🏆 旗舰版（**新**）| ¥18,000 / 用户 | + 多基地 + API + BI | 集团客户 |

### 2.2 轻量版的"3 个砍掉"

#### 砍 1：硬件依赖
- **不强制**扫码枪 / 标签机 / 工业平板
- 客户用手机 + 微信小程序就能用
- 后期想升级 → 加买硬件包

#### 砍 2：复杂功能
- 只保留基础功能（入库、出库、盘点、库存查询）
- 多仓位 / 复杂工艺 / 卷号绑定 → 标准版以上

#### 砍 3：实施成本
- 不强制驻场实施
- 远程培训 1 小时即可
- 客户自助导入数据

### 2.3 轻量版的"3 个加上"

#### 加 1：手机端友好
- 手机端 100% 功能可用
- 微信小程序快速访问
- 老板手机端看库存数据

#### 加 2：与 AI 库存绑定
- 客户买 AI 库存（¥3,000 / 月）→ **轻量 WMS 免费送**
- 或：买轻量 WMS + AI 库存包 ¥5,000 + ¥36,000 = ¥41,000 / 年（首年）
- 第 2 年只续 AI ¥3,000 / 月

#### 加 3：和 ERP 数据互通
- 与你方钢贸 ERP / 钢厂 ERP **直接对接**（你方独有优势）
- 不需要额外开发接口

### 2.4 轻量版收费模式

| 收费 | 金额 |
|---|---|
| 一次性 | ¥5,000 / 用户（≤ 5 用户）|
| 增加用户 | ¥3,000 / 额外用户 |
| 年维护 | 第 2 年起 ¥2,000 / 年（含升级）|
| AI 库存绑定 | ¥3,000 / 月（强烈推荐买）|
