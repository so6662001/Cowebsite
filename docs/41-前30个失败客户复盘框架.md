# 前 30 个失败客户复盘框架

> 用途：将 M1-M3 拜访 / 接触但未签约的失败客户做系统化复盘  
> 配套：docs/39 M1 末复盘 + docs/40 客户成功 SOP  
> 核心信条：**失败客户比成功客户更有价值**——成功复制难，失败可以避免

---

# 第一部分：为什么要做"失败客户复盘"

## 1.1 行业铁律
- B 端 SaaS 公司**70% 的失败来自重复同样的错误**
- 销售员个人会**美化失败**（不愿承认自己问题）
- 系统化复盘 = 把**个人错误变成组织资产**

## 1.2 时间窗口
- M1 末（2026.07.13）：复盘前 10-15 个失败客户
- M2 末：复盘累计 20-25 个
- **M3 末：完成 30 个完整复盘** + 输出《失败客户洞察报告 v1.0》

---

# 第二部分：失败客户的定义与分类

## 2.1 「失败客户」定义

满足以下任一条件：
1. 已上门拜访 ≥ 2 次，但 60 天内未签约
2. 进入诊断 / 工作坊，但未签 POC
3. 进入 POC，但 30 天后流失
4. 签约后 30 天活跃率 < 30%

## 2.2 失败客户的 7 大类型

| 类型 | 描述 | 占比（行业典型）|
|---|---|---|
| **A. 时机型** | 客户认可产品，但"今年不投系统" | 25% |
| **B. 价格型** | 客户嫌贵，竞品便宜 50%+ | 20% |
| **C. 价值型** | 客户没听懂"为啥要花这钱" | 15% |
| **D. 关系型** | 决策人变了 / 失去支持 | 12% |
| **E. 信任型** | 客户怕"买了用不起来" | 10% |
| **F. 竞品型** | 竞品强势锁定 | 8% |
| **G. 内部型** | 客户内部团队反对 | 10% |

## 步骤 2：客户访谈（60 分钟）

### 关键：销售本人**不参与**访谈
- 销售会美化 / 委屈
- **必须老板 / 销售总监 / 产品**亲自打电话

### 访谈话术
```
X 总，我是 XXX 公司的老板李 XX。

之前我们销售来跟您聊过 X X 系统，
您当时没决定 / 拒绝了 / 没续约。

我今天打电话**不是来推销的**，
也不是来"挽回"的。

我想花 5 分钟问您 3 个真心话——
您能帮我吗？您说什么我都不会反驳。

[等回应]

问题 1：您当时为什么没决定？
问题 2：我们销售哪里没说清楚？
问题 3：什么情况下您会重新考虑？

[听完后]

X 总，谢谢您。
您今天告诉我的话，会帮助我们公司变得更好。
之后您有任何需要，随时找我。
```

### 访谈输出
- 客户原话（不要改）
- 失败类型归类（A-G）
- 关键失败点（销售 / 产品 / 价格 / 时机）

## 步骤 3：根因分析（5W 法）

### 模板
```
现象：客户 X 拒绝
↓ Why 1
表面原因：__________
↓ Why 2
深层原因：__________
↓ Why 3
更深原因：__________
↓ Why 4
组织 / 流程根因：__________
↓ Why 5
最终根因：__________

可改进的环节：
□ 销售个人能力
□ 产品功能 / 定价
□ 销售流程 / SOP
□ 客户筛选标准
□ 客户成功 SOP
```

## 步骤 4：归类汇总（每周）

每周复盘会汇总：
- 本周新增失败客户 N 个
- 7 大失败类型分布
- TOP 3 高频失败点

## 步骤 5：行动改进（每月）

基于失败客户洞察，每月输出：
1. **销售培训重点**（针对 TOP 失败点）
2. **产品迭代需求**（针对产品缺陷）
3. **流程优化清单**（SOP 修订）
4. **客户筛选标准**（避免错的客户）

# 第四部分：7 大失败类型的"对症下药"

## 类型 A：时机型（25%）—— "今年不投系统"

### 真实根因
- 客户**财务紧张**
- 客户**内部其他优先级**（如换设备、扩产）
- **没有迫切痛点**

### 改进对策
- **销售筛选**：S/A 段优先（财务好的）
- **话术调整**：先讲"不上系统的代价"，再讲产品
- **价格创新**：推"0 首付月供"模式
- **保持联系**：CRM 标记，6 个月后重启

### 销售训练要点
- 学会问"您今年的优先级排序"
- 学会算"机会成本"（不上的代价）

---

## 类型 B：价格型（20%）—— "竞品便宜 50%+"

### 真实根因
- 客户**只比价**不比价值
- 销售**没讲清楚价值**
- 客户**对竞品认知错误**（看到的不是全功能）

### 改进对策
- **不正面降价**（破坏价格体系）
- **强调"价值锚定"**：算 ROI
- **送 + 不降**：免费送 1 年 AI / 3 个月免费试用
- **三位一体方案捆绑**：竞品没有

### 销售训练要点
- 学会"价值故事"（不是"功能介绍"）
- 学会算 ROI（具体到块）

---

## 类型 C：价值型（15%）—— "没听懂为啥要花这钱"

### 真实根因
- 销售**讲产品 / 不讲价值**（卖货思维）
- 客户**听不懂行话**（中台、闭环…）
- **没有同行案例**

### 改进对策
- **强制顾问式销售**（5 步法）
- **5 个客户故事**必背
- **健康度自评**让客户自己发现痛点

### 销售训练要点
- 录音抽查"价值话术 vs 卖货话术"比例
- 每周角色扮演

---

## 类型 D：关系型（12%）—— "决策人变了"

### 真实根因
- 客户**核心员工离职**（采购经理、IT 经理）
- 客户**股东变化**
- **没有维护多层关系**

### 改进对策
- **多层接触**：见老板 + 副总 + 中层
- **CRM 标签**：记录每个决策链人物
- **季度回访**：保持老客户活跃

### 销售训练要点
- 每个 S/A 客户**至少接触 3 个层级**

---

## 类型 E：信任型（10%）—— "怕买了用不起来"

### 真实根因
- 客户**之前买系统失败**（吃灰）
- 销售**承诺过度**反而引起怀疑
- **没有同行背书**

### 改进对策
- **风险逆转**：30 天免费 + 6 月退款
- **同行背书**：让灯塔客户老板**亲自打电话**
- **客户成功 SOP**：让客户看到"上线后不会被甩"

### 销售训练要点
- 学会"信任建立"话术（不夸大）
- 学会"邀请同行通话"

---

## 类型 F：竞品型（8%）—— "竞品锁定"

### 真实根因
- 客户**已和竞品深度合作**（数据迁移成本）
- 竞品**关系深**
- 销售**无差异化**

### 改进对策
- **不正面打**——选其他客户
- **找差异化场景**（钢厂全链数据 + AI 价格）
- **未来再争夺**——竞品有问题时

### 销售训练要点
- 学会"放弃"——不浪费时间

---

## 类型 G：内部型（10%）—— "客户内部团队反对"

### 真实根因
- 客户**老板想做 / 中层反对**
- 客户**IT / 财务反对**（担心被替代）
- **没有内部"内应"**

### 改进对策
- **培养"内部代言人"**（最痛的部门 / 最受益的人）
- **绕过反对者**（让老板拍板）
- **降低反对者损失**（不替代，是辅助）

### 销售训练要点
- 学会识别"决策链阻力点"

---

# 第五部分：失败客户的"3 种处置"

## 处置 1：「6 个月再启动」（适合 A/D/G 型）
- CRM 标记"6 月后回访"
- 持续朋友圈互动 + 行业资讯推送
- 6 月后销售总监 / 老板亲自重启

## 处置 2：「降低期望换签」（适合 B/E 型）
- 推荐"种子版"（最低门槛）
- 30 天免费试用
- 客户用上后再升级

## 处置 3：「彻底放弃」（适合 C/F 型）
- 标记"长尾"
- 不再分配销售资源
- 仅自动化邮件保持联系

# 第六部分：30 个失败客户的"3 个洞察输出"

## 洞察 1：销售个人差距
基于 30 个失败客户，每个销售出"个人改进点"

例：
```
销售 A1（M3 末报告）
- 失败客户 8 个
- 主要类型：C 价值型 5 个、B 价格型 3 个
- 销售个人问题：
  ✗ 顾问式销售落地差（80% 都是卖货话术）
  ✗ 价值故事讲不清楚
- 改进对策：
  → M4 顾问式销售强化训练 30 小时
  → 5 个客户故事重新背诵
  → 老板每周亲自带 2 通拜访
```

## 洞察 2：产品 / 价格问题

例：
```
产品改进需求（来自失败客户洞察）
1. 钢贸 ERP 价格 ¥7 万被 30% 客户嫌贵
   → 建议出"经营版 ¥5 万"（之前没有的档位）
2. 库准 WMS 硬件依赖被 15% 客户嫌烦
   → 建议出"轻量版 ¥5,000"（已计划）
3. AI 询价被 40% 客户问"和别家有啥不一样"
   → 建议出对比手册 + 演示视频
```

## 洞察 3：流程 / SOP 改进

例：
```
流程改进（来自失败客户洞察）
1. 60% 失败客户的"决策人 = 老板"，但销售见不到老板
   → 强制"3 次拜访必须见到老板"
2. 45% 失败客户没填健康度自评
   → 强制 SOP："自评是签约前必填项"
3. 80% 失败客户没收到"同行案例"
   → 强制 SOP："首次拜访必须给案例 PDF"
```

# 第七部分：失败客户复盘会议 SOP

## 7.1 复盘会议节奏

### 周复盘（每周一）
- 上周新增失败客户 N 个
- 类型分布
- TOP 3 高频失败点
- 本周改进 1 件事

### 月复盘（每月底）
- 累计失败客户 N 个
- 全员失败客户共享 + 学习
- 老板 + 产品 + 销售总监深度讨论
- 输出 5 个改进动作

### 季复盘（每季度）
- 输出《失败客户洞察报告》
- 影响下季度战略

## 7.2 失败客户复盘会议铁律
- **销售不参加自己客户的复盘**（避免自我辩护）
- **不指责具体销售个人**
- **聚焦"组织能改进的"**，不聚焦"个人错"

# 第八部分：失败客户的"再利用"

## 再利用 1：销售培训案例
- 把 30 个失败客户做成**销售培训教材**
- 每周角色扮演用真实失败案例

## 再利用 2：产品迭代输入
- 失败原因 → 产品 backlog
- 产品经理每月看 1 次失败客户报告

## 再利用 3：行业洞察
- 30 个失败客户的共性 = 行业洞察
- 用于：市场策略 / 内容营销 / 竞品分析

---

# 第九部分：5 句话给老板

1. **失败客户复盘 = 销售团队的"练兵场"**——比新签客户更有价值
2. **必须老板亲自访谈失败客户**——销售会美化
3. **每周复盘失败客户**——M1 末就要开始，不等到 M3
4. **7 大失败类型对症下药**——不能"一刀切"
5. **失败 → 改进 → 减少失败 → 业绩提升**——闭环必须建立
