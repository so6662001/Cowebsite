# CS 团队 4 周培训手册（详细脚本版）

> 用途：3-20 人 CS 团队入职后的 4 周标准化培训  
> 目标：4 周后 CS 顾问能独立服务 50-100 个客户  
> 配套：docs/40 客户成功 SOP

---

# 第一部分：4 周培训总览

## 4 周节奏

```
W1 行业 + 产品基础 → 通过 30 题考试
W2 服务流程 + 工具使用 → 模拟客户场景 5 个
W3 反馈收集 + 用户访谈 → 真实访谈 5 个客户
W4 上岗试运行 → 独立服务 5-10 客户
```

## 通过标准
- W1 末考试 ≥ 80 分
- W2 末模拟评分 ≥ 7/10
- W3 末用户反馈周报评分 ≥ 7/10
- W4 末上岗考核通过

# 第二部分：Week 1 行业 + 产品基础

## D1（周一）：钢铁 / 钢贸行业速成

### 上午（09:00-12:00）：钢铁行业基础（3 小时）

#### 09:00-10:00 钢铁产业链 1 小时
**讲师**：销售总监 / 业务总监

**讲稿要点**：
```
钢铁产业链 = 上游（铁矿石）→ 中游（钢厂）→ 下游（钢贸 + 终端）

▼ 钢厂分类
- 央企（鞍钢 / 宝钢 / 河钢 / 沙钢）：年产 > 1000 万吨
- 民营大型（友发 / 永钢 / 大昌）：500-1000 万吨
- 民营中型（你方钢厂主业客户）：100-500 万吨
- 加工型（钢管 / 镀锌 / 开平）：10-100 万吨

▼ 钢贸分类
- 大型贸易商（年流水 > ¥3 亿）：找钢网 / 钢银的"VIP"
- 中型（¥1-3 亿）：你方主力客户
- 小型（< ¥1 亿）：长尾客户

▼ 主要钢材品类
- 板材：热轧 / 冷轧 / 镀锌 / 镀铝锌
- 长材：螺纹钢 / 线材 / 圆钢 / 型钢
- 管材：焊管 / 无缝管 / 镀锌管 / 精密管
- 加工：开平 / 纵剪 / 拉伸 / 抛光
```

#### 10:00-11:00 钢贸生意逻辑
**讲稿要点**：
```
钢贸赚钱本质 = 信息差 + 关系 + 时机

▼ 4 大业务模式
1. 现货贸易：买进卖出，赚差价（毛利 1-3%）
2. 配送加工：买原料 + 加工 + 配送（毛利 3-5%）
3. 代理分销：钢厂下游代理（毛利 2-4% + 返点）
4. 期现结合：用期货对冲（毛利 5-10%）

▼ 钢贸利润链
1. 原料采购成本（钢厂出厂价）
2. + 运输费（铁路 / 公路 / 水运）
3. + 仓储费（每吨每月）
4. + 资金成本（融资利率 6-10%）
5. + 人工 / 管理
6. + 加工费（如开平 / 纵剪）
7. = 卖出价
8. 毛利 = 卖出 - 成本

▼ 钢贸的 5 大成本
- 资金成本：占总成本 30%（最大）
- 人力：占 20%
- 仓储：占 15%
- 物流：占 20%
- 损耗：占 15%
```

# 第四部分：Week 3 反馈收集 + 用户访谈

## D11-D13（周一-周三）：用户访谈 SOP

### D11 上午：访谈方法论

**讲稿要点**：
```
访谈 = 倾听 + 引导，不是问答

▼ 访谈 3 原则
1. 不打断（让客户多讲）
2. 不评价（不说"您说得对 / 不对"）
3. 不卖货（绝对不推销）

▼ 标准访谈结构（30 分钟）
- 5 分钟：寒暄 + 建立信任
- 10 分钟：开放性提问（让客户讲使用情况）
- 10 分钟：具体场景挖痛点
- 5 分钟：感谢 + 留尾巴

▼ 5 类必问问题
1. 整体感受：1-10 分给个分
2. 使用频率：您每周用几次？
3. 价值认知：最有用的功能是？
4. 痛点：哪里不爽？
5. 推荐意愿：会推荐同行吗？
```

### D11 下午：访谈话术练习

**模拟练习**：每学员 5 个模拟访谈，每个 30 分钟

### D12-D13：陪师傅做真实访谈

- 每天 2-3 个真实客户访谈
- 学员先**听** → 然后**部分接管**

# 第六部分：4 周培训的 5 个铁律

| ❌ 不能 | ✅ 必须 |
|---|---|
| 只看 PPT 不实操 | 每天必有"动手"环节 |
| 闭门讲理论 | W1-W2 就要见真实客户 |
| 学员"听课型" | 学员"主导型"（必须开口） |
| 1 对多大班 | 1 对 5 小班 |
| 师傅不参与 | 师傅全程陪跑 |
