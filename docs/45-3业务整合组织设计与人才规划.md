# 3 业务整合：组织设计 + 人才规划

> 用途：从 1 业务（钢厂主业）扩展到 3 业务（+ 钢贸 + 平台 + 数据）的组织演进  
> 配套：docs/32 轻量启动 + 3 业务组织架构 + tools/跨业务财务整合模型  
> 核心信条：**多业务公司死于"组织不分"——必须独立 KPI 独立团队，但共享平台**

---

# 第一部分：3 业务整合的"3 个关键决策"

## 决策 1：组织模式选择

### 模式 A：「**分公司 / 子公司模式**」
- 业务 1（钢厂 SaaS）= 子公司 A
- 业务 2（钢贸 SaaS）= 子公司 B
- 业务 3（平台 + 数据）= 子公司 C
- 集团总部统筹

**优势**：
- 独立 KPI / 独立法人
- 清晰的责任 + 文化
- 便于融资 + 估值

**劣势**：
- 协同效应弱
- 客户数据隔离
- 重复职能

**适合**：Y3 以后业务都达 ¥1 亿 ARR

### 模式 B：「**事业部模式**」（**推荐**）
- 一个法人公司
- 3 个事业部（各自总裁 / VP）
- 共享平台（IT / HR / 财务 / 法务）
- 总部协同

**优势**：
- 独立运营 + 共享平台
- 资源高效利用
- 协同效应好

**劣势**：
- 事业部之间可能冲突
- 总部统筹要强

**适合**：Y1-Y3 启动期 → 强烈推荐

### 模式 C：「**矩阵式组织**」
- 业务线 × 职能线交叉
- 销售 / CS / 产品 等共享

**优势**：
- 资源最优
- 协同最强

**劣势**：
- 汇报关系复杂
- 责任不清
- B 端创业期不适合

**适合**：成熟期 Y5+

### 推荐路径
```
Y1-Y2 事业部模式（模式 B）
   ↓
Y3-Y4 准事业部 → 子公司化（部分业务转 A）
   ↓
Y5+ 完全集团化（模式 A + 总部矩阵）
```

## 决策 2：事业部边界

### 业务 1 钢厂事业部
- **服务对象**：钢管 / 镀锌 / 一体 / 加工 4 类钢厂
- **收入来源**：ERP / MES / WMS / AI / 咨询 / 三位一体
- **目标**：Y3 ¥5,500 万

### 业务 2 钢贸事业部
- **服务对象**：钢贸商（流水 ¥3000 万 - ¥10 亿）
- **收入来源**：ERP / AI / 货袋子 / 接班咨询
- **目标**：Y3 ¥2.5 亿

### 业务 3 平台 + 数据事业部
- **服务对象**：买卖双方撮合 + 银行 / 保理 / 大买家
- **收入来源**：撮合佣金 + 增值 + 信用数据外卖
- **目标**：Y3 ¥5,300 万

### 边界划分铁律
| 维度 | 业务 1 | 业务 2 | 业务 3 |
|---|---|---|---|
| 客户 | 钢厂 | 钢贸商 | 撮合 + 数据买家 |
| 销售 | 独立 | 独立 | 独立 |
| CS | 独立 | 独立 | 共享 |
| 产品 | 独立 | 独立 | 独立 |
| 工程 | 共享（CTO 统筹）| 共享 | 共享 |
| 数据 | 独立 + 授权共享 | 独立 + 授权共享 | 跨业务数据池 |

## 决策 3：协同 vs 独立的"边界"

### 必须独立
- KPI（不能"和稀泥"）
- 销售团队
- CS 团队
- 客户档案

### 必须共享
- 技术中台 / 工程团队
- 数据中台
- 财务 / HR / 法务
- 公司战略 / 品牌

### 协同合作
- 客户引荐（业务 1 → 业务 2 / 业务 2 → 业务 3）
- 联合销售（三位一体方案）
- 跨业务客户管理（CRM 共享 + 标签独立）

# 第六部分：组织文化设计

## 6.1 三大文化（建议）

### 文化 1：「客户为中心」
- 所有决策从"客户怎么想"出发
- 销售 / CS / 产品都要见客户

### 文化 2：「数据驱动」
- 所有 KPI 公开透明
- 周战报 + 月复盘 + 季度评估
- 不用经验拍板，用数据决策

### 文化 3：「持续学习」
- 每月内部培训 4 小时
- 鼓励"读书 / 培训 / 外部交流"
- "你的成长 = 公司的成长"

---

## 6.2 文化落地的 5 个机制

| 机制 | 说明 |
|---|---|
| 周战报 | 每周一 9:00（详见 docs/18）|
| 月度大会 | 月底全员复盘 |
| 季度战略会 | CEO + 业务 VP |
| 半年 OKR | 全员对齐 |
| 年度优秀员工 | 业绩 + 文化双标准 |

| 规则 | 说明 |
|---|---|

| 7. 协同 KPI 单独评 | 不影响主业务 KPI |

# 第八部分：3 业务整合的「3 个失败陷阱」

## 陷阱 1：「合并管理」
- 把 3 业务塞给一个销售总监
- 看似省钱 → **必死**（每业务都做不好）

## 陷阱 2：「资源平均分」
- 3 业务各 33% 资源
- 实际：业务 1 是现金牛、业务 2 是增长引擎、业务 3 是战略投资
- **正确**：业务 1 30% / 业务 2 50% / 业务 3 20%

## 陷阱 3：「数据墙太低」
- 业务 1 钢厂订单数据**直接给**业务 2 平台
- 钢厂客户愤怒（商业秘密泄露）
- **必须用户授权 + 数据脱敏**

---

# 第九部分：5 句话给老板

1. **3 业务必须独立 KPI 独立团队** —— 合并管理 = 必死
2. **业务 2 钢贸总裁是最重要的招聘** —— Y2 营收主力，必须老板亲自找
3. **CTO 是技术命脉** —— Y1 就要找好，不能慢
4. **COO 在 M7 起招** —— 老板必须从"事事管"过渡到"事事看"
5. **期权池 15-20% 是合理范围** —— 给关键人才 + 全员激励
