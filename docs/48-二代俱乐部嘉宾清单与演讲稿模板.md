# 第一部分：3 类核心嘉宾

## 嘉宾类型 1：「主讲嘉宾」（最重要）—— 二代接班成功者

### 画像
- 35-45 岁
- 真正接班且**成功**（公司营收 ≥ ¥2 亿，接班 ≥ 3 年）
- 有故事感（不是低调派）
- 不是你方公司客户**最好**（更有公信力）

### 推荐人选清单（按地区）

#### 浙江
- **某焊管厂二代王总**（产值 ¥4 亿，接班 5 年）
- **某不锈钢管二代李总**（产值 ¥3 亿，接班 4 年）

#### 江苏
- **某镀锌厂二代陈总**（产值 ¥5 亿，接班 4 年）
- **某加工配送二代周总**（产值 ¥2.5 亿，接班 3 年）

#### 山东
- **某钢管厂二代孙总**（产值 ¥6 亿，接班 5 年）

#### 广东
- **某钢贸集团二代刘总**（产值 ¥8 亿，接班 6 年）

### 邀请话术
```
X 总，我们 9 月办「钢贸 2.0 · 二代说」第 1 期，
30 位二代闭门 1.5 天，
我们想请您做 90 分钟主讲嘉宾——
讲讲您接班 5 年的故事。

不需要您准备 PPT，
就是您自己的真实经历。

我们提供：
- ¥X 万 嘉宾费（具体面谈）
- 高铁 / 飞机往返 + 高端酒店
- 全场最高规格接待

您愿意吗？这群二代很想听您的故事。
```

### 嘉宾费建议
- 行业大佬级（产值 ≥ ¥5 亿）：¥15,000-30,000
- 中型成功二代（¥2-5 亿）：¥8,000-15,000
- 必须**对公开发票** + 5-8% 增值税

# 第三部分：「主讲嘉宾」演讲稿模板

## 3.1 90 分钟标准结构

```
0-5 min  寒暄 + 自我介绍
5-15 min "我接班前 我在想什么"
15-45 min "我接班的 12 个月：3 个错的、3 个对的"
45-60 min "我现在的反思 + 给在场二代 3 句话"
60-90 min Q&A
```

## 3.2 完整演讲稿（约 6000 字模板）

### 开场（5 分钟）

```
[嘉宾上台，自然不紧张]

各位老板朋友、各位二代朋友，
大家好，我是 X X X（XX 钢铁 / 钢贸董事长）。

[简单 1 句简介]
"我家做钢管 30 年，
我接班 5 年了，
公司现在年产值 4 亿。"

[拉近距离]
我今天来不是给大家讲'成功学'的——
我自己接班的时候吃了多少亏，
我把真话讲给在座二代听。

我儿子今年 28 岁，正在大学，
我希望他听完我今天讲的，
将来少走我的弯路。

[暖场，让二代笑出来]
```

### 第一段：「接班前我在想什么」（10 分钟）

```
2020 年我决定接班的时候，
我心里是有恐惧的。

▼ 第一个恐惧：我不行
我留学回来才 1 年，
我爸做了 30 年，
我懂什么？
我去车间，工人看我都像看小孩。

▼ 第二个恐惧：行业不行
那时候房地产开始下行，
钢贸利润越来越薄。
我朋友都在做互联网 / 金融，
都在劝我"别回来"。

▼ 第三个恐惧：我爸不放手
我爸表面上让我"管销售"，
但每个决定他还要拍板。
我做副总 1 年，
没真正决定过一件事。

[停顿]

[环顾在座二代]
你们有没有这种感觉？

[暖场 + 共鸣]
```

### 第二段：「我接班的 12 个月 - 3 个错」（15 分钟）

```
我接班后做错的 3 件事——

▼ 错事 1：第一个月我就"大刀阔斧"
我以为要"立威"——
开会就说"我们要转型 / 要数字化 / 要砍掉老员工"
结果团队几乎反水。

老员工说："小孩懂什么"，
我爸打电话来骂我"急什么"。

教训：第一个月**别动任何大事**，
先和团队建立关系。

▼ 错事 2：我以为"客户都得用我新的"
我接班后改了报价流程 + CRM，
让客户都通过系统询价。
结果 30% 老客户跑了——
他们说"我跟你爸打了 20 年电话，
现在还要给我搞这种东西？"

教训：客户改变要**慢、要个性化**，
不是一刀切。

▼ 错事 3：我以为"数字化能解决一切"
我花了 ¥100 万上系统，
以为数据出来就能赚钱。
结果系统跑起来发现——
人不会用、数据不准、流程没改。
钱白花了。

教训：**人 + 流程 + 系统**缺一不可，
数字化是工具，不是答案。

[停顿，让大家消化]
```

### 第三段：「3 个对」（15 分钟）

```
但是我也做对了 3 件事，
让我现在公司比我爸时候营收 +60%。

▼ 对事 1：我学会"先听 6 个月"
错事 1 之后，我闭嘴 6 个月。
天天在厂里、在销售面前、在客户面前——
我只问问题，不下结论。

6 个月后我才**真正懂这门生意**。

二代朋友们，你们一定要忍住——
**先听 6 个月**。

▼ 对事 2：找到我爸不会的事去做
我爸最强的是关系 + 经验。
我做不到。

我去做我爸做不到的事：
- 数据化（不是软件，是看数据决策）
- 出海（接出口订单 + 跨境）
- 引入互联网思维（线上拓客）

3 年后我做了 ¥1.5 亿增量营收——
这都是我爸做不出来的。

▼ 对事 3：让我爸有"面子"
我爸 60 岁了，
他最在意的不是钱，是面子。

我做的所有事都让他"光彩"——
公司变好了，
报纸上有他的名字，
朋友圈晒的是他的成就。

他越来越愿意放手。

[这一段最打动场内一代老板们]
```

### 第四段：「反思 + 3 句话给二代」（15 分钟）

```
我现在 5 年过去回头看——

我以前以为"接班 = 把老的换成新的"，
现在我知道"接班 = 把老的和新的都做好"。

我以前以为"我爸不行"，
现在我知道"我爸做的事 70% 我做不到"。

我以前以为"接班是辛苦的事"，
现在我知道"接班是有趣的事"——
看着公司一点点变好的成就感，
比互联网公司打工大 10 倍。

[停顿]

给在座二代 3 句话：

第 1 句：**先听 6 个月，再说话**。
冷静下来，你才看得到自己有什么、缺什么。

第 2 句：**找到你爸做不到的事**，
做好它。
你的价值在这里。

第 3 句：**让你爸"光彩"**，
他会让你"接班"得越来越顺。

[再停顿]

最后一句话——

我们这代人接班是有责任的：
中国钢铁这个行业，
有 8000 万人在里面工作，
有 6000 亿 GDP 在这里产生。

我们这代人做得好，
这个行业能多挺 30 年。
我们做不好——
这个行业就被淘汰。

不是我们一个人的事，
是我们一代人的事。

[最后停顿]

谢谢大家。

[鞠躬]
```

### 第五段：Q&A（30 分钟）

```
[主持人接过来]

谢谢 X 总。
现在大家可以提问，
也可以说说你们的感受。

[让二代自由提问，X 总自然回答]
```

## 3.3 嘉宾排练流程（T-7 天）

| 日 | 动作 |
|---|---|
| T-7 周 | 邀请确认 + 演讲方向沟通 |
| T-3 周 | 你方 CEO 与嘉宾 1 对 1 视频沟通（讲清楚活动调性）|
| T-1 周 | 嘉宾**完整排练 1 次**（你方 CEO + 销售总监旁听）|
| T-3 天 | 调整稿子（基于排练反馈）|
| T 日 | 正式演讲 |

# 第四部分：「跨界圆桌嘉宾」话题与脚本

## 4.1 圆桌话题（5 个，每个 15 分钟）

```
话题 1：未来 10 年钢贸还存在吗？
  - 一定存在但形态会变
  - 重资产 → 轻服务
  - 大批发 → 精细化

话题 2：互联网 + 金融 + 钢贸的融合点在哪？
  - 数据中台
  - 供应链金融
  - 客户共享

话题 3：二代独特机会在哪？
  - 整合分散行业
  - 用数据 + AI 改造
  - 出海 + 跨境

话题 4：二代最大的挑战是什么？
  - 一代的"放手"
  - 老员工的认同
  - 自己的耐心

话题 5：建议二代怎么做？
  - 学懂 6 个月
  - 找差异化
  - 做高价值的事
```
