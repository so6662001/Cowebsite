# 失败客户反向挽回 SOP（已失败 → 重新签约）

> 用途：把"已失败"客户系统化地"反向挽回"  
> 配套：docs/41 失败客户复盘框架 + tools/失败客户分析模板.xlsx  
> 核心信条：**失败客户 = 已经投入精力的客户**，挽回成本 < 新客户开发成本 70%

---

# 第一部分：为什么失败客户「值得」挽回

## 1.1 失败客户的真实价值

| 维度 | 新客户 | 失败客户 |
|---|---|---|
| 行业认知 | 0 | 已了解 |
| 对你方品牌的认知 | 0 | 已认知 |
| 信任建立时间 | 6-12 月 | 3-6 月 |
| 拜访次数（到成交）| 5-8 次 | 2-4 次 |
| 单客 CAC | ¥5 万 | **¥1.5 万** |
| 转化率 | 5-8% | **15-25%** |

**结论**：失败客户挽回 = 新客户开发的 **3 倍 ROI**

## 1.2 但是必须分类
**不是所有失败客户都值得挽回**——按 docs/41 的 7 大类型差异化处理。

# 第二部分：7 大失败类型的「挽回时点 + 难度」

| 类型 | 挽回最佳时点 | 挽回难度 | 推荐挽回率 |
|---|---|---|---|
| A 时机型（不是时候）| **6 个月** | ⭐ 低 | **40-60%** |
| B 价格型（嫌贵）| 3 个月 | ⭐⭐ 中 | 20-30% |
| C 价值型（没听懂）| 3-6 个月 | ⭐⭐ 中 | 25-35% |
| D 关系型（决策人变）| 立刻（30 天内）| ⭐⭐ 中 | 30-40% |
| E 信任型（怕失败）| 6-12 个月 | ⭐⭐⭐ 较高 | 15-20% |
| F 竞品型（竞品锁）| **12-24 个月** | ⭐⭐⭐⭐ 高 | 5-10% |
| G 内部型（团队反对）| 6-12 个月（等组织变）| ⭐⭐⭐ 较高 | 15-25% |

# 第三部分：A 类「时机型」挽回 SOP（占比最大，最易挽回）

## 3.1 客户特征
- 客户认可产品，但"今年不投系统"
- 一般是：财务紧张 / 内部优先级冲突 / 没有迫切痛点

## 3.2 6 个月挽回路径

### 阶段 1：T+0 到 T+90 天 — 保持联系（不主动卖）

#### T+0（失败那天）
- CS 总监 / 销售总监**亲自打电话**："X 总，理解您的决定，我们 6 个月后再聊"
- 客户档案标记 **#A 时机型，6 月再启动**
- CRM 设置"T+180 自动提醒"

#### T+30
- 销售员**朋友圈互动**（点赞 + 偶尔评论）
- 不发产品，发**行业资讯**

#### T+60
- 发 1 篇行业深度文章给客户
- **不卖东西**，只说"看您可能感兴趣"

#### T+90
- 客户**生日 / 节日**祝福
- **不要群发**，必须个性化

### 阶段 2：T+90 到 T+180 — 价值递送

#### T+120
- 发 1 个**同行案例**（行业 / 区域同行）
- 文案："您看 X 同行最近这么做，我觉得您可能想看看"

#### T+150
- 邀请客户参加**老板局 / 行业活动**
- 不直接卖，但让客户"看见"你方公司的"势能"

#### T+180（关键节点）
- **重新启动销售**
- 销售总监 / 老板**亲自电话**："X 总，6 个月过去了，我们再聊聊？"

### 阶段 3：T+180+ — 重启销售

#### 重启拜访话术
```
X 总，6 个月前我们聊过 X X 产品您说"今年不投"——

我们 6 个月没打扰您，
但我一直在朋友圈看您：

- 您 X 月接了 X X 客户
- 您 X 月发了"今年压力大"的朋友圈
- 您 X 月跟 X 同行去 X 地参观

我觉得现在可能是合适时机了。

我这次来不是卖东西的——
我带了 1 份给您"专属定制"的方案，
是基于您 6 个月里的动态做的。

您看哪天我去您那儿 1 小时？
```

## 3.3 A 类挽回转化率提升技巧

- **送 30 天免费试用**（之前没给的话）
- **首付分 12 期免息**（解决资金压力）
- **"6 个月观察期"**（前 6 月效果不达标退款）

# 第四部分：B 类「价格型」挽回 SOP

## 4.1 客户特征
- 嫌贵 / 比竞品贵
- 通常不是真的"没钱"，是"没看到价值"

## 4.2 3 个月挽回路径

### T+30：第 1 次接触
- 发**ROI 计算器** PDF
- 让客户**自己算**他用了之后省多少钱

### T+60：第 2 次接触
- 发**竞品对比手册**
- 客观对比（不踩竞品）

### T+90：重启销售
- **新的报价方案**：
  - 方案 A：原价 + 送 1 年增值
  - 方案 B：分期付款（12-24 期）
  - 方案 C：种子版（更便宜的入门）
- **必须出 3 个版本让客户选**

## 4.3 B 类挽回的 3 个杀手锏

### 杀手锏 1：「ROI 算给客户看」
```
X 总，6 月前您说"贵"——
但我们算给您看：

您年流水 ¥2 亿，
我们 ¥10 万 / 年的方案
省 1% 成本 = ¥200 万

¥10 万 vs ¥200 万 = 20 倍 ROI

您愿意花 ¥10 万换 ¥200 万吗？
```

### 杀手锏 2：「同行老板背书」
让灯塔客户老板**亲自打电话**说："X 总你别比价了，我用 1 年这个东西真值。"

### 杀手锏 3：「分期 + 兜底」
- 24 期分期免息
- 6 个月不达标退款
- "其实您不用一次性掏 ¥10 万"

# 第五部分：C 类「价值型」挽回 SOP

## 5.1 客户特征
- 没听懂"为啥要花这钱"
- 销售当时讲产品没讲价值

## 5.2 改进路径

### T+30：换销售
- **必须换销售员**（原销售已被客户标记"差"）
- 由销售总监 / CS 总监接手

### T+60：重新做"诊断"
- 上门做**健康度自评 30 题**
- 让客户**自己发现痛点**
- 不是销售讲，是客户讲

### T+90：基于诊断推荐
- 不卖**产品**
- 卖**解决方案**（针对客户痛点）

## 5.3 C 类挽回必带的 3 件物料
1. 健康度自评表（30 题，钢贸版 / 钢厂版）
2. 5 个客户故事 PDF
3. 行业白皮书

# 第六部分：D 类「关系型」挽回 SOP（响应必须快）

## 6.1 客户特征
- 决策人换了 / 关系人离职
- 必须**立刻**响应（30 天黄金期）

## 6.2 30 天挽回路径

### T+7（关键！）
- 通过**多种渠道**找新决策人
- 销售总监 + 老板**主动接触**

### T+14：重新建立关系
- 上门 / 视频会议
- **不卖产品**，只问"您怎么看 X X 业务"

### T+30：重新报价
- 给新决策人**新的方案**
- 不是接着上一次的报价（让对方有"主导感"）

## 6.3 D 类挽回必避的事

| ❌ 不能 | 原因 |
|---|---|
| 提"上次我们和 X X 总聊过" | 让新决策人不舒服 |
| 直接重启销售 | 关系还没建立 |
| 不主动接触 | 错过 30 天黄金期 |

# 第七部分：E 类「信任型」挽回 SOP

## 7.1 客户特征
- 之前买过系统失败 / 怕花钱白搭

## 7.2 6-12 个月挽回路径

### 长期关系建设（不急销售）
- T+30 朋友圈互动
- T+90 邀请参加客户参观日
- T+180 邀请加入"客户俱乐部"
- T+360 老板局邀请

### 杀手锏：「极致风险逆转」
- 30 天免费 + 6 月不达标退款 + 实施费 50% 兜底
- "您完全没有风险，连 1 块钱也不用付"

# 第八部分：F 类「竞品型」挽回 SOP（最难）

## 8.1 客户特征
- 已用竞品（找钢网 / 用友 / 金蝶）

## 8.2 不要急 — 等"竞品出问题"

### 监控竞品动态
- 行业群 / 朋友圈
- 客户员工的吐槽
- 竞品价格上涨 / 产品迭代慢 / 服务差

### 等待时机
- 客户**主动抱怨**竞品时
- 竞品**重大事件**（涨价 / 创始人变动 / 服务出问题）
- 客户**业务模式变化**（新业务竞品不支持）

## 8.3 时机来时的「24 小时响应」

```
X 总，听说您和 X 竞品最近有些不顺——

我不是来抢您的——
您先告诉我您现在最大的痛是什么。

我们能帮您解决就帮，
不能帮就推荐别的方案，
不勉强。

您方便聊 30 分钟吗？
```

## 8.4 F 类挽回的「迁移工具包」

- **数据迁移服务**（免费帮客户从竞品迁移）
- **双系统并行 30 天**（不影响业务）
- **首年价格 5 折**（竞品迁移特殊优惠）

# 第九部分：G 类「内部型」挽回 SOP

## 9.1 客户特征
- 老板想买 / 中层反对
- 中层担心**被替代** / 失去权力

## 9.2 处理路径

### 找到"内部代言人"
- 不是反对的中层
- 是**最痛**的部门（如财务 / 风控）
- 培养他成为"我方代言人"

### 降低反对者损失
- 强调"AI 是辅助工具，不替代人"
- 强调"用了之后 X X 中层会更轻松"
- 提供**中层个人成长资源**（培训 / 行业会议门票）

### 等组织变化
- 反对者离职 / 调岗 → 重启
- 6-12 个月观察期

# 第十一部分：「永久放弃」的客户

## 11.1 什么时候放弃

| 条件 | 触发 |
|---|---|
| 6 次接触无响应 | 30 天后再 1 次，不行就放 |
| 客户明确说"永不合作" | 立刻放 |
| 客户公司倒闭 / 跑路 | 标记关停 |
| 客户老板换人 + 新人拒绝 | 6 月观察期，仍拒绝放 |

## 11.2 放弃不等于完全清零

- 客户档案保留
- CRM 标记"长尾"
- 每 6 个月**自动化邮件**保持联系
- 业务模式变化时**重新评估**

# 第十三部分：客户挽回话术总集

## 通用开场（所有类型）
```
X 总，我们 X 月前聊过 X X 项目您没决定——
我打这通电话**不是来重新推销的**，
是想问您 3 个真心话：
1. 您当时为什么没决定？
2. 现在情况有变化吗？
3. 什么情况下您会重新考虑？

[听完后再决定下一步]
```

## A 类挽回话术（时机型）
```
X 总，我注意到您 X 月做了 X X 事——
看起来您今年的状态比 6 月前好多了。

我有 1 个想法，
不卖产品，只是分享：
您看 X X 钢贸（同行）这种情况是怎么处理的——
他们这个动作让我想到您。

您要不抽 30 分钟我跟您说说？
```

## B 类挽回话术（价格型）
```
X 总，您说"贵"，我后来想了很久——
我们有 1 个新方案，
价格是原来的 60%，
但保留 80% 的功能。

您看可以吗？
我下周三去您那儿 1 小时。
```

## D 类挽回话术（关系型）
```
X 总，您好（新决策人）。
我是 X X 公司的 X，
之前跟您前任 X X 总聊过 X X 项目，
当时没决定。

我打这个电话**完全不是接着上次的**——
您是新的决策者，
我想重新听您的想法。

您方便聊 30 分钟吗？
```
