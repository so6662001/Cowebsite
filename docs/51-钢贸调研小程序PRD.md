# 钢贸版 30 题调研 微信小程序 PRD

> 用途：把 tools/steeltrade_survey.html 升级为微信小程序  
> 配套：docs/46 调研问卷线上化方案  
> 开发预算：¥5-10 万 / 周期 4-6 周

# 第一部分：产品定位

## 1.1 一句话定义
> **微信小程序**，让钢贸老板**扫码 5 分钟**自评 + 立刻拿 PDF 报告 + 自动留资到 CRM

## 1.2 与现有 HTML 单页的差异

| 维度 | HTML 单页（已交付） | **微信小程序（本 PRD）** |
|---|---|---|
| 部署 | 服务器静态托管 | 微信小程序云 + 后端 |
| 留资 | 截图 / 私聊销售 | **自动入 CRM** |
| 分析 | 无 | **后台统计 + 客户洞察** |
| 销售跟进 | 销售运营手动分配 | **自动分配 9 销售** |
| 复访 | 无 | **同一客户多次测评对比** |
| 数据沉淀 | 无 | **行业数据库 + 报告** |
| 老板看 | 无 | **每月行业景气报告** |

## 1.3 目标用户

### 主要用户
- **钢贸老板**（45-65 岁）—— 填问卷
- **二代 / 副总**（25-40 岁）—— 看报告
- **你方销售**（9 人）—— 跟进客户
- **你方运营** —— 后台管理

### 次要用户
- 行业研究员（看月度报告）
- 政府 / 协会（看区域报告）

# 第三部分：核心页面设计

## 3.1 首页（钢贸老板入口）

### 视觉风格
- 钢铁工业蓝 + 大字号（45-65 岁老板用）
- 不超过 3 个核心按钮
- 一图读懂"我能在这里干什么"

### 核心元素
```
[Banner] "5 分钟测出您的钢贸健康度"
        子文案："已有 X 位钢贸老板完成"

[主按钮] 开始测评（30 题）

[次按钮] 我的报告  |  行业月报  |  预约专家

[底部] 关于我们 | 客服 | 免责
```

## 3.2 测评流程

### 流程 1：基础信息（4 题）
```
[1/4] 您的公司名称是？  
[2/4] 您的主营业务？（4 选 1）
[3/4] 您的年流水范围？（5 选 1）
[4/4] 您的联系方式？
```

### 流程 2：30 题（7 模块）
- 每题 1 屏（手机端）
- 进度条 + 模块标识
- 单选模式
- 支持上一题 / 下一题
- 自动保存（中断后可继续）

### 流程 3：结果页
```
[评分大卡]
您的总分：X / 150
等级：A / B / C / D

[7 模块雷达图]
（可视化）

[7 模块进度条]
（数字 + 颜色）

[痛点 TOP 3]
（个性化推荐）

[解决方案]
（推荐套餐 + 联系销售）

[操作]
- 下载 PDF
- 分享给老板
- 预约专家
```

## 3.3 我的报告

### 历史测评
- 时间轴展示
- 同一客户**多次测评对比**
- 看见"半年前到现在"的变化

### PDF 报告
- 一键下载（≤ 3 秒）
- 含客户名 / 评分 / 雷达图 / 推荐 / 联系销售

### 行业对标
- 您的分数 vs 行业平均
- 您的分数 vs 同段（S/A/B/C）平均
- 您的分数 vs 同地区平均

## 3.4 行业月报（每月自动生成）

### 内容结构
```
[封面] 钢贸行业 X X 月健康度报告

[1] 整体数据
- 本月测评客户数
- 行业平均分
- 月度变化

[2] 7 模块行业分布

[3] 最痛 TOP 3 困境
- 数据图表
- 案例分析

[4] 区域对比
- 长三角 / 珠三角 / 京津冀

[5] 升级建议
（自动 + 人工编辑）
```

# 第五部分：数据流转

## 5.1 客户填问卷的数据流

```
客户扫码进入
    ↓
微信授权（OpenID + 手机号）
    ↓
基础信息（4 题）→ 后端
    ↓
30 题（实时保存到云端，防中断）
    ↓
评分计算 → 实时展示
    ↓
PDF 生成（后端）→ 推送给客户
    ↓
客户信息入 CRM
    ↓
按规则自动分配 9 销售
    ↓
销售收到企业微信通知
    ↓
销售上 CRM 跟进
```

## 5.2 销售跟进数据流

```
销售收到通知 → 进 CRM 查看客户
    ↓
预约客户拜访
    ↓
拜访记录 → CRM
    ↓
进展更新（试用 / POC / 签约 / 失败）
    ↓
销售总监周战报看
    ↓
老板月战报看
```

# 第六部分：销售自动分配规则

## 6.1 分配维度

### 维度 1：客户段
| 段 | 优先分配 |
|---|---|
| S（年流水 > ¥10 亿）| 大客户销售 A1/A2/A3 |
| A（¥3-10 亿）| 大客户销售 A1/A2/A3 |
| B（¥1-3 亿）| 中端销售 B1/B2/B3 |
| C（< ¥1 亿）| 电销销售 C1/C2/C3 |

### 维度 2：客户地区
| 地区 | 优先分配 |
|---|---|
| 长三角 | A2 / B1 / C1 |
| 珠三角 | A1 / B2 / C2 |
| 京津冀 | A3 / B3 / C3 |
| 山东 | A1 / B1 |
| 其他 | 老板 + 销售总监仲裁 |

### 维度 3：客户痛点
| 痛点 | 优先分配 |
|---|---|
| 接班场景 | 接班咨询团队 + 业务总监 |
| 高分（≥ 120）| 老板亲自接 |
| 低分（< 60）| 急救销售队 |

## 6.2 分配机制

### 自动分配（80% 客户）
- 按规则**5 秒内自动分配**
- 销售收到企业微信通知
- 30 分钟内必须响应

### 人工分配（20% 高价值客户）
- 老板 / 销售总监**审核**
- 安排最强销售

# 第七部分：自动化运营

## 7.1 短信 / 微信触发

### 客户填完问卷
- **5 秒内**短信："已收到，专家 1 工作日内联系"
- **30 分钟内**销售加微信
- **24 小时内**销售电话回访

### 客户未填完中断
- 24 小时后**短信提醒**："还差 X 题，5 分钟搞定"
- 7 天后**销售主动联系**

### 客户填完未跟进
- 销售 3 天未联系 → **销售总监预警**
- 7 天未联系 → **老板预警**

### 行业月报推送
- 每月 1 日**自动推送**给所有客户
- 个性化（含客户名 + 评分对比）

## 7.2 复访机制

- 客户填完后**6 个月**自动提醒"重新测一次"
- 看见"我半年提升了多少"
- **数据沉淀** = 客户成功的可视化

# 第八部分：数据隐私 + 合规

## 8.1 用户授权
- 微信授权（OpenID + 手机号）
- **明确告知**：数据用于服务 + 行业研究（脱敏）
- 用户可**随时删除**自己的数据

## 8.2 数据加密
- 传输：HTTPS
- 存储：加密
- 备份：每日 + 异地

## 8.3 合规
- 《个人信息保护法》合规
- 用户协议 + 隐私政策（必须有）
- 数据**仅用于服务**，不卖给第三方（外卖时必须脱敏 + 老板审批）
