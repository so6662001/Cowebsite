# 第四部分：剪辑标准（重要！）

## 4.1 剪辑铁律

| ❌ 不能 | ✅ 必须 |
|---|---|
| 摆拍痕迹明显 | 自然纪实风 |
| 字幕字小 | 字号 ≥ 48pt（手机看）|
| 数据浮夸 | 真实数据，可验证 |
| 客户名露脸 | **必须客户书面同意** |
| 背景音乐喧宾夺主 | 音乐音量 < 旁白 50% |

## 4.2 剪辑节奏

- 0-3 秒：**钩子**（最痛点）
- 4-15 秒：**故事场景**
- 16-90 秒：**关键转折**
- 90-150 秒：**数据结果**
- 150-180 秒：**客户原话**（最有说服力）

## 4.3 字幕规范
- 简体中文
- 字号 ≥ 48pt
- 描边 1pt（防止背景干扰）
- 关键数据**红色高亮**
- 客户原话**引号 + 加粗**
