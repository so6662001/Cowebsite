# 第一部分：CRM 分级是什么？

## 1.1 CRM 分级的定义

**CRM 分级 = Customer Relationship Management 客户关系管理 + 客户分级管理**

> **不是把客户简单分 A/B/C 段**——而是基于**多维度数据**给客户打"标签 + 分数"，让销售知道：
> - 哪些客户**值得花精力**（A 级）
> - 哪些客户**该砍掉**（D 级）
> - 哪些客户**有潜力**（B 级，重点培养）
> - 哪些客户**有风险**（红色预警）

## 1.2 钢贸客户的「5 维度分级模型」

| 维度 | 权重 | 数据来源 |
|---|---|---|
| ① **价值维度**（年采购额）| 25% | 历史订单 |
| ② **利润维度**（贡献毛利）| 25% | 财务数据 |
| ③ **付款维度**（信用 / 应收）| 20% | 应收账款 |
| ④ **粘性维度**（合作年限 / 频次）| 15% | 订单频率 |
| ⑤ **潜力维度**（增长 / 发展空间）| 15% | 行业趋势 + 客户业务 |

### 综合评分公式
```
客户分数 = 价值 × 0.25 + 利润 × 0.25 + 付款 × 0.20 + 粘性 × 0.15 + 潜力 × 0.15
       范围：0-100 分
```

## 1.3 CRM 分级的 5 级标签

| 等级 | 分数 | 描述 | 销售动作 |
|---|---|---|---|
| **S 钻石** | ≥ 85 | 高价值 + 高利润 + 高付款 + 高粘性 | 老板亲自维护 + 月度上门 |
| **A 黄金** | 70-84 | 主力客户 | 销售总监主跟 + 双周维护 |
| **B 白银** | 55-69 | 一般客户 | 销售员维护 + 月度跟进 |
| **C 青铜** | 40-54 | 低价值 / 低利润 | 自动化维护 + 季度跟进 |
| **D 警示** | < 40 | 高风险（应收逾期 / 不付款） | **冻结订单 + 法务介入** |

## 1.4 CRM 分级与 4 段客户的区别

| 维度 | 4 段（S/A/B/C 段） | CRM 分级（S/A/B/C/D）|
|---|---|---|
| 含义 | 按**年流水规模** | 按**综合价值 + 风险** |
| 作用 | 决定销售资源分配 | 决定**对单个客户**的服务策略 |
| 范围 | 1500 个客户全划分 | 每个客户的客户都分级 |
| 例子 | 某钢贸商年流水 ¥3 亿 = A 段 | 该钢贸商的 200 个客户里，每个再分 S/A/B/C/D |

**简单说**：4 段 = 我方对客户的分级；CRM 分级 = 客户对自己客户的分级。

## 1.5 CRM 分级解决的困境

| 困境 | 如何解决 |
|---|---|
| 困境 1 利润压缩 | 砍 D 级、保 S/A 级 → 整体毛利 +0.5-1.5% |
| 困境 2 应收账款 | D 级 = 冻结订单（避免坏账）|
| 困境 4 客户结构变化 | 看 5 维度变化趋势 → 提前预警客户流失 |
| 困境 8 销售跑单 | 客户数据全在系统（不在销售脑子里）|

### 钢贸行业特化设计

#### 特化 1：动态利润调整
- 钢价上涨 → 自动**保留利润空间**（避免被客户压价）
- 钢价下跌 → 提示销售**抢单**

#### 特化 2：客户分级定价
- S 客户：让 2% 利润保关系
- D 客户：不让利 + 加风险溢价

#### 特化 3：加工成本动态化
- 开平 / 纵剪 / 拉伸 / 抛光 各自单价
- 损耗率不同（开平 1-2% / 纵剪 0.5-1.5%）

### 关键算法
```python
def smart_pricing(order):
    # 1. 基础成本
    raw_cost = steel_factory_price * weight
    transport = distance * unit_freight * weight
    processing = process_cost(order.process_type, weight)
    invoice_cost = base_price * invoice_rate  # 6% / 13% 增值税
    capital_cost = base_price * funding_days * interest_rate / 365
    
    total_cost = raw_cost + transport + processing + invoice_cost + capital_cost
    
    # 2. 客户分级利润
    profit_rate = get_customer_profit_rate(order.customer_id)
    # S: 0.05-0.08 / A: 0.03-0.05 / B: 0.02-0.03 / C: 0.01-0.02
    
    # 3. 风险溢价
    risk_premium = get_risk_premium(order.customer_id)  # D 级 +1-3%
    
    # 4. 市场调整
    market_factor = get_market_factor()  # 钢价上涨期 +0.5%
    
    # 5. 三档报价
    base_price = total_cost * (1 + profit_rate + risk_premium + market_factor)
    return {
        "min": total_cost * 1.005,  # 保本
        "recommended": base_price,
        "max": base_price * 1.05,
    }
```

- 年流水 ¥1 亿 → 年增 ¥50-150 万

### 关键算法

```python
def credit_score(customer):
    score = 50  # 基础分
    
    # 1. 工商信息（权重 15%）
    if customer.registered_capital > 10_000_000:  # 1000 万+
        score += 10
    if customer.years_in_business > 10:
        score += 8
    
    # 2. 付款历史（权重 35%，最重要）
    avg_pay_days = customer.average_payment_days
    if avg_pay_days < 30:
        score += 20
    elif avg_pay_days < 60:
        score += 10
    elif avg_pay_days > 90:
        score -= 15
    
    # 3. 当前应收账款（权重 20%）
    overdue_ratio = customer.overdue_amount / customer.total_receivables
    if overdue_ratio > 0.3:
        score -= 15
    
    # 4. 行业风险（权重 15%）
    industry_risk = {
        "real_estate": -10,
        "construction": -5,
        "automotive": +8,
        "appliance": +5,
    }
    score += industry_risk.get(customer.industry, 0)
    
    # 5. 外部风险（权重 15%）
    if customer.has_lawsuit_record:
        score -= 20
    if customer.is_default_listed:
        score -= 30  # 失信，直接 D 级
    
    return max(0, min(100, score))


def risk_level(score):
    if score >= 80: return "A"
    elif score >= 65: return "B"
    elif score >= 50: return "C"
    else: return "D"


def real_time_alert(customer):
    alerts = []
    # 关联企业风险
    if any_related_company_in_default(customer):
        alerts.append("关联企业失信，建议立刻冻结")
    # 付款异常
    if customer.last_payment_delay > 30:
        alerts.append(f"付款延迟 {customer.last_payment_delay} 天")
    # 订单异常
    if customer.recent_order_increase > 200:  # 突然增 200%
        alerts.append("订单突增异常，可能跑路前囤货")
    return alerts
```

- 减少坏账 60-80%

def credit_model(customer):
    scores = {
        "工商": customer.business_score() * 0.15,
        "经营": customer.operation_score() * 0.20,
        "付款": customer.payment_score() * 0.20,
        "应收": customer.receivables_score() * 0.10,
        "库存": customer.inventory_score() * 0.05,
        "销售": customer.sales_stability_score() * 0.05,
        "客户": customer.client_structure_score() * 0.10,
        "数字化": customer.digital_score() * 0.05,
        "法律": customer.legal_score() * 0.05,
        "行业": customer.industry_relation_score() * 0.05,
    }
    return sum(scores.values()) * 10  # 转 1000 分制


def credit_grade(score):
    grades = [
        (850, "AAA"), (700, "AA"), (600, "A"),
        (500, "B"), (400, "C"), (0, "D"),
    ]
    for threshold, grade in grades:
        if score >= threshold:
            return grade
```

def predict_next_order(customer):
    # 基于历史订单频率 + 季节性
    avg_interval = customer.average_order_interval
    last_order_days = customer.days_since_last_order
    
    if last_order_days > avg_interval * 0.8:
        confidence = (last_order_days / avg_interval - 0.8) * 100
        return {
            "predicted": True,
            "confidence": min(confidence, 95),
            "suggested_action": "立刻联系，可能即将下单"
        }


def churn_alert(customer):
    signals = []
    if customer.order_decline_90d > 0.5:
        signals.append("订单量 90 天下降 50%+")
    if customer.inquiry_decline_90d > 0.5:
        signals.append("询价频率下降 50%+")
    if customer.contact_changed:
        signals.append("核心联系人变更")
    
    if len(signals) >= 2:
        return {"churn_risk": "HIGH", "signals": signals}
```
