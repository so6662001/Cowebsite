# 30 题评分销售角色扮演视频脚本（培训用）

> 用途：CS / 销售培训视频拍摄  
> 形式：1 个 25 分钟完整版（5 个场景 × 5 分钟）+ 5 个独立场景视频（独立可看）  
> 拍摄预算：¥3-5 万 / 完整套（含演员 + 场地 + 后期）

---

# 第一部分：5 个场景设计

| 场景 | 适合 | 时长 |
|---|---|---|
| 场景 1：温和老板（A 级，配合）| 入门销售培训 | 5 分钟 |
| 场景 2：抗拒老板（B 级，强势）| 中级销售培训 | 5 分钟 |
| 场景 3：故意打高分（C 级，狡猾）| 高级销售培训 | 5 分钟 |
| 场景 4：低分但不愿承认 | 心理战培训 | 5 分钟 |
| 场景 5：接班场景（一代 + 二代同场） | 综合培训 | 5 分钟 |

**总时长**：25 分钟完整版 + 5 个独立片段

# 场景 1：温和老板（最常见）

## 演员设置
- **客户老板（张总）**：48 岁，钢管厂老板，年流水 ¥2 亿，温和配合
- **销售（小李）**：32 岁，公司销售总监

## 拍摄分镜

| 时间 | 画面 | 台词 | 动作要点 |
|---|---|---|---|
| 0:00-0:15 | 张总办公室全景 + 小李进门 | （客气）"小李，你来了，坐坐坐。" | 自然 |
| 0:15-0:30 | 小李坐下 + 拿出 iPad | "张总，我今天不卖东西——就 30 道题，5 分钟看您在行业的位置。" | 不急 |
| 0:30-1:00 | 张总 iPad 自答 + 小李陪问 | "好，您说说。"<br>"题 1：您今年毛利率是多少？" | 屏幕特写 |
| 1:00-1:30 | 张总皱眉答题 | "（停顿）3-5% 吧。"<br>（选 3-5%，3 分）<br>"您去年是多少？"<br>"4.5% 吧" | 老板皱眉 |
| 1:30-2:00 | 小李陪问延伸 | "您觉得为啥下降？" | 倾听 |
| | | "建材客户回款慢" | |
| | | "建筑装修客户占多少？" | |
| | | "60% 吧"（选 < 10%，1 分）| |
| 2:00-2:30 | 答应收账款部分 | "题 6：90 天+ 应收占比？"<br>张总沉默 5 秒："37% 吧"（选 25-40%，2 分） | 沉默 5 秒（真实感）|
| 2:30-3:00 | 关键时刻 | 小李："X 总，37% 是行业警示线，您身边 X X 钢贸赵总当时 38% 差点关门。" | 镜头特写客户表情 |
| 3:00-3:30 | 客户答 30 题 | 快速过完 30 题 | 时间流逝感 |
| 3:30-4:00 | 出报告 + 雷达图 | 屏幕显示：78 分 / C 级 / 7 模块雷达图 | 报告全屏 |
| 4:00-4:30 | 销售推荐方案 | "X 总，您 3 个红区年损失约 ¥X 万——我们方案 ¥X 万，3 个月回本。" | 方案展示 |
| 4:30-5:00 | 客户决定 | "我先试试 30 天免费试用。" | 自然结束 |

## 标注重点（培训提示）

| 时间点 | 学习要点 |
|---|---|
| 0:15 "不卖东西" | **铁律 1**：开场必须降低戒心 |
| 1:30 "您觉得为啥下降" | **铁律 2**：每题必有延伸问 |
| 2:00 客户沉默 5 秒 | **铁律 3**：允许沉默（不催）|
| 2:30 "X 钢贸赵总" | **铁律 4**：同行案例必引用 |
| 4:00 "3 个月回本" | **铁律 5**：必须算 ROI |

## 销售复盘提问

视频结束后**销售自问**：
- 我开场是否够"放低"？
- 我是否陪问够深？
- 我是否引用了案例？
- 我是否算 ROI？
- 我是否给"风险逆转"承诺？

# 场景 2：抗拒老板（强势）

## 演员设置
- **抗拒老板（陈总）**：58 岁，钢贸老板，年流水 ¥3 亿，强势 + 不愿意被"测评"
- **销售（小王）**：经验丰富的销售总监

## 拍摄重点

| 时间 | 关键冲突 + 应对 |
|---|---|
| 0:00-0:30 | 陈总开场抗拒："你们这些卖系统的别浪费我时间" |
| 0:30-1:00 | 小王不急："X 总，我不是来卖东西的——就 5 分钟，您觉得我说错了再赶我走。" |
| 1:00-2:00 | 陈总半信半疑开始答题，但**故意答得很模糊** |
| 2:00-3:00 | 小王陪问，**温和但精准**："您说大致清楚——能告诉我您 TOP 5 客户的毛利率吗？" |
| 3:00-4:00 | 陈总**沉默**，意识到自己其实不清楚 |
| 4:00-5:00 | 小王**不戳穿**："我们 [XX 钢贸] X 总也是这样，他后来发现……" |

## 培训提示
- **铁律 1**：永远不要"硬抢话语权"，让客户**主动发现自己的问题**
- **铁律 2**：陪问要"挑战式但温和"
- **铁律 3**：客户沉默时**不接话**，让他自己"翻案"

# 场景 3：故意打高分（最有挑战）

## 演员设置
- **狡猾老板（张总）**：47 岁，做钢贸 20 年，**故意全部 5 分**
- **销售（高级销售总监）**

## 拍摄重点

| 时间 | 关键技巧 |
|---|---|
| 0:00-1:00 | 张总快速答题，**全选 5 分**，看小张反应 |
| 1:00-2:00 | 小张**温和质疑**："X 总，您是行业 TOP 1%——您愿意让我们参观您的工厂吗？" |
| 2:00-3:00 | 张总**改口**："其实有些地方……（开始松口）" |
| 3:00-4:00 | 小张**陪问细节**："您说库存账实差 < 1%——上次盘点发现差了多少？" |
| 4:00-5:00 | 张总**主动承认**："其实差 3%，我让他们改了数据。" |

## 培训提示
- **不戳穿**但**让客户松口**
- **细节问题**让客户没法继续"答 5 分"
- **不要直接说"您撒谎"**，要"我相信您"+ 细节追问

# 场景 4：低分但不愿承认

## 演员设置
- **要面子的老板（李总）**：62 岁，公司其实濒临倒闭，但**死撑面子**
- **销售（资深销售总监）**

## 拍摄重点

| 时间 | 关键技巧 |
|---|---|
| 0:00-1:00 | 李总答题时**眼神躲闪**，但**全选 3-4 分** |
| 1:00-2:00 | 销售看出来 → **不答题，先聊家常** |
| 2:00-3:00 | 销售："X 总，您今年生意怎么样？"<br>李总（沉默）："还行……" |
| 3:00-4:00 | 销售**真诚说**："X 总，我也是钢贸圈出来的，今年大家都不好过——您要不要跟我说说真实情况？" |
| 4:00-5:00 | 李总**情绪软化**：开始说真话 |

## 培训提示
- **建立信任**比"完成测评"更重要
- **真诚 + 同理心**是最强武器
- **不评判**客户的"低分"

# 场景 5：接班场景（一代 + 二代）

## 演员设置
- **一代周总**：60 岁，传统派
- **二代周小公子**：30 岁，海归
- **销售（业务总监）**

## 拍摄重点

| 时间 | 关键技巧 |
|---|---|
| 0:00-1:00 | 销售**同时面对一代 + 二代**："今天我想分别问您们" |
| 1:00-2:00 | 销售先问**一代**：传统问题（财务 / 应收 / 销售）<br>周总自答 |
| 2:00-3:00 | 销售问**二代**：数字化问题（系统 / 客户 / 数据）<br>周小公子自答 |
| 3:00-4:00 | 出**双视角报告**：<br>- 一代看到的："营收稳定"<br>- 二代看到的："增长乏力 + 系统老旧"<br>**两人当场讨论** |
| 4:00-5:00 | 销售**不站队**："您俩说的都对——我们方案是让您俩都'看见'同一个数据" |

## 培训提示
- 接班场景**必须双方都谈**
- **不站队**（一代二代各有道理）
- **数据是桥梁**（让双方有共同语言）

# 第三部分：剪辑标准

## 3.1 5 个分剪版本

| 版本 | 时长 | 用途 |
|---|---|---|
| 完整版 | 25 分钟 | 销售培训会用 |
| 单场景 ×5 | 5 分钟 / 个 | 单独学习用 |
| 浓缩版 | 8 分钟 | 季度大会用 |
| 短视频版 ×5 | 60 秒 / 场景 | 朋友圈传播 |
| 抓眼版 | 30 秒 | 抖音 / 视频号 |

## 3.2 剪辑铁律

| ❌ 不能 | ✅ 必须 |
|---|---|
| 摆拍痕迹 | 真实纪实 |
| 配音字幕只贴一种字 | 客户原话**红字 + 引号** |
| 一镜到底 | 多机位切换（销售脸 / 客户脸 / 屏幕）|
| 背景音乐喧宾夺主 | 音乐 < 对话 |
| 销售单向输出 | 客户和销售对话节奏 50:50 |

## 3.3 字幕设计

- **简体中文**
- 字号 ≥ 48pt
- 关键数据**红色加粗**
- 客户原话**引号**
- 培训提示**右下角弹出**

# 第四部分：5 个场景的「培训用法」

## 4.1 销售新人培训（W1）

- 看完整版（25 分钟）
- 总结销售必备的"5 大铁律"
- 角色扮演 1-2 个场景

## 4.2 销售中级培训（M3）

- 单独学习场景 2-3（抗拒 / 高分）
- 每个销售挑 1 个最难的客户做"模拟拜访"
- 录音回放

## 4.3 高级销售培训（M6）

- 场景 4-5（最难）
- 实战 + 老板亲自带教
