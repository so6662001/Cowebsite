## 2.1 7 模块对比表

|---|---|---|---|---|---|

## 2.2 模块深度分析

### M1 财务健康度（67.8 分 / +2.6）

- **改善点**：净利率从 1.1% → 1.4%
- **恶化点**：90 天+ 应收 22.5% → 24.8%
- **结论**：**财务体表温度回暖，但血液（现金）流转放慢**

### M2 客户管理（64.3 分 / +1.9）

- **改善点**：A 级客户依赖度从 45% → 38%
- **恶化点**：客户流失率 12% → 14%（销售跑单加剧）
- **结论**：**客户结构在缓慢优化，但销售流失带走客户的风险加大**

### M3 数字化能力（61.2 分 / +2.5）

- **改善点**：上 ERP 比例 42% → 47%
- **恶化点**：80% 中小钢贸仍用 Excel
- **结论**：**头部加速数字化，腰部追赶，尾部完全脱队**

### M4 风险控制（70.5 分 / -0.7）

- **改善点**：—
- **恶化点**：客户跑路率上升 + 银行抽贷加剧
- **结论**：**外部风险增加快于内部能力提升**

### M5 增长能力（67.2 分 / +2.7）

- **改善点**：跨业态拓展（出口 / 加工）增加
- **恶化点**：新客户开发能力仍弱
- **结论**：**头部企业开始多元化，腰部还在等"风口"**

### M6 团队能力（70.1 分 / +0.8）

- **改善点**：二代接班加速
- **恶化点**：销售跑单加剧
- **结论**：**接班是希望，跑单是隐患**

### M7 战略前瞻（62.5 分 / +2.4）

- **改善点**：65 分以上企业有清晰 3 年战略
- **恶化点**：30% 企业"再做做看"心态
- **结论**：**两极分化，敢做战略者活，没战略者死**

# 10. 行动建议（4 类企业 4 种建议）

## 10.1 A 级（≥ 90 分）

- **战略**：扩张 / 收购同行 / 上市
- **数字化**：AI + 自动化 + 出海
- **建议投入**：年营收 1-2% 用于数字化

## 10.2 B 级（80-89 分）

- **战略**：稳健 + 局部升级
- **数字化**：补齐 1-2 个红区模块
- **建议投入**：年营收 0.5-1% 用于数字化

## 10.3 C 级（60-79 分）

- **战略**：**必须升级**（再不动就掉 D）
- **数字化**：上 ERP + CRM + WMS
- **建议投入**：年营收 0.5% 用于数字化 + 1% 用于咨询

## 10.4 D 级（< 60 分）

- **战略**：**生死大考**（要么转型要么退出）
- **数字化**：先救命再升级（应收 / 现金流）
- **建议投入**：先免费试用 30 天 + 看 ROI
