# 销售使用 SOP

## 拜访前
1. **查客户类型**：CRM / 工商查 → 判断是钢管 / 镀锌 / 开平
2. **选 1 页纸**：对应行业拿 2-3 张（不要 3 行业都带，会显得不专业）
3. **行业徽章面朝上**

## 拜访中
1. **开场**：把 1 页纸正面放客户面前
2. **5 秒**：客户读"行业现状"3 行数据
3. **30 秒**：手指"6 大独有困境"问"X 总命中哪几个？"
4. **5 分钟**：扫码做健康度体检
5. **结束**：1 页纸**留给客户**（让他给老板娘 / 二代看）

## 拜访后
1. 1 张 1 页纸 → 客户老婆 / 二代 / 财务 / 司机随便看一眼
2. 客户 = "病毒传播"载体
