# 第 9 页：三轮联动效应（1+1+1 > 3）

```
为什么三者联动 = 1+1+1 > 3？

  ┌──────────┬─────────────────┬─────────────────┐
  │ 单独效果  │ 价值              │ 局限              │
  ├──────────┼─────────────────┼─────────────────┤
  │ 仅管理软件│ 看见 / 但不会用    │ 数据死了          │
  │ 仅现货平台│ 拓客 / 但无内部支撑 │ 接单接不住        │
  │ 仅咨询    │ 知道 / 但落不下来   │ 战略空转          │
  └──────────┴─────────────────┴─────────────────┘

  联动后：
  • 软件提供"数据" → 平台用"数据"做精准营销
  • 平台带来"客户" → 咨询用"客户"做战略升级
  • 咨询给"方向" → 软件配合"方向"上模块

  3 件事一起做 = 商业体进入"飞轮"：
  数据 → 客户 → 战略 → 数据更精准 → 客户更多 → 战略更清晰
```

**讲解要点**（2 分钟）：
- 这是销售**最重要的一页**
- 客户大多数会问"我能不能只买 1 个？"——这一页回答

**设计要点**：
- 飞轮图（数据 → 客户 → 战略 循环）
- 颜色递进

# 附录 B：5 个常见客户陷阱

| 陷阱 | 销售识别 | 应对 |
|---|---|---|
| 客户翻 PPT 太快 | 不听讲，自己看 | 暂停 → 直接互动："X 总，哪一页对您最重要？" |
| 客户拿 PPT 找漏洞 | "你这个数据哪来的？" | 翻到附录 → 数据来源 + 案例验证 |
| 客户全程不点头 | 不参与 | 第 4 页停下 → "X 总，3 个根因您命中几个？" |
| 客户说"全要" | 太积极反而要警惕 | 第 6 页停下 → 模块化 / 先上 1-2 个 |
| 客户说"再想想" | 决策延迟 | 第 11 页停下 → 3 重保证 + 30 天免费试用 |
