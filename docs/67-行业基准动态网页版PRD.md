# 一、产品定位

## 1.1 一句话定位

> **"钢贸 / 钢厂老板的'看见自己在哪'的实时仪表盘"**——
> 输入年流水 / 行业 / 地区 → 5 秒内看到您与 1,547 家同行的完整对照。

## 1.2 与已有交付物的关系

| 形态 | 文档 | 性质 |
|---|---|---|
| 1 张 A4 通用版 | v18 / docs/57 | 静态印刷 |
| 1 张 A4 行业版 | v21 / docs/64 | 静态印刷 |
| 1 张 A4 地区版 | v21 / docs/65 | 静态印刷 |
| **动态网页版** | **v21 / docs/67 + tools/industry_benchmark_dashboard.html** | **动态 SaaS ★** |

**动态网页版 = 静态印刷 + 季度报告的"中间桥梁"**——
- 比印刷更实时（每周更新）
- 比报告更易看（5 秒看完）

# 三、核心功能（4 大模块）

## 3.1 模块 1：客户输入

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 公司名 | 文本 | ✗ | 客户脱敏（可不填）|
| 年流水（万元）| 数字 | ✓ | 1,000-1,000,000 |
| 行业类型 | 选择 | ✓ | 钢管 / 镀锌 / 开平 / 综合钢贸 / 钢厂 |
| 所在地区 | 选择 | ✓ | 长三角 / 珠三角 / 京津冀 / 华中 / 西南 / 其他 |
| 业态 | 选择 | ✗ | 加工 / 贸易 / 流通 / 综合 |
| 成立年份 | 数字 | ✗ | - |

**输入交互**：
- 移动端友好（响应式 / 全屏单页）
- 输入完点"对照" 按钮 → 5 秒内出报告

## 3.2 模块 2：对照看板

### 2.1 第 1 屏：总体定位

```
您 = 行业平均的 1.25 倍
   = 长三角平均的 0.92 倍
   = 行业 TOP 35%（前 30% 是健康线）

7 模块雷达图 + 总分
```

### 2.2 第 2 屏：15 项关键指标对照

| 指标 | 您 | 行业平均 | 您的地区 | 您的行业 | 健康线 |
|---|---|---|---|---|---|
| 毛利率 | X% | X% | X% | X% | ≥ X% |
| 净利率 | X% | X% | X% | X% | ≥ X% |
| 90 天+ 应收 | X% | X% | X% | X% | ≤ X% |
| 库存周转 | X 天 | X | X | X | ≤ X |
| ...（共 15 项）| | | | | |

每行右侧 = 颜色指示（绿 / 黄 / 红）

### 2.3 第 3 屏：趋势图

- 您过去 4 个季度的总分（折线图）
- 行业平均同期对比
- 预测下季度（基于过去 4 季 + AI 预测）

### 2.4 第 4 屏：红区 / 绿区分析

- 红区 TOP 3（最严重 3 个指标）→ 自动给"应对建议"
- 绿区 TOP 3（最强 3 个指标）→ 自动给"如何放大"

### 2.5 第 5 屏：同行案例

- 与您同流水段 / 同行业 / 同地区的"3 个标杆案例"
- 每个案例：困境 / 我们做的 5 件事 / 12 月结果 / ROI

## 3.3 模块 3：行动建议

- 自动生成"3 步骤行动建议"
- 链接到我们的产品方案（M1-M7 ROI 计算器）
- "免费 5 分钟健康度自评"（跳转到 v20 30 题测评）

## 3.4 模块 4：分享 / 转发

- 一键生成"专属海报"（含您的等级 + 头像 + 行动建议）
- 微信 / 朋友圈 / WeCom 分享
- 防伪水印（含客户脱敏 ID）

# 四、数据模型

## 4.1 行业基准数据表

```
industry_benchmark
├── id (uuid)
├── category (string) -- "财务/客户/数字化/风控/增长/团队/战略"
├── metric_name (string) -- "毛利率/净利率/..."
├── industry (string) -- "钢管/镀锌/开平/综合/钢厂"
├── region (string) -- "长三角/珠三角/京津冀/华中/西南/全国"
├── revenue_band (string) -- "<3kw / 3kw-1y / 1-5y / >5y"
├── value_avg (decimal)
├── value_top10 (decimal) -- 行业 TOP 10% 值
├── value_bottom10 (decimal) -- 行业 BOTTOM 10% 值
├── healthy_line (decimal) -- 健康线
├── warning_line (decimal) -- 警示线
├── danger_line (decimal) -- 危险线
├── direction (enum) -- 'higher_better' / 'lower_better'
├── unit (string) -- "%/天/万元/..."
├── quarter (string) -- "2026Q2"
├── sample_size (int) -- 样本量
├── updated_at (timestamp)
```

## 4.2 客户提交记录表

```
user_submissions
├── id (uuid)
├── session_id (string)
├── company_name (string, nullable)
├── revenue (decimal)
├── industry (enum)
├── region (enum)
├── biz_type (enum, nullable)
├── founded_year (int, nullable)
├── score_total (decimal) -- 计算后总分
├── score_by_module (json) -- 7 模块各分
├── red_zones (json) -- 红区指标
├── created_at (timestamp)
├── ip_country (string)
├── source (string) -- "wechat_share/qr/direct/cs_recommend"
```

## 4.3 案例库表

```
case_studies
├── id (uuid)
├── industry (enum)
├── region (enum)
├── revenue_band (string)
├── hero_name (string) -- 客户脱敏名（如"山东 XX 钢管 王总"）
├── module_focus (enum) -- M1-M7
├── before_metrics (json)
├── after_metrics (json)
├── timeline_months (int)
├── investment (decimal)
├── benefit (decimal)
├── roi (decimal)
├── quote (string) -- 客户原话
├── published (bool)
```

# 七、技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 | Vue 3 + Vite + Tailwind CSS + Chart.js / ECharts | 轻量 + 移动端优 |

| CDN | 腾讯云 / 阿里云 | 海报静态资源 |
| 监控 | Sentry + 阿里云 ARMS | 异常 / 性能 |

# 附录 B：数据校准 / 公平性

- 所有数据来自**真实样本聚合**（不是拍脑袋）
- 样本量 < 50 的数据 = 不展示（保护单家公司）
- 异常值剔除：超过 P95 / P5 的样本不进入聚合
- 季度交叉验证：与协会 / 钢联数据交叉校验偏差 ≤ 5%

# 附录 C：合规

- 客户数据脱敏：公司名 / 联系方式不显示
- 数据上传 = 客户授权（隐私协议明示）
- 不出境数据（仅国内服务器）
- 季度安全审计 / 第三方渗透测试
