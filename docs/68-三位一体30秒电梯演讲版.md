# 三位一体方案 · 30 秒电梯演讲版（全员必背）

> 用途：销售 / CS / 老板自己在**电梯里 / 饭桌上 / 1 句寒暄后**讲完三位一体  
> 长度：**严格 30 秒以内（≈ 90-110 字）**  
> 适用场景：电梯 / 饭桌 / 偶遇 / 微信开场 / 自我介绍 / 路演开场  
> 训练目标：**全员脱口而出 / 不卡壳 / 不结巴**

---

# 一、标准版（30 秒 / 全员必背）

```
我们是钢联数字化研究院。

简单 3 句话：

第 1，我们陪 1,547 家钢贸 / 钢厂老板做完整体检；
第 2，我们看到 10 大困境根因就 3 个——看不见 / 做不准 / 跑得慢；
第 3，我们用三位一体——管理软件 + 现货平台 + 咨询陪跑——
      让您"看得见 / 做得准 / 跑得快"。

3 重保证：30 天免费试用、6 个月不达标退款、12 个月顾问陪跑。

X 总，您要不要也做个 5 分钟体检？
```

## 字数统计
- 标准版：约 110 字 / 28 秒（普通语速）/ 30 秒（含小停顿）

## 关键节奏点
| 时点 | 节奏 |
|---|---|
| 0:00 | "我们是钢联数字化研究院。" 简短铭牌 |
| 0:03 | "简单 3 句话" 抛出结构 |
| 0:05-0:13 | 第 1 句（体检 1,547 家）|
| 0:13-0:21 | 第 2 句（3 个根因）|
| 0:21-0:27 | 第 3 句（三位一体）|
| 0:27-0:30 | 3 重保证 + 邀约 |

## 必背 5 个关键词

1. **1,547 家**（信誉锚点）
2. **3 个根因**（认知锚点）
3. **三位一体**（方案锚点）
4. **看得见 / 做得准 / 跑得快**（价值锚点）
5. **3 重保证**（风险逆转锚点）
