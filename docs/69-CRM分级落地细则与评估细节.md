# CRM 分级落地细则与评估细节（深度落地版）

> 用途：v19 / docs/58 的 CRM 分级是**概念框架**（5 维度 + 5 级标签），本文档是**深度落地版**——把每个维度拆到子指标 + 取数公式 + 打分规则 + 销售 SOP + 特殊场景 + 业态差异化 + 数据架构 + 评估闭环  
> 受众：产品 / 销售 / CS / BI / 客户成功 / 销售总监 / CEO  
> 配套工具：`tools/build_crm_grading_calculator.py` → `tools/CRM分级评分计算器.xlsx`  
> 落地周期：MVP 4-6 周（含数据接入 + 评分逻辑 + 销售 SOP 培训）

---

# 总览：CRM 分级的"3 层架构"

```
┌──────────────────────────────────────────────────────┐
│ 第 1 层：数据层（5 维度 / 18 个子指标 / 每天更新）    │
│   订单 / 应收 / 沟通 / 风险 / 行业                     │
├──────────────────────────────────────────────────────┤
│ 第 2 层：评分层（归一化 → 加权 → 复合规则 → 等级）    │
│   S/A/B/C/D 五级 + 4 个特殊标签                       │
├──────────────────────────────────────────────────────┤
│ 第 3 层：行动层（销售 SOP / 资源配额 / 季度复盘）      │
│   月 / 周 / 日级动作 + 升降级触发                      │
└──────────────────────────────────────────────────────┘
```

**核心思想**：**评分不是目的，行动才是目的**——
分级只是决策的输入，**每一级有明确的"动作清单 + 资源配额 + KPI"**。

# 第一部分：5 维度 × 18 子指标完整细则

## 1.1 维度 ① 价值维度（权重 25%）

### 子指标 V1-V4

| 子指标 | 权重 | 数据源 | 计算公式 | 时窗 |
|---|---|---|---|---|
| **V1 年采购额** | 10% | 订单表 | `SUM(订单金额) WHERE 客户ID=X AND 时间 BETWEEN [近 12 月]` | 滚动 12 月 |
| **V2 月均订单数** | 5% | 订单表 | `COUNT(订单) / 12` | 滚动 12 月 |
| **V3 单笔订单均值** | 5% | 订单表 | `SUM(金额) / COUNT(订单)` | 滚动 12 月 |
| **V4 SKU 多样度** | 5% | 订单明细 | `COUNT(DISTINCT SKU)` | 滚动 12 月 |

### V1 年采购额打分规则（钢贸版）

| 年采购额 | 单项得分 | 等级 |
|---|---|---|
| ≥ ¥3,000 万 | 100 | 超大 |
| ¥1,000 - ¥3,000 万 | 85 | 大 |
| ¥500 - ¥1,000 万 | 70 | 中 |
| ¥100 - ¥500 万 | 50 | 小 |
| ¥30 - ¥100 万 | 30 | 微 |
| < ¥30 万 | 10 | 试单 |

> **业态差异化**：钢厂客户的 V1 阈值整体 ×3（钢厂客户体量大）；加工厂 ×0.5（加工厂客户体量小）。

|---|---|
| ≥ 8 单 / 月 | 100 |
| 4-8 单 / 月 | 80 |
| 2-4 单 / 月 | 60 |
| 1-2 单 / 月 | 40 |
| < 1 单 / 月 | 20 |

### V3 / V4 同理（详见配套 Excel）

### 维度 ① 综合分

```
价值分 = V1×40% + V2×20% + V3×20% + V4×20%
范围：0-100
```

## 1.2 维度 ② 利润维度（权重 25%）

### 子指标 P1-P3

| 子指标 | 权重 | 数据源 | 计算公式 |
|---|---|---|---|
| **P1 综合毛利率** | 15% | 财务 + 订单 | `(销售额 - 钢厂成本 - 运费 - 加工费) / 销售额` |
| **P2 年贡献毛利** | 7% | 财务 | `客户贡献毛利 / 公司总毛利` |
| **P3 利润趋势** | 3% | 财务（同比）| `(本年毛利 - 去年毛利) / 去年毛利` |

### P1 毛利率打分（钢贸基准）

| 毛利率 | 单项得分 | 含义 |
|---|---|---|
| ≥ 6% | 100 | 高利润客户（必须保）|
| 4-6% | 85 | 优质客户 |
| 2-4% | 65 | 一般客户 |
| 1-2% | 40 | 利润薄（警示）|
| 0-1% | 15 | 贴本（红区）|
| < 0% | 0 | 亏损（必砍）|

> **业态差异化**：
> - 钢贸：基准如上
> - 钢厂：阈值 ×1.5（钢厂毛利更高）
> - 加工：基准如上 / 但加工费比例可独立打分

### P2 年贡献毛利打分（占公司总毛利比例）

| 占比 | 单项得分 |
|---|---|
| ≥ 5% | 100 |
| 2-5% | 80 |
| 0.5-2% | 60 |
| 0.1-0.5% | 40 |
| < 0.1% | 20 |

### P3 利润趋势打分

| 同比变化 | 单项得分 |
|---|---|
| > +20% | 100 |
| +5% ~ +20% | 80 |
| -5% ~ +5% | 60 |
| -20% ~ -5% | 40 |
| < -20% | 20 |

### 维度 ② 综合分

```
利润分 = P1×60% + P2×28% + P3×12%
```

> **复合规则**：如果 P1 < 0%（亏损客户），不论其他维度多高，**强制降到 C 级及以下**（详见第 3 部分）。

# 第二部分：综合评分计算

## 2.1 基础公式

```
客户综合分 = 价值 × 25% + 利润 × 25% + 付款 × 20% + 粘性 × 15% + 潜力 × 15%
         范围：0-100
```

## 2.2 缺失值处理

| 缺失类型 | 处理 |
|---|---|
| 新客户（< 6 月）| 维度 V1/V2/V3/P1/P2 用同行业相同流水段中位数补；维度 L1/L2 直接给 30（新客户）|
| 财务数据缺失 | P1 用销售估算（销售价 - 钢厂价 - 估算运费）|
| 应收数据缺失 | R3 默认 70（中性）/ R4 默认 100（无记录）|
| 沟通数据缺失 | L3 默认 50 |
| 行业 / 区域缺失 | G1/G4 默认 50 |

## 2.3 归一化与异常值

- 所有单项分**已归一化到 0-100**
- 异常值剔除：单维度计算时 P95+ 的样本被截尾（避免一笔超大订单拉高所有分数）
- 月度数据**采用滚动 12 月**，避免季节性波动

## 2.4 评分更新频率

| 数据源 | 更新频率 |
|---|---|
| 订单（V1-V4 / P2）| 实时（订单触发）|
| 应收（R1-R4）| 每天 |
| 沟通（L2-L3）| 每天 |
| 财务（P1）| 月末核算后 |
| 行业 / 区域（G1-G4）| 季度 |
| **综合分** | **每天 02:00 重算** |

# 第三部分：5 级 + 4 特殊标签的边界与触发

## 3.1 5 级基础规则

| 等级 | 综合分 | 行为约束 |
|---|---|---|
| **S 钻石** | ≥ 85 | 老板亲自维护 / 月度上门 / 总监级备份 |
| **A 黄金** | 70-84 | 销售总监主跟 / 双周维护 |
| **B 白银** | 55-69 | 销售员维护 / 月度跟进 |
| **C 青铜** | 40-54 | 自动化维护 / 季度跟进 |
| **D 警示** | < 40 | 冻结订单 / 法务介入 / 30 天降级评估 |

## 3.2 强制降级规则（必须执行）

| 触发条件 | 强制等级 |
|---|---|
| R4 ≥ 2 次坏账（无论金额） | **强制 D + 黑名单** |
| R3 付款准时率 < 50% | **强制 D** |
| R2 > 50% 且超过 6 月未还 | **强制 D + 冻结订单** |
| P1 综合毛利率 < 0%（亏损客户）| **不允许 ≥ B 级** |
| 销售流失带走该客户但未授权 | **强制冻结 + 重新分配** |
| 客户法律诉讼 / 失信被执行 | **强制 D + 黑名单** |

## 3.3 强制升级规则

| 触发条件 | 触发升级 |
|---|---|
| 单笔订单 > ¥1,000 万 / 90 天内 | **临时 S 级**（90 天观察）|
| 客户主动签长协 ≥ 12 月 + 预付款 | **+1 级** |
| 客户接入 EDI / API | **+1 级**（粘性加强）|
| 客户成为我方公开案例 | **+1 级** |

## 3.4 4 个特殊标签（与等级正交）

| 标签 | 触发 | 含义 |
|---|---|---|
| 🔴 **风险预警** | R1 > 90 天 或 R2 > 30% | 应收已经预警 |
| 🟡 **沉睡客户** | L2 = 0（12 月无下单）| 需要唤醒 |
| 🟢 **战略客户** | 老板手动标记 | 战略合作 / 不按规则 |
| ⚫ **黑名单** | 强制 D + 历史坏账 | 永久禁止合作 |

## 3.5 平局 / 边界处理

| 情况 | 处理 |
|---|---|
| 综合分恰好 = 70（A/B 边界）| **向上取 A**（鼓励维护）|
| 综合分恰好 = 40（C/D 边界）| **向下取 D**（保守原则）|
| 同分多客户排序 | 按 R2（90+ 应收占比）排序 |

# 第四部分：每级的销售 SOP（含资源配额 / KPI）

## 4.1 S 钻石客户（≥ 85 分）

### 配置
- **主跟人**：销售老板 / 销售总监
- **备份人**：CS 总监
- **资源配额**：每客户年度可投入 ¥5-10 万（差旅 + 礼品 + 老板局）
- **维护频率**：月度上门 + 周度电话 + 日度微信
- **总数控制**：≤ 客户总数 5%（如 1,500 客户 → ≤ 75 个 S）

### 月度 SOP

| 时间 | 动作 |
|---|---|
| 月初 | 老板亲自电话 / 关心生意状况 |
| 月中 | 销售总监上门 / 走 5 步流程（详见 v15 顾问式销售 SOP）|
| 月末 | 主动对账 + 应收清账 + 下月预订单沟通 |
| 季度 | 邀请进老板局 |
| 半年 | 邀请进二代俱乐部（如有）|
| 年度 | 老板亲自送年货 + 战略对话 |

### KPI

| KPI | 目标 |
|---|---|
| 续单率 | ≥ 95% |
| 同比销售额增长 | ≥ +15% |
| 客户净推荐分（NPS）| ≥ 70 |
| 客户访谈 | 每年 4 次 |

## 4.2 A 黄金客户（70-84 分）

### 配置
- **主跟人**：销售总监 / 资深销售
- **备份人**：销售经理
- **资源配额**：每客户年度 ¥1-3 万
- **维护频率**：双周上门 + 周度电话
- **总数控制**：≈ 客户总数 15-20%（如 1,500 客户 → ≈ 250 个 A）

### 月度 SOP
- 双周上门 1 次
- 月度对账 + 应收
- 季度业务回顾
- 老板局年度 1-2 次

### KPI

| KPI | 目标 |
|---|---|
| 续单率 | ≥ 90% |
| 销售增长 | ≥ +10% |
| 升级到 S 比例 | ≥ 15% / 年 |

## 4.3 B 白银客户（55-69 分）

### 配置
- **主跟人**：销售员
- **备份人**：销售经理
- **资源配额**：每客户年度 ¥3,000-1 万
- **维护频率**：月度电话 + 季度上门
- **总数控制**：≈ 客户总数 40-50%（大多数客户在这里）

### 月度 SOP
- 月度电话 1 次
- 季度上门 1 次
- 半年 1 次"健康度自评"邀请
- 升级路径明确化（什么动作可以从 B 升 A）

### KPI

| KPI | 目标 |
|---|---|
| 续单率 | ≥ 75% |
| 升级到 A 比例 | ≥ 20% / 年 |
| 应收 30+ 天 | ≤ 20% |

## 4.4 C 青铜客户（40-54 分）

### 配置
- **主跟人**：无（自动化为主）
- **备份人**：CS 团队
- **资源配额**：每客户年度 ≤ ¥1,000
- **维护频率**：季度 SMS + 半年电话
- **总数控制**：≈ 客户总数 25-30%

### 月度 SOP
- 自动化：群发月度行情 + 报价
- 季度群发新品 / 优惠
- 半年 1 次电话调研
- 评估"是否升级 B / 是否降到 D"

### KPI

| KPI | 目标 |
|---|---|
| 升级到 B 比例 | ≥ 15% / 年（孵化）|
| 降级到 D 比例 | ≤ 25% / 年 |
| 自动化覆盖率 | ≥ 90% |

## 4.5 D 警示客户（< 40 分）

### 配置
- **主跟人**：法务 / 风控 / 应收专员
- **备份人**：销售经理（备案）
- **维护频率**：仅"催收 / 黑名单 / 评估"

### 月度 SOP

| 触发 | 动作 |
|---|---|
| 应收逾期 | 法务催收（30 / 60 / 90 天三级）|
| 持续不付款 | 法律诉讼 / 进黑名单 |
| 客户主动表态 | 评估是否给"重新签约 SOP"（v15 失败客户挽回）|
| 6 月观察期 | 重新评估 / 升级回 C 或维持 D |

### KPI

| KPI | 目标 |
|---|---|
| 坏账率 | ≤ 1% |
| 应收回收率 | ≥ 90% |
| D → C 升级率 | 5-10% / 年（少数客户能挽回）|

## 4.6 销售总员工配额（参考）

| 销售职级 | 可服务客户配额 |
|---|---|
| 销售老板 | 5-10 个 S 客户 |
| 销售总监 | 10-15 S/A 客户 |
| 资深销售 | 30-50 A/B 客户 |
| 销售员 | 80-120 B/C 客户 |

# 第五部分：特殊场景与例外

## 5.1 新客户首单（< 6 月）

- 不参与正常评分（数据不足）
- **临时给 B 级 + "新客户"标签**
- 6 月后正式评分
- 首单期间销售投入**与 A 级相当**（争取留存）
- **触发条件**：3 个月内 ≥ 3 单 / 应收无逾期 → 提前晋级

## 5.2 一次性大单（项目客户）

- 单笔 > ¥1,000 万但客户历史短 → 给 **"项目客户"** 标签
- 评分时**只看本单数据**，不进入年度滚动评分
- 项目结束后重新评估

## 5.3 季节性客户（如建材 / 家电）

- **去季节性**：用滚动 12 月数据消除季节
- **季节性偏离修正**：旺季高分 ×0.85 / 淡季低分 ÷0.85
- 建材类客户允许**淡季 L2 = 0** 不算沉睡

## 5.4 集团客户（多公司 / 多采购实体）

- **总集团 + 子公司双轨**
- 子公司各自评分 → 集团评分取**加权平均**
- 集团 ≥ A → 所有子公司**最低保 B 级**（兜底）
- 集团内部协议价等优惠**只给到集团级**

## 5.5 关联交易 / 上下游客户

- 与我方有股权 / 投资关系的客户 → **"关联客户"** 标签
- 评分照常 但**销售提成 / 资源不双倍**

## 5.6 销售跑单带走的客户

- 销售离职 30 天内 → **冻结**该销售名下所有客户分级（防止做高数据）
- 30-90 天 → CS 团队接管 + 重新评估
- 90 天 → 客户重新分配 + 新销售从 B 级开始服务

## 5.7 黑名单（永久 D 级）

- 触发：≥ 2 次坏账 / 法律失信 / 严重违约
- 进入黑名单 → **30 天内全公司通告**
- 想要解除：**老板 + 法务 + CS 三方签字**
- 重新合作时间间隔 **≥ 24 月**

# 第八部分：评估闭环（季度复盘 + 销售考核 + 客户分级流转）

## 8.1 季度复盘（每季度 1 次 / 4 小时会议）

### 复盘内容

| 维度 | 关注点 |
|---|---|
| 分级分布 | S/A/B/C/D 各占比是否合理（建议 5/15/45/25/10）|
| 升降级流向 | 多少 B 升到 A / 多少 A 降到 B |
| 强制规则触发 | 触发了多少次 / 是否合理 |
| 数据完整度 | < 80% 完整度的客户占比 |
| 销售投入与产出匹配度 | 销售在 D 级花了多少时间（应该 < 5%）|
| 收入贡献结构 | S 级贡献占比是否 ≥ 35% / D 级是否 < 2% |

### 复盘输出

1. 调整阈值（如发现 A 级太多 → 提高边界到 75）
2. 调整权重（如发现行业越来越重视应收 → R 权重从 20% → 25%）
3. 调整销售投入（如发现 B 级投入产出比最高 → 加大 B 级投入）

## 8.2 销售考核（季度 / 与提成挂钩）

| 考核项 | 权重 | 目标 |
|---|---|---|
| 名下客户**升级率**（B→A / C→B）| 20% | ≥ 15% / 季 |
| 名下客户**降级率**（A→B / B→C）| 15% | ≤ 10% / 季（负向）|
| 名下客户**坏账率** | 15% | ≤ 1% |
| 名下客户**续单率** | 20% | ≥ 80% |
| 名下客户**评分数据完整度** | 10% | ≥ 90% |
| 名下客户**新单贡献毛利** | 20% | 按级别 KPI |

### 提成挂钩规则

- 销售提成 = 单子毛利 × **客户分级系数**
  - S 客户：×1.5
  - A 客户：×1.2
  - B 客户：×1.0
  - C 客户：×0.6
  - D 客户：×0 + **倒罚**（防止销售给 D 客户接单）

## 8.3 客户分级流转监控

### 健康流转方向（应该多）

| 流向 | 健康线 |
|---|---|
| C → B | ≥ 15% / 年 |
| B → A | ≥ 20% / 年 |
| A → S | ≥ 10% / 年 |
| D → C | 5-10% / 年（少数挽回）|

### 警示流转（应该少）

| 流向 | 警示线 |
|---|---|
| A → B | < 10% / 年 |
| B → C | < 15% / 年 |
| C → D | < 20% / 年 |
| 任何级别 → 沉睡 | < 5% / 年 |

### 报警机制

- 月度自动报警：分级分布偏离基准 ±10% / 大量集中降级
- 季度强制复盘：CMO + 销售总监 + CS 总监三方

# 第十一部分：FAQ / 反常识

## Q1：为什么不直接用 A/B/C 段（按规模）就好，要这么复杂？

**A**：年流水 ¥1 亿但 90 天+ 应收 50% 的客户 vs 年流水 ¥3,000 万但付款准时的客户——哪个值得花精力？**单维度分级会害死你**。

## Q2：评分会不会让销售去"做高数据"？

**A**：会。所以 ① 50% 数据来自系统自动取（订单 / 应收 / 沟通）销售改不了；② R4（坏账记录）+ R3（准时率）有"延迟反噬"——做高短期数据反而拉低长期评分。

## Q3：销售离职怎么办？

**A**：参见 5.6——离职 30 天客户冻结评分 / 90 天后重新分配 / 新销售从 B 级服务起。

## Q4：客户老板有"情面"——明明该 D 但是老板朋友？

**A**：用🟢 战略客户标签——老板手动标记 / 不参与提成扣罚 / 但**不能反向影响其他评分**。上限 ≤ 5%。

## Q5：评分模型多久更新一次权重？

**A**：季度看分布 + 半年微调权重 + 年度大改。绝对不要每月改（销售会无所适从）。

## Q6：客户能看到自己的评分吗？

**A**：**不能直接看分数**——但可以看"健康度建议"（如"您的付款准时率行业 TOP 20%"）。客户感知是**正向反馈 + 升级激励**，不是冷冰冰的分数。

## Q7：D 级客户接到老板朋友推荐，要不要破例？

**A**：参见 5.7 黑名单流程——必须**老板 + 法务 + CS 三方签字 + 进入"重新合作 SOP"**。不能"老板一句话就过"。

## Q8：评分维度未来还会加吗？

**A**：会的，未来重点扩展方向：
- **ESG 维度**（碳排放 / 合规 / 数字化）
- **客户对我方的评分**（双向评分）
- **AI 预测未来 12 月价值**（不只是看过去）

## Q9：5 维度权重为啥是 25/25/20/15/15？

**A**：**钢贸特殊性**：
- 利润优先（行业普遍 1-3% 净利率，差 1 个点天壤之别）→ 25%
- 价值次之 → 25%
- 付款核心（应收是钢贸最大杀手）→ 20%
- 粘性 + 潜力 是"未来" → 各 15%
- 不同业态可调（详见第 6 部分）

## Q10：为什么不用市面上现成的 CRM（如纷享 / 销售易 / 简道云）？

**A**：现成 CRM 有 3 大问题：
1. **维度通用，钢贸不适用**——没有"90 天+ 应收占比""坏账记录"这类钢贸核心指标
2. **不接 ERP 应收 / 财务数据**——脏数据进 + 评分失真出
3. **强制规则不支持复合逻辑**——R4 ≥ 2 次坏账强制 D 这种规则做不出来

我们的方案 = 钢贸定制 + 与 ERP 一体 + 销售提成挂钩。

# 第十二部分：5 句话给老板

1. **CRM 分级不是"客户标签"，是"销售资源分配 + 提成激励 + 风险控制"的核心** —— 决定 80% 利润流向
2. **5 维度 × 18 子指标 + 强制规则 + 季度复盘** —— 一个完整闭环
3. **80% 数据来自系统自动 / 20% 手动** —— 销售改不了关键数据
4. **销售提成与客户分级挂钩**（S×1.5 / D×0 + 倒罚）—— 没有这个挂钩，分级就是摆设
5. **MVP 4-6 周可以跑** —— 不要等"完美"，先跑起来季度迭代

# 附录 C：CRM 分级 vs 现有 4 段客户（v12）

| 维度 | 4 段 | CRM 分级 |
|---|---|---|
| 含义 | 客户**规模分级**（S / A / B / C 段）| 客户**价值 + 风险综合分级**（S / A / B / C / D）|
