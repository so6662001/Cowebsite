# 8 AI 产品训练数据集设计

> 用途：8 个 AI 产品的**模型训练数据集设计**——每个模型需要多少数据 / 数据来源 / 标注规则 / 冷启动方案 / 持续学习  
> 受众：算法 / 数据 / 产品 / BI  
> 关键挑战：**冷启动**（前 100 个客户没数据 → 怎么训第 1 版模型）

---

# AI-1 · 智能定价数据集

## 1.1 数据需求

| 数据类型 | 样本数 | 字段示例 | 来源 |
|---|---|---|---|
| **历史订单成交** | 10 万+ | 客户ID/SKU/数量/成交价/成交时间/利润 | 客户 ERP |
| **钢厂出厂价** | 5 年日度 | 钢厂/SKU/日期/出厂价/价差 | 公开 + 钢厂 API |
| **物流成本** | 10 万 路线 | 起讫地/SKU/运费/时效 | 物流系统 |
| **客户画像** | 1,500 客户 | CRM 分级/历史毛利/付款 | CRM |
| **竞品报价**（最难拿）| 5,000 条 | 同行业同 SKU 报价/成交 | 销售调研 |
| **市场行情** | 日度 | 地区均价/期货价/库存指数 | 我的钢铁 / 钢联 |

## 1.2 标注规则

```python
# 报价样本标注
{
  "input": {
    "customer_grade": "A",
    "sku": "Q235B_PIPE_219x6",
    "quantity": 200,
    "delivery_days": 7,
    "mill_price": 3650,
    "inventory_price": 3640,
    "logistics_cost": 45,
    "regional_avg_price": 3790,
    "customer_history_margin_avg": 4.3,
    "trend_7d": 0.012
  },
  "output": {
    "suggested_price": 3820,
    "actual_price": 3820,
    "deal_won": true,
    "final_margin": 4.2
  },
  "labels": {
    "is_optimal": true,    # 是否最优（人工 + 业务规则）
    "deal_quality": "high" # 成交质量
  }
}
```

## 1.3 模型架构

| 层 | 模型 | 输出 |
|---|---|---|
| 基础价 | 线性回归 / XGBoost | 成本下限 |
| 中间价 | LightGBM | 标准报价 |
| 最优价 | 排序模型 LTR | 3 套报价排序 |
| 防丢单价 | 客户流失模型 | 最低价 |

## 1.4 冷启动（前 100 个客户）

### 方案 1：规则引擎
```
建议价 = (钢厂价 + 物流成本) × (1 + 基础毛利率)
其中 基础毛利率 按 CRM 分级：
  S 级 = 6%
  A 级 = 5%
  B 级 = 4%
  C 级 = 3%
  D 级 = 2.5%（接近成本，但不亏）
```

### 方案 2：协同过滤
- 用 CRM 分级 + 行业 + 地区找"相似客户"
- 取其历史平均毛利率作建议

### 方案 3：从 100 → 1,000 客户
- 6 月内积累 1 万+ 样本
- 切换为 ML 模型（LightGBM）

## 1.5 评估指标

| 指标 | V1 目标 | V2 目标 |
|---|---|---|
| 采纳率 | ≥ 60% | ≥ 80% |
| 毛利偏差 | ± 1.0 个点 | ± 0.5 个点 |
| 丢单率 | < 25% | < 15% |
| 推理 P95 | < 800ms | < 200ms |

# AI-2 · 风控数据集

## 2.1 数据需求

| 数据 | 样本数 | 来源 |
|---|---|---|
| **历史客户行为** | 1,500 客户 × 12 月 | 我方 CRM + 订单 |
| **应收账款历史** | 5 万 应收记录 | 财务系统 |
| **跑路 / 坏账标注样本** | 500 正例 + 5,000 负例 | 历史回溯 |
| **工商外部数据** | 全国企业 | 国家企业信用 / 启信宝 / 天眼查 |
| **司法外部数据** | 失信 / 被执行 | 中国裁判文书 / 中国执行信息 |
| **舆情数据** | 行业相关 | 微博 / 行业网站 |

## 2.2 标签定义

```
正例（跑路 / 坏账客户）：
- 90 天+ 应收持续 6 月+ 且未付清
- 主动停止合作 + 欠款未还
- 法人变更 + 跑路（实际无法联系）
- 进入失信被执行人名单

负例（正常客户）：
- 12 个月内付款准时率 ≥ 90%
- 90 天+ 应收 < 5%
- 无任何外部不良信号
```

## 2.3 关键特征工程

| 特征类 | 示例 |
|---|---|
| 财务历史 | 应收账龄变化 / 付款准时率 / 平均回款周期 |
| 行为变化 | 下单频次变化 / 客单价变化 / 沟通频次变化 |
| 外部信号 | 法人变更 / 工商变更 / 失信 / 舆情 |
| 行业 | 客户所属行业景气度 / 主要客户行业 |
| 我方数据 | CRM 分级 / 历史合作年限 |

## 2.4 模型

| 层 | 模型 |
|---|---|
| 跑路概率 | XGBoost 二分类 |
| 跑路时间预测 | 生存分析（Cox 回归）|
| 客户分级 | 多分类（S/A/B/C/D）|

## 2.5 评估

| 指标 | V1 目标 |
|---|---|
| 跑路预测 AUC | ≥ 0.85 |
| Precision@TopK | ≥ 75% / TopK=20 |
| 误判 A 级为 D 级率 | < 1% |
| 推理 P95 | < 500ms |

## 2.6 冷启动

- **前 100 客户**：纯规则（应收 + 工商 + 司法）
- **100-500 客户**：规则 + 浅层 ML
- **500+ 客户**：完整 ML 模型

# AI-3 · 应收预警数据集

## 3.1 数据需求

| 数据 | 来源 |
|---|---|
| 应收主表（订单 + 应收 + 已收）| 财务系统 |
| 历史付款行为 | 同上 |
| 对账历史（异议 / 确认）| 同上 |
| 客户外部信号 | 工商 / 司法（同 AI-2）|

## 3.2 时序特征

| 特征 | 周期 |
|---|---|
| 应收余额变化 | 30 / 60 / 90 / 180 天 |
| 平均账龄变化 | 同上 |
| 90 天+ 占比变化 | 同上 |
| 付款准时率滚动 | 12 月滚动 |
| 季节性偏差 | 同期 vs 全年 |

## 3.3 模型

- **LSTM**（时序）：预测未来 30 / 60 / 90 天应收风险
- **规则引擎**：触发自动催收（30/60/90 三级）

## 3.4 标签

```
应收逾期标签：
- T+30 天：未付款 → 30 天逾期
- T+60 天：还未付 → 60 天逾期
- T+90 天：再未付 → 90 天+ 严重逾期
- T+180 天：判定为坏账
```

## 3.5 评估

| 指标 | 目标 |
|---|---|
| 30 天后逾期预测 AUC | ≥ 0.80 |
| 催收任务覆盖率 | ≥ 95% |
| 误推送率 | < 5% |

# AI-4 · 信用模型数据集

## 4.1 数据需求

| 数据 | 样本数 | 来源 |
|---|---|---|
| 公司财报 | 1 万 公司 × 5 年 | 客户授权 + 公开数据 |
| ERP 真实数据接入 | 200+ 客户 | 我方 ERP 客户 |
| 银行授信记录 | 5,000 公司 | 合作银行 |
| 实际还款记录 | 5,000 公司 | 合作银行 |
| 数字化能力数据 | 1,500 客户 | 我方 30 题健康度 |

## 4.2 评分卡模型

### 传统评分卡（基础线）

```
信用分 = ∑ 各维度分 × 权重
其中：
  财务健康  20%
  应收质量  15%
  数字化   12% ★ 银行新规重点
  ...
```

### 评分卡 + ML 融合

| 层 | 用途 |
|---|---|
| 评分卡基线 | 可解释（给银行看）|
| LightGBM 修正项 | 提升精度（+5-8%）|
| 规则护栏 | 失信 / 司法 / 工商异常 一票否决 |

## 4.3 标签

- **正例**：12 月内还款准时率 ≥ 95% 且无违约
- **负例**：12 月内出现 30 天+ 逾期 / 违约 / 强制执行

## 4.4 评估

| 指标 | 目标 |
|---|---|
| KS 值 | ≥ 0.45（银行标准）|
| AUC | ≥ 0.78 |
| 与银行内部评分相关性 | ≥ 0.7 |

## 4.5 冷启动

- **前 100 公司**：纯财报 + 工商 + 司法（规则）
- **100-500 公司**：评分卡 + 历史回测
- **500+ 公司**：ML 模型 + 银行联合训练

# AI-5 · 钢价预警数据集

## 5.1 数据需求

| 数据 | 频次 | 跨度 | 来源 |
|---|---|---|---|
| 钢厂出厂价 | 日度 | 5 年 | 各大钢厂官网 + API |
| 期货价（HC/RB）| 实时 | 5 年 | 上海期货交易所 |
| 库存指数 | 周度 | 5 年 | 我的钢铁 / 钢联 |
| 产量数据 | 月度 | 10 年 | 国家统计局 |
| 进出口数据 | 月度 | 5 年 | 海关 |
| 宏观经济 | 月度 | 10 年 | 国家统计局（PMI/CPI/PPI）|
| 国际钢价 | 日度 | 5 年 | LME / Platts |
| 重大事件 | 离散 | 5 年 | 新闻 NLP 抽取 |

## 5.2 模型架构

```
┌──────────────────────────────────────────┐
│ 时序模块（LSTM / Transformer）            │
│   输入：60 天历史钢价 + 期货 + 库存 + 宏观  │
│   输出：未来 7 天预测                      │
├──────────────────────────────────────────┤
│ 事件模块（NLP）                            │
│   输入：行业新闻 / 政策 / 突发              │
│   输出：事件冲击分（-5 ~ +5）              │
├──────────────────────────────────────────┤
│ 融合层                                    │
│   时序预测 × 事件冲击 = 最终预测            │
└──────────────────────────────────────────┘
```

## 5.3 评估

| 指标 | 目标 |
|---|---|
| 1 天 MAE | < 1.5% |
| 7 天方向准确率 | ≥ 65%（涨/平/跌）|
| 异常事件检出率 | ≥ 80% |

## 5.4 冷启动

- 钢价数据**公开可得**（无冷启动问题）
- 直接从 5 年历史数据开始训练
- 配合**专家规则**做兜底（如"产量突增 + 库存大增 → 必跌"）

# 横向通用：冷启动统一方案

## 阶段 1：纯规则期（< 100 客户）

- **不训练模型**
- **业务规则 + 行业基准**驱动
- 监控规则准确率 / 业务采纳

## 阶段 2：浅层 ML 期（100-500 客户）

- **简单模型**（XGBoost / LightGBM）
- 用 V1 数据训练
- 定期与规则做 A/B 对比

## 阶段 3：完整 ML 期（500+ 客户）

- **深度模型 + 多任务**
- 持续学习（每周 / 月更新）
- A/B Test 各算法

## 阶段 4：联邦学习期（1,000+ 客户）

- 多客户数据**不出本地**联合训练（数据脱敏 + 加密）
- 与银行 / 钢厂 / 协会**数据联邦**
- 模型效果再提升 20-30%
