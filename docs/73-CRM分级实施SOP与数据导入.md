# W2 · 数据清洗与导入

## W2.1 数据导入工作流

```
[客户原始数据]
     ↓ 解析 / 编码识别（UTF-8 / GBK）
[标准化映射]
     ↓ 字段映射 + 单位转换 + 时区
[数据清洗]
     ↓ 去重 / 异常值 / 空值
[业务校验]
     ↓ 完整度 / 一致性 / 时序逻辑
[导入数据仓库]
     ↓ 多租户隔离 + 加密
[数据完整度评估]
     ↓ < 80% 通知客户补
[数据完整度 ≥ 80%] → 进入 W3
```

## W2.2 5 大数据清洗规则

### 规则 1：客户主表

| 问题 | 处理 |
|---|---|
| 客户名重复（同公司多记录）| 合并 / 保留最新 |
| 客户名极简（"张总"）| 推回客户补全 |
| 业态空 | 用主营 SKU 猜（钢管 / 镀锌 / ...）|
| 地区空 | 从联系人地址 / 工商查 |
| 规模空 | 用近 12 月订单总额估算 |

### 规则 2：订单历史

| 问题 | 处理 |
|---|---|
| 缺时间 | 推回客户 / 删除 |
| 价格 < 钢厂出厂价 | 标记异常 / 销售核实 |
| 数量 = 0 | 删除 |
| 客户 ID 不在主表 | 自动建客户 + 推回核实 |
| 利润 = 销售价（无成本）| 销售价 × 估算毛利率回填 |

### 规则 3：应收账款

| 问题 | 处理 |
|---|---|
| 账龄 > 365 天 | 标记为"陈年应收" / 与坏账库比对 |
| 应收 - 实收差异 > ¥10 万 | 推回客户对账 |
| 无对应订单 | 推回核实 |

### 规则 4：销售归属

| 问题 | 处理 |
|---|---|
| 1 客户多销售 | 选 12 月内沟通最多者 |
| 销售已离职 | 标记"待重新分配"|

### 规则 5：黑名单

| 问题 | 处理 |
|---|---|
| 历史坏账无时间 | 标记"历史"（不参与时序）|
| 客户名脱敏 | 与主表模糊匹配 |

## W2.3 数据完整度评分

| 维度 | 完整度计算 | 目标 |
|---|---|---|
| 客户基础信息 | 必填字段非空率 | ≥ 95% |
| 订单历史 | 12 月覆盖客户比例 | ≥ 80% |
| 应收账款 | 应收订单匹配率 | ≥ 90% |
| 销售归属 | 1 客户 1 销售对应率 | 100% |
| **综合** | 加权 | **≥ 80%（最低）/ ≥ 90%（理想）** |

## W2.4 数据完整度低于 80% 怎么办

| 方案 | 适用 |
|---|---|
| 1. 推回客户补（推荐）| 客户配合度高 |
| 2. 销售协助手工补 | 数据散在销售脑子里 |
| 3. 用行业基准代替 | 实在补不上 / 阶段 1 妥协 |
| 4. 缓 1 周 + 改进数据流 | IT 配合度高 |

## W2.5 数据导入工具

- 我方提供 **CSV 模板 + 校验工具**
- 客户填模板 → 上传 → 自动校验 + 报告

# W3 · 评分校准与老板审阅

## W3.1 首版评分跑通

### 自动评分流程
```
[完整数据] → [评分引擎] → [5 维度 18 子指标分] → [综合分 + 等级] → [触发强制规则] → [最终分级]
```

### 评分输出示例（首版 / 1,500 客户）

```
S 钻石  ≥ 85 分    62 客户（4.1%）
A 黄金  70-84      245 客户（16.3%）
B 白银  55-69      678 客户（45.2%）
C 青铜  40-54      385 客户（25.7%）
D 警示  < 40       130 客户（8.7%）
```

## W3.2 TOP 100 客户**人工校准**

> **关键步骤**：销售总监 + 老板**逐一审 TOP 100**（最重要的客户）

| 类型 | 客户数 | 审阅人 | 时间 |
|---|---|---|---|
| S 级（全部）| 62 | 老板 + 销售总监 | 2 小时 |
| A 级 TOP 50 | 50 | 销售总监 | 1 小时 |
| D 级（全部）| 130 | 销售总监 + 法务 | 2 小时 |
| 异常分布客户 | 20 | 销售总监 | 1 小时 |

### 校准维度
1. **机器评分 vs 人工感觉**是否一致
2. **强制规则触发是否合理**（如 R4=2 但客户其实正常）
3. **业务特殊情况**（战略客户 / 关联客户 / 老板朋友）

### 校准结果记录

```json
{
  "customer_id": "xxx",
  "machine_score": 84,
  "machine_grade": "A",
  "human_grade": "S",       // 老板手动覆盖
  "override_reason": "战略客户 / 老板朋友 / 不参与提成扣罚",
  "tags": ["🟢 战略客户"]
}
```

## W3.4 阈值微调

如果分布偏离基准（如 A 级 > 10%），需要微调阈值：

| 情况 | 调整 |
|---|---|

| C 级 < 40%（太少）| 阈值 70 → 72（更严）|
